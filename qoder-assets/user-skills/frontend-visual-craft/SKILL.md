# 前端视觉工艺（打磨层）

使用本 skill 时，输出开头标注【项目名·frontend-visual-craft】，项目名取当前工作区根目录名（如 remote-monitor、hc-standard）。

## 内核

功能跑通之后的差距不在"用没用阴影"，在数值对不对。这五条全是数值活儿：色阶差 1.5%–3%、字重差一档、字间错开 30ms、阻尼比大于还是小于 1。凭感觉调出来的界面就是"AI 味"本身。

所以：一个细节要么带上具体数值，要么别动它。写"加个柔和的阴影"等于没写。

## 先判断该不该出手

| 现状 | 先做什么 |
|---|---|
| 视觉风格还没定（配色、字体族、气质） | 先走 `frontend-design`，风格定了才轮到这一层 |
| 按钮位置反直觉、点不到、误触 | 先走 `frontend-interaction-design` |
| 结构对、风格对，就是"差口气" | 走本 skill |

顺序不能倒：位置对了 → 风格定了 → 才打磨精度。在错的布局上打磨等于给歪楼刷漆。

## 五条工艺规则

### 1. 层次用微明度阶梯，不用边框

**为什么**：黑边是把"分层"这件事画成一条线，眼睛先看到线再看到内容。明暗差 1.5%–3% 时，眼睛读到的是"这块浮起来了"，不是"这里有条线"。

**落地**：

- 定义 4 级 surface，每级亮度（L 值）只差 1.5%–3%。
- 亮色模式下，page 用略灰（如 `#f7f8fa`）当 surface-0，卡片纯白当 surface-1。**页面必须纯白打底时，层次改用极轻投影承担**——白到顶就没法再往上叠了。
- 暗色模式不要用 `#000` 打底（白字光晕最重），用 `#121417` 系，每级叠白 4%/7%/10%，越高越亮。
- 需要边界时用 hairline：`inset 0 0 0 1px` 内阴影，不占盒模型、不会被 subpixel 吃掉半像素。
- 输入框聚焦：内 1px 品牌色 40% + 外 3px 品牌色 14% 双环，同时 field 自身升一级 surface，做出"咬合"感。

**翻车点**：

- `outline: none` 单独出现 = 键盘用户彻底失去焦点。必须保留 `:focus-visible`，并在 `@media (forced-colors: active)` 下退回实线 outline。
- `color-mix()` 在微信小程序旧 webview 不支持，dark 三级要预算成 rgb 写死（`#1e2125 / #262a2e / #2e3236`）。

### 2. 暗色模式字重降一档，但小正文别降

**为什么**：白字在黑底上会产生 halation（光晕外溢），同一 wght 的笔画在暗底上视觉更粗。降一档是光学补偿，不是审美偏好。

**落地**：

- 可变字体直接用 `font-weight: 360`（400 → 360，约 -40），别绕 `font-variation-settings`。
- 静态字体只能换 300 字重的字族，**不要用 `-webkit-text-stroke` 硬凑**，会把字形糊掉。
- 标题/大字号（≥20px）降一档；**12–14px 小正文保持原档**——低对比 + 细笔画会糊成一团。

**翻车点**：视频里"全站 wght -40"是有前提的。字体不是可变字体时 `font-weight: 360` 静默取整到 300 或 400，看起来时好时坏；全局无差别降档会让小字更难读。别照抄。

### 3. 流式文字做晕染，不做逐字蹦

**为什么**：硬切换让每个字都是独立事件，眼睛一直被打断。`blur(6px) → 0` 的瞬间对焦模拟"字从雾里浮出来"，相邻错开 30ms 后连成一道波浪。

**落地**：

- 逐字/逐词包裹，`animation: ink-in 420ms ease-out both` + `animation-delay: calc(var(--i) * 30ms)`。
- keyframes：`from { filter: blur(6px); opacity: 0 }` → `to { filter: blur(0); opacity: 1 }`。
- 行内图标：`vertical-align: -0.125em`（往下 1/8 字高）。**必须用 em**，px 不随字号缩放。
- `@media (prefers-reduced-motion: reduce)` 直接关掉动画。

**翻车点**（四条都会毁掉效果）：

- 整段重渲染 = 所有已显示的字反复重新晕染。必须按索引 key，只有新增字符带 delay。
- 30ms × 100 字 = 3s，长段落要等到天荒地老。按 chunk 限长（≤24 字）或把 `--i` 取模封顶。
- 逐字 `filter: blur` 在低端安卓 webview 掉帧，降级为 `opacity + translateY(2px)`。
- 中英混排时逐字 `inline-block` 会把英文单词从中间折断换行，用 `Intl.Segmenter`（granularity: 'word'）切分，中文按字、英文按词。

### 4. 数字锁死等宽 + 排版不塌

- **数字抖动**：`font-variant-numeric: tabular-nums`，老内核补 `font-feature-settings: 'tnum' 1`。前提是字体自带 tnum 特性。
- **补一刀**：tnum 只管数字，`%` `.` `+` `-` 仍然会变宽。容器给 `min-width` + 右对齐，否则时钟和百分比照样左右晃。
- **折叠区展开**：`grid-template-rows: 0fr → 1fr` 自适应撑开，不写 JS 量高度。内层**必须**是 `overflow: hidden; min-height: 0`，少任何一行都不生效。
- **孤字落行**：`text-wrap: balance` 给标题（中英文都吃），`text-wrap: pretty` 只对西文孤词有效，中文基本无感——中文场景真正管用的是控制容器宽度。

### 5. 动效按性格分两类，混用就违和

| 类型 | 场景 | 手感 | 参数（k / c / m） | CSS 近似 |
|---|---|---|---|---|
| 过阻尼 | 拖拽吸附、翻页、抽屉落位 | 零回弹，起步即快，末尾咬死 | 1200 / 70 / 1 | `cubic-bezier(0,0,.2,1)` 120ms |
| 欠阻尼 | 点赞、复制成功、收藏 | 越过目标再弹回来一次 | 400 / 18 / 1 | `cubic-bezier(.34,1.56,.64,1)` 320ms |

参数不是拍的：临界阻尼 = 2√(k·m)。k=1200 时 ≈ 69，取 70 刚好压死在目标位；k=400 时 = 40，取 18 得 ζ≈0.45，一次明显回弹后收敛。

**翻车点**：

- 拖拽进行中不能用 transition 接管 transform，手指还在动它自己往回弹是最难受的触感。
- 反馈气泡 2.5s 自动隐藏，定时器每次重触发**必须先 clear**，否则连点两次，第一次的定时器会把它提前关掉。

## 提示词模板

需求后面接这一段，能一次性把这一层带上：

> 视觉按以下工艺执行：层次用 4 级 surface 微明度阶梯（亮色 page 略灰当 0 级、越高越亮；暗色用 #121417 系打底不碰纯黑；每级差 1.5%–3%），不用粗边框，边界用 1px 半透明 hairline；输入框聚焦用内 1px 品牌色 40% + 外 3px 14% 双环，同时字段自身升一级 surface，保留 :focus-visible 与 forced-colors 兜底；可变字体在暗色模式把 ≥20px 的字降一档 wght（约 -40），12–14px 小正文不动；流式文字按字 blur(6px)→0 渐显、相邻错开 30ms、每 chunk ≤24 字、行内图标 vertical-align: -0.125em；所有动态数字用 tabular-nums 且容器 min-width + 右对齐，折叠区用 grid-template-rows 0fr→1fr 并给内层 overflow:hidden;min-height:0；动效分性格——拖拽吸附类 k1200/c70 过阻尼零回弹，反馈类 k400/c18 欠阻尼带一次回弹并 2.5s 自动隐藏且重触发清定时器；全部动效在 prefers-reduced-motion 下降级。

## 审查模式

给了截图或文件路径时，按五条逐项对照，只报数值级差异，不评价风格偏好：

```
【<项目名>·frontend-visual-craft】视觉工艺审查：<页面或组件名>

1. 层次  `文件:行` 现状 → 违反哪条 → 具体数值改法
2. 暗色字重 ...
3. 文字动效 ...
4. 数字排版 ...
5. 动效性格 ...

已核对无问题：色阶步进、焦点可见性、tnum、动效中断性
```

一条都没犯就直说"工艺层没问题"，别为了凑报告把风格偏好包装成缺陷。

## 硬红线

- 纯 `#000` 打底 + 纯 `#FFF` 正文，halation 拉满。
- `outline: none` 且没有任何替代焦点指示。
- 用醒目的 1px 纯黑或纯白边框承担分层。
- 动态数字（时钟、计数、金额）没上 tnum。
- 逐字动画不判 `prefers-reduced-motion`。
- 拖拽类动效带回弹。
- 同屏混用两种阻尼性格。
