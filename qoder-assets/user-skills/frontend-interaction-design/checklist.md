# 交互审查清单

用法：按场景逐组扫，每项只在"判定口径"成立时记录。分级别默认值可下调——如果整个项目已经统一成另一种写法且用户用习惯了，一致性优先，报 P2 而不是 P1。

## 1. 导航与返回

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 每页都有返回路径 | 非首屏页面，无法一眼看到返回或关闭入口，且系统手势/返回键不可用 | P0 |
| 返回不丢上下文 | 从列表进详情再返回，丢失滚动位置、筛选条件或已选状态 | P1 |
| 导航范式不混用 | iOS 风格页面里出现汉堡菜单；Android 里用 Sheet 顶部"完成" | P1 |
| 小程序导航栏让位胶囊 | 自定义导航栏的右侧操作与胶囊重叠或被遮挡 | P0 |
| 返回与关闭语义分清 | 弹层用"返回"字眼、页面用"关闭"字眼，造成误解 | P2 |

## 2. 主次与顺序

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 一屏只有一个主按钮 | 同一视口内出现两个 filled 或品牌色按钮 | P1 |
| 确认/取消顺序 | 中文界面里确认在左、取消在右（与阅读方向相反） | P2 |
| 主次不只靠颜色 | 移除颜色后无法区分主次（仅靠红/绿色差） | P2 |
| 危险操作不与主操作并排 | 删除与保存相邻且都是文字或都是 filled | P0 |
| 批量栏有明确主操作 | 批量栏里只有危险操作，没有"处理/导出"之类的主操作 | P2 |

## 3. 可点尺寸与间距

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 触控目标下限 | 实际可点区域小于 24×24px（WCAG 下限），或移动端小于 44×44pt / 48×48dp；若同时与相邻可点物间距 < 8dp，升为 P0 | P1 |
| 文字按钮内边距 | 可点区域等于文字外接框，周围不足 8dp 空隙 | P1 |
| 相邻可点元素间距 | 两个可点元素间距 < 8dp（密集列表 < 12dp），如行内"编辑/删除"紧贴 | P1 |
| 图标按钮可识别 | 仅图标无文字、无 aria-label、无 tooltip，且不是通用图标 | P2 |
| 贴边目标不被系统吃掉 | 贴屏幕边缘的按钮未内缩，与手势条/圆角重叠 | P0 |

## 4. 移动端可达性与安全区

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 主操作在下半屏 | 高频主操作位于屏幕上 1/3 且无底部替代入口 | P1 |
| 底部安全区 | 固定底栏未加 `env(safe-area-inset-bottom)`，按钮被 Home Indicator 或手势条压住 | P0 |
| 键盘不遮按钮 | 输入时主操作被键盘覆盖，且无上推、无吸附加载 | P0 |
| 长页面主操作可达 | 页面超过 2 屏，提交按钮只在文末，用户必须滚到底才能操作 | P1 |
| 大屏机顶部左侧 | 关键操作只在顶部左侧，6.7 寸以上机型单手够不到 | P2 |
| 横屏/平板布局 | 操作栏放在屏幕顶部居中，两侧留大片空白 | P2 |
| 高德/地图类手势冲突 | 边缘手势区放了高频按钮（边缘滑动返回会误触） | P2 |

## 5. 列表与批量操作

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 行内操作数量 | 一行直出超过 2 个操作按钮，且未收进"更多" | P2 |
| 行操作位置稳定 | 操作按钮的位置随内容长度浮动（左对齐紧跟文本） | P2 |
| 批量栏空选态 | 没有选中项时仍显示批量操作按钮，点了无事发生 | P1 |
| 批量栏不遮内容 | 批量栏升起后，最后一行内容被永久遮挡且无法滚动到底 | P1 |
| 删除入口唯一 | 同一行既有左滑删除又有行内删除，且行为不一致 | P2 |
| 分页/加载更多位置 | 加载更多在列表顶部；或分页器跟随内容浮动而不是固定在底部 | P2 |

## 6. 表单

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 提交按钮紧跟最后一项 | 提交按钮与最后一个输入项之间隔了大段空白或额外滚动区 | P1 |
| 长表单分步 | 单项表单单屏超过 8 个字段仍需一次提交 | P2 |
| 错误提示就近 | 校验失败只在页面顶部 toast，未在对应字段旁标注 | P1 |
| 字段与按钮的从属清晰 | 提交按钮视觉上像是某个输入项的附属（间距小于字段间距） | P2 |
| 危险提交的措辞 | 确认按钮写"确定"，未说明具体动作（应为"删除/提交/停用"） | P2 |
| 重复提交防护 | 异步提交无 loading、无禁用态，可连点 | P1 |

## 7. 弹窗 / 抽屉 / Bottom Sheet

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 操作紧贴内容 | 按钮与内容之间隔了大段空白，或按钮浮在内容中间 | P2 |
| 关闭入口 | 无关闭按钮、点击遮罩不关闭、Android 返回键不关闭 | P1 |
| 移动端 Sheet 可下拉关闭 | 底部 Sheet 无下拉手势、无关闭按钮 | P2 |
| 弹层不叠弹层 | 弹窗里再开弹窗，第二层关闭后第一层状态丢失 | P1 |
| 弹层高度可控 | 内容超出屏幕但不可滚动，按钮被挤出视口 | P0 |
| 主按钮唯一 | 弹窗底部两个等权重按钮（"确定"和"保存"并存） | P1 |

## 8. 危险操作

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 二次确认 | 删除、停用、清空类操作无确认，直接执行 | P0 |
| 确认文案具体 | 用"确定/是否继续"，未复述对象（如"删除 3 台设备？"） | P1 |
| 不可撤销的提示 | 不可恢复的操作未说明后果，也未提供撤销入口 | P1 |
| 危险按钮样式 | 删除按钮与普通按钮同色同权重 | P1 |
| 危险操作位置 | 危险操作出现在首屏右上角等高频误触区 | P2 |

## 9. 空状态 / 加载 / 错误

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 空状态有唯一可点物 | 空状态只有文案没有出口，或同时给了 3 个以上按钮 | P1 |
| 引导按钮位置 | 引导按钮不在说明文案正下方或未水平居中 | P2 |
| 加载态 | 首屏加载无骨架屏或 loading，直接空白 | P2 |
| 错误可重试 | 请求失败只显示"加载失败"，没有重试按钮 | P1 |
| 空与错的区分 | 请求失败时显示"暂无数据"，掩盖了真实错误 | P1 |

## 10. 反馈与状态

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 按压反馈 | 按钮、卡片、列表项点击无任何视觉反馈（移动端缺 hover-class/active 态） | P2 |
| 异步结果反馈 | 操作成功后无 toast 或状态变化，用户不知道成没成 | P1 |
| 禁用态原因 | 按钮置灰但没有任何提示说明为什么不能点 | P2 |
| 长任务有进度 | 超过 2 秒的操作只有 loading 圈，无进度或阶段提示 | P2 |

## 11. 桌面端后台

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 表格操作列位置 | 操作列不在右侧固定，横向滚动后消失 | P1 |
| CTA 在视线终点 | 表单提交按钮脱离表单区域（放页面最底部或顶部菜单） | P1 |
| 悬停不是唯一入口 | 行操作只在 hover 时出现，触屏设备/键盘用户无法使用 | P1 |
| 弹窗按钮位置 | 弹窗 footer 按钮左对齐、或取消在右 | P2 |
| 全宽主按钮 | PC 上用横跨 800px+ 的全宽主按钮 | P2 |
| 快捷键与双击 | 双击行打开详情等隐式交互，无其他显式入口 | P2 |

## 12. 无障碍与文案

| 检查项 | 判定口径 | 默认级别 |
|---|---|---|
| 焦点顺序 | 键盘 Tab 或读屏遍历顺序与视觉顺序不一致（DOM 顺序与 CSS 视觉顺序相反） | P1 |
| 图标按钮命名 | 纯图标按钮无 aria-label / alt | P1 |
| 只读状态可辨识 | 禁用/只读状态与可编辑状态视觉无差异 | P2 |
| 文案指代明确 | 按钮写"提交"但实际是"保存草稿"，或"下一步"未说明下一步是什么 | P2 |
| 文案长度 | 移动端按钮内文字过长被截断，或换行撑破布局 | P2 |
