开发语言: Java 8
核心框架: Spring Boot 2.1.13.RELEASE (对应 Spring Cloud Greenwich.SR6)
ORM框架: MyBatis-Plus 3.2.0
其他关键库:
- Swagger 2.7.0 (API文档)
- Fastjson 1.2.70 (JSON处理)
- JJWT 0.9.0 (JWT认证)
- EasyExcel 2.1.6 (Excel操作)
- Netty 4.1.115.Final (网络通信)
- Dynamic Datasource 3.3.1 (多数据源)
- Sharding-JDBC 4.0.0-RC2 (分库分表)
- Activiti 7.1.0.M4 (工作流)
- XXL-JOB 2.4.0 (分布式任务调度)
