Bug class: 特殊作业票视频上传失败。

Root cause: workStartTime 与 workEndTime 取值相同会触发罗伯湘（LuoboXiang）saveTicketAndDevice 返回 3012 错误："作业结束时间不能早于或等于作业开始时间"，票据被拒后视频上传整链路中断。

Fix pattern: 在发起视频上传/调用 saveTicketAndDevice 之前校验并强制 workEndTime > workStartTime（等于即视为非法），不要把该判断交给远端报错。

Reusable lesson: Don't 允许 workStartTime == workEndTime 入库后直接推给罗伯湘，因为它会拒收并阻塞视频上传；instead 在本地做严格时间先后校验后再外呼。适用于经 LuoboXiang 对接的特殊作业票视频上传；不适用于其它票型或非 LuoboXiang 集成。
