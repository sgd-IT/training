园区监管平台对重大危险源包保责任人（implementPerson）只提供批量新增/变更关联信息接口（POST /openapi/implementPerson/saveOrUpdateBatch，文档编号 5.3.7.1），删除包保责任人无需上报平台，仅本地删除即可（已确认）。与从业人员（practitioners）不同：从业人员删除需将 deleted 置 1 经其 saveOrUpdate 接口做平台侧软删；包保责任人实体不应包含 deleted 字段，其本地表也无该列。包保的删除逻辑不得再补平台上报。
补充现状（2026-09-22 核查）：该接口的推送从未成功验证过——开发库与测试库各仅 4 条数据且 sync_status 全为 0；历史 33 次操作中新增 18 成功/9 失败、删除 6 次、修改 0 次。测试用例"改一条包保责任人信息保存→平台侧该条信息变化"（需求21）将是修改推送链路的首次真实验证。
