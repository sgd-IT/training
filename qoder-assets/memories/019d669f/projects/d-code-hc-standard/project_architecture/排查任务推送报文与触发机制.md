排查任务（checkTask）推送报文由 RiskTaskSaveEntity 承载，通过 BaseRiskTaskMapper.xml 的 selectBaseRiskTaskListByIds 从 base_risk_task 取数（check_cycle_unit 在 SQL 里由中文转 1-4）。推送触发路径：新增仅落库（sync_status 默认 0），由 quartz DataSyncTask.syncRiskTask（每天 6:00/23:30）扫 sync_status in (null,0,2) 补推；修改在 updateBaseRiskTask 落库后立即调 sync 推送（2026-09-23 新增，推送异常被捕获并标记 sync_status=2，由定时任务重试，不阻断本地保存）。兜底入口：PC 同步按钮（GET /base/riskTask/sync/{ids}）与按日期补推。推送结果统一写 sync_status：1=成功、2=失败。
