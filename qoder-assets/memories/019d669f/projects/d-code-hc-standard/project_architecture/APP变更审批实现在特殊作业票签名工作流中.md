"APP变更审批流程"不是独立模块，其实现在特殊作业票（8 类：动火、受限空间等）的签名工作流与"变更作业人"动作里，只能从 APP 端发起，核心逻辑落在 RuoYi 后端服务中。据此两条定位约束：一是按"变更审批""审批流程"这类业务词在后端检索模块名会找不到对应工程，须从作业票签名与变更作业人的接口入手；二是该流程无 PC 端入口，PC 上验证不到，测试必须在 APP 端走完整签名单据链。
