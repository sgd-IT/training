排查任务接口（5.4.6.6）的字段类型与格式要求如下：
- checkCycleUnit：必须为整数，取值范围为1-4（1=小时，2=天，3=月，4=年），不得填写汉字。
- checkStartTime：必须为字符串格式，格式为'yyyy-MM-dd HH:mm:ss'，用于平台计算统计周内应排查次数。
