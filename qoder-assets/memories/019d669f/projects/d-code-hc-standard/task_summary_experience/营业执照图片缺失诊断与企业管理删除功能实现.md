## Task description
- Core requirement 1: Diagnose and resolve the 'business license image missing' data repair issue in the 企业管理 (enterprise management) module (需求编号01 营业执照图片缺失恢复).
- Core requirement 2: Implement the 'add delete function to enterprise management' feature, including UI buttons, permission checks, and soft-delete capability.
- Task background: The 企业管理 module corresponds to the base/contractor/index page; business license images are stored in base_contractor.file_path; the platform sync pushes contractor data but does not include license images.

## Execution process
1. For license image diagnosis: queried base_contractor table, verified all 4 file_path URLs are valid and files are accessible JPEGs; confirmed frontend ImagePreview renders full URLs correctly; concluded local data is intact and the only location where images are 'missing' is the remote regulatory platform due to sync DTO not including any image field.
2. For delete functionality: identified that frontend delete buttons were commented out in index.vue; verified backend delete endpoint and permission menu exist; un-commented both toolbar batch and row-level delete buttons; implemented soft-delete by adding del_flag column to base_contractor and updating BaseContractorMapper.xml to use update instead of delete and add del_flag='0' filters to all select statements.
3. Verified operation logging works for delete actions via sys_oper_log.

## Notes
- The '营业执照图片缺失' issue was determined to be a platform-side problem, not a local data issue, because the sync payload lacks an image field.
- Soft-delete implementation requires manual DB ALTER TABLE to add the del_flag column, as the MCP is read-only.

## Task overview
Successfully completed two complex tasks: (1) diagnosed the root cause of the business license image issue, confirming local integrity and identifying the platform sync as the failure point; (2) implemented the delete functionality with soft-delete, un-commenting UI elements and modifying backend mapper to support recovery.
