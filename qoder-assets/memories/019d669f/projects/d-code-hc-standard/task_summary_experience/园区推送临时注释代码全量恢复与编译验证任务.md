## Notes
- "恢复注释代码"必须跨层成套处理：Service 调用、Controller 端点、前端按钮是同一功能的三层入口，只恢复后端会留下无入口的死端点或调用失败的前端按钮。
- 恢复不等于全部解注释：接口已废弃的模块（包保履职）不在恢复范围，须先对照《待上正式库变更清单》区分"临时停用"与"永久废弃"。
- 手工解注释易引入 tab/空格缩进偏差造成虚假 diff，恢复后应用 git diff 对比 HEAD 收敛空白噪音。
- Java 大工程 GetProblems 语言服务器可能长时间未就绪，用 mvn -o compile -pl 模块 -am 离线编译作为替代验证手段。
