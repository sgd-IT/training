## Task description
- Core requirement: support modification of personnel certificate information — add an 'edit' button on the certificate list page to update certificate info.
- Task background: the 企业管理 (enterprise management) module corresponds to base/contractor/index.vue; certificate images are stored in base_contractor_people_cert.file_path; the platform sync pushes contractor data but does not include certificate image fields. Backend already has PUT /base/contractorPeopleCert endpoint and updateBaseContractorPeopleCert service; frontend index.vue had the edit button and logic commented out.

## Execution process
1. Identified that the backend controller, service, and mapper XML all already support certificate editing (PUT endpoint, dynamic SQL update); only the frontend was missing the UI trigger.
2. Restored the row-level '修改' button in ruoyi-ui/src/views/base/contractorPeopleCert/index.vue by un-commenting the relevant block and removing surrounding dead code.
3. Fixed two critical form rendering issues in handleUpdate: converted certType from Long to String for el-select compatibility, and added peopleList loading by contractorId to ensure correct person selection dropdown.
4. Verified operation logging works for edit actions via sys_oper_log.

## Notes
- The edit functionality only updates the local database; it does not re-upload or sync the certificate image file to the remote regulatory platform (which requires separate handling).
- This environment lacks MySQL MCP access, so the menu permission `base:contractorPeopleCert:edit` could not be verified; if the button doesn't appear, check the sys_menu table for its existence.
