项目名称: 若依管理系统 (RuoYi)
版本: 3.8.6
架构: 基于Spring Boot的多模块系统
核心模块:
- ruoyi-admin: 启动入口
- ruoyi-framework: 核心框架配置
- ruoyi-system: 系统业务逻辑
- ruoyi-quartz: 定时任务
- ruoyi-generator: 代码生成器
- ruoyi-common: 通用工具类
功能特性: 用户管理、权限控制、数据监控、定时任务、代码生成、PDF/Excel处理等
