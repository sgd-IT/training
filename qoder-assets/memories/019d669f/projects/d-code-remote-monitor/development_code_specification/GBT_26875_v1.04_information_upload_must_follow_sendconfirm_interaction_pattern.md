According to GB/T 26875 v1.04 protocol documentation section 5.1, 'information upload' (terminal → platform) must follow a 'send/confirm' interaction pattern; section 5.2 specifies retransmission with ≤30s timeout and up to 3 retries if no confirmation is received.
