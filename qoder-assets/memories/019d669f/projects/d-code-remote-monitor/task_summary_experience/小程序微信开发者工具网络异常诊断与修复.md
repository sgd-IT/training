## Task description
- Core requirement: diagnose and fix "network error" shown when scanning QR code to preview the mobile mini-program in WeChat DevTools
- Task background: the mobile app uses environment-dependent base URLs; dev environment uses http://192.168.250.47:48080/admin-api (HTTP + local IP); WeChat DevTools enforces domain validation by default, blocking HTTP requests to local IPs unless explicitly disabled

## Execution process
1. Read manifest.json to identify the source of urlCheck:false setting
2. Read request.js to extract dev/prod API base URLs and confirm hardcoded IP usage
3. Read compiled project.config.json in unpackage/dist/dev/mp-weixin/ and verify urlCheck:false is missing from the setting section
4. Read source project.config.json to confirm it also lacks urlCheck:false
5. Apply SearchReplace to add "urlCheck": false to both the compiled and source project.config.json files

## Notes
- The manifest.json has "urlCheck": false but uni-app compilation does not propagate this setting to the generated project.config.json, causing WeChat DevTools to enforce domain validation.
- The dev URL http://192.168.250.47:48080/admin-api requires the phone and development server to be on the same local network; if not, switching to the production HTTPS URL is required for testing.

## Task overview
Successfully diagnosed and fixed the WeChat mini-program network error: identified missing urlCheck:false in project.config.json as the primary cause and applied the fix to both compiled and source configuration files; confirmed that the local IP dev URL requires same-network access or fallback to production HTTPS URL.
