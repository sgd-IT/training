任何 git commit 或代码审核（review）操作之前，必须先向用户展示变更摘要并等待用户明确同意，禁止自动执行提交或审核；git 提交禁止堆积大量修改一次性提交，必须拆分成最小的、逻辑独立的修改单元逐个提交——一个提交只包含一个功能点、修复点或重构点。
