The following code-base structural facts were verified during the implementation of RegulatorStatisticsServiceImpl:
- DeviceInfo.createTime is of type LocalDateTime (line 101 in DeviceInfo.java)
- AlarmRecordServiceImpl.checkAndEscalate uses isBefore() (not <=) to determine overtime, making the regulatory cockpit's overtime logic identical to the escalation task's logic
- StockSnapshot is a newly introduced record type used to share current inventory, approved weight, daily in/out weights, and unconfigured count between getStatistics and getStockOverview methods
- RetailDataScopeHelper.getAccessibleRetailIds() returns null when no accessible retail IDs exist, requiring defensive null checks in service methods
