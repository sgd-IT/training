## Task description
- Core requirement: fix the bug where '超量存储' type disposal in alarm management cannot jump to the corresponding '出货' interface in inventory incoming/outgoing module
- Task background: `alarm/index.vue`'s `handleDisposal` method jumps to `/store/inventory/records` for `alarmType === 3`, but without any parameters; the records page receives no params and only shows the list, not opening the '登记出货' dialog with pre-set type=2

## Execution process
1. `alarm/index.vue`: modified `handleDisposal` to pass `query: { type: '2' }` when `row.alarmType === 3`, using `router.push({ path: '/store/inventory/records', query: { type: '2' } })`
2. `records.vue`: added `onMounted` hook to read `route.query.type`; if present and equals '2', calls `handleAdd()` to open the registration dialog and sets `form.type = 2` to pre-select '出货'
3. Verified that `retailId` from the alarm row is correctly passed through the route query and used to pre-fill the dialog's '所属零售店' field
4. Confirmed other alarm types still use the original disposal dialog unchanged
5. Confirmed direct access to `/store/inventory/records` (no query) does not trigger auto-dialog
