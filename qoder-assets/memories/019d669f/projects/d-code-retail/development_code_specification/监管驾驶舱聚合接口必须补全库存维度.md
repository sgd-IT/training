The regulatory dashboard's aggregation interfaces (e.g., `/fireworks/regulator/statistics`) must include stock-related dimensions. Specifically, two new endpoints are required: `stock-overview` (showing total stock, approved weight, utilization rate, overage store count) and `stock-ranking` (ranking stores by overage ratio with red/yellow/green color coding aligned to alarm severity levels). This ensures regulatory oversight covers inventory compliance alongside alarms and devices.
