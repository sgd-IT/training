运行环境要求：
- JDK: 21 (推荐) 或 25
- Maven: 3.x+
- Redis: >= 6.0 (支持分布式限流、队列等)
- 数据库：MySQL, Oracle, PostgreSQL, SQLServer等 (支持异构切换)

启动方式：
- 使用Maven命令：`mvn clean install`
- 默认Profile为dev
- 支持Docker编排一键部署

关键配置：
- 日志级别：local/dev/info, prod/warn
- 监控账号：ruoyi/123456 (默认)
