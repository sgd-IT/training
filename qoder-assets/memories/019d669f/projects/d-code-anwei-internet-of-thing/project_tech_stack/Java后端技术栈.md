技术栈：
- 开发语言：Java 8
- Web框架：Spring Boot 2.1.13.RELEASE, Spring Cloud Greenwich.SR6
- ORM：MyBatis-Plus 3.2.0 (配合 dynamic-datasource-spring-boot-starter 3.3.1)
- 数据库驱动：MySQL Connector J 9.1.0
- 工作流：Activiti 7.1.0.M4
- 分库分表：Sharding-JDBC 4.0.0-RC2
- 任务调度：XXL-Job 2.4.0
- 文档生成：Swagger 2.7.0
- 工具库：Hutool 4.1.1, Fastjson 1.2.70, Gson 2.11.0, Netty 4.1.115
- 存储/支付/第三方：Qiniu, Aliyun OSS, QCloud COS, 微信支付 SDK, 支付宝 SDK, 百度 OCR, 个推 SDK
