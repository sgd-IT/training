依赖管理策略：
- 使用 dependencyManagement 统一管理所有子模块的依赖版本。
- 关键版本锁定：Jackson 2.9.10.8 (安全修复), Spring Cloud Cairo-SR7/Greenwich.SR6。
- 特殊处理：Activiti 排除了 mybatis 以避免与 MyBatis-Plus 冲突；Elasticsearch 需配合特定 Spring Boot 版本。
- 主要依赖包括：Fastjson, Swagger, EasyExcel, PDFBox, iTextPDF, Tencent/Ali/QCloud SDKs, JWT, ZXing, Pinyin4J。
