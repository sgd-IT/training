**开发语言**: Java 8

**核心框架与组件**：
- `Spring Boot 2.1.13.RELEASE`（主框架）
- `Spring 5.3.39`、`Spring Cloud Greenwich.SR6`
- `MyBatis-Plus 3.2.0`（ORM）
- `Sharding-JDBC 4.0.0-RC2`（分库分表）
- `Activiti 7.1.0.M4`（工作流）
- `XXL-JOB 2.4.0`（分布式任务调度）
- `FastJSON 1.2.70`、`Jackson 2.9.10.8`（JSON处理）
- `Swagger 2.7.0`（API文档）
- 多云对象存储：七牛、阿里OSS、腾讯COS
- 第三方SDK：微信支付、支付宝、百度OCR、腾讯云、个推、MQTT、Netty
