双预防机制所有推送数据均来源于自建平台本地MySQL数据库，具体表映射关系如下：
- 分析对象 → `base_risk_obj`
- 风险单元 → `base_risk_unit`
- 风险事件 → `base_risk_event`
- 管控措施 → `base_risk_measure`
- 排查任务配置 → `base_risk_task`
- IMEI编码 → `base_risk_imei`
- 风险四色图 → `base_risk_fourchart`
- 排查记录 → `base_risk_task_record`
- 隐患信息 → `base_hidden_trouble_upload`
- 启停记录 → `base_risk_unit_log`
