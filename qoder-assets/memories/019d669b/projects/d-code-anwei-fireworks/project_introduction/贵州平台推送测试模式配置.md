贵州平台数据推送支持测试模式：
- 查询条件统一改为 `.eq(..., 1)`，仅处理 `access_status = 1` 的测试数据
- 推送成功后**不更新** `access_status` 字段（即不执行 `.set("access_status", 2)`），便于重复测试
- 该模式仅用于人工测试验证，与生产环境 `0→2` 增量流程隔离
