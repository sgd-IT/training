**开发语言与基础框架**: Java 8, Spring Boot 2.1.13.RELEASE, Spring Framework 5.3.39

**核心中间件与组件**: 
- MyBatis-Plus 3.2.0（ORM）
- Sharding-JDBC 4.0.0-RC2（分库分表）
- Dynamic Datasource 3.3.1（多数据源）
- Activiti 7.1.0.M4（工作流）
- MQTT v3.1.2（物联网消息）
- Netty 4.1.115.Final（网络通信）

**常用工具库**: FastJSON 1.2.70, Swagger 2.7.0, JJWT 0.9.0, EasyExcel 2.1.6, ZXing 3.3.0, iTextPDF 5.5.13, Lombok 1.18.30
