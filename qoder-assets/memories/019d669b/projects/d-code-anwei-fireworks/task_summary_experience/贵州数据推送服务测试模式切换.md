## 任务描述
为贵州政务数据推送服务（PushingGZDataService）配置测试模式：所有数据源查询统一启用 access_status = 1 过滤，并禁用推送成功后的 access_status = 2 回写，确保测试可重复。

## 执行过程
```mermaid
graph TD
    A[需求:启用测试模式] --> B[首轮grep定位9处access_status=1注释点]
    B --> C[search_replace全部注释]
    C --> D[二次grep确认0匹配]
    D --> E[识别4处access_status=0的增量接口（ZBBJ/RYCRJL/CLCRJL/SXTFX）]
    E --> F[识别4处set\("access_status", 2\)回写块]
    F --> G[search_replace恢复13处=1查询 + 注释4处set=2]
    G --> H[三次grep验证：13处=1存在、4处set=2已注释]
```

## 任务总结
成功实现测试模式切换：13处数据查询统一过滤 access_status = 1（含原9处基础数据 + 4处增量报警/出入记录），4处推送后状态回写被注释，避免污染测试数据，支持反复验证。
