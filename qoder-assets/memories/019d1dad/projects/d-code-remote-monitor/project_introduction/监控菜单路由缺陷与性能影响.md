项目存在一个已知的架构缺陷：'MySQL监控'和'Java监控'两个菜单实际上是iframe外壳，由于Nginx未配置对应转发规则，它们会回退到前端SPA首页（即大屏页面）。这导致每次点击这两个菜单都会在后台启动一个完整的大屏实例，并触发每30秒一次的接口轮询（如dashboard/statistics、device-locations等），大量消耗数据库连接池和Redis资源，是导致后端偶发超时和连接数飙升的根本原因之一。
