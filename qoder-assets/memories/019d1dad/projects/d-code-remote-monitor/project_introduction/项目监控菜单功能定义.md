项目监控菜单设计意图：
- MySQL 监控：原本用于展示 Druid 内置监控台（数据源连接池状态、SQL 监控含执行次数与最慢耗时、SQL 防火墙、Web应用/URI 监控、Session 监控、Spring 监控、JSON API），前端 infra/druid/index.vue 仅用 IFrame 组件（width/height 100%）加载 VITE_BASE_URL + '/druid/index.html'。数据来源是 Druid 的 StatFilter（application-prod.yaml 中 filter.stat.enabled: true、log-slow-sql: true、slow-sql-millis: 100），页面渲染由 StatViewServlet 提供（stat-view-servlet.enabled: true、url-pattern: /druid/*）。该 Servlet 的 allow 为空即不限制 IP，login-username/login-password 均为空即不校验登录，本地直连 48080 可无密码进入；若对外恢复访问必须先补账号密码。
- infra_config 表中 config_key='url.druid' 的配置项用于覆盖 iframe 默认地址（Druid 独立部署到其他域名时使用），值为空则走同域 /druid/index.html。
- Java 监控：原本用于 iframe 加载 Spring Boot Admin（/admin/applications，看 JVM 堆、线程、GC、日志级别），但 application-prod.yaml 已 exclude AdminServerAutoConfiguration 等相关自动配置，生产环境该功能实际关闭、入口不可用。
- Redis 监控：与上述两个 iframe 外壳不同，是真实页面，调用 /infra/redis/get-monitor-info 获取 Redis INFO 结果自行渲染，因此可正常工作。
