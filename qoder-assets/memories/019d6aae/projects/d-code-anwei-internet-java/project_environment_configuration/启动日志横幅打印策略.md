项目启动日志横幅使用log.error打印，目的是确保在任意日志级别配置下（如生产环境仅启用INFO及以上）都能显示。这是一种非规范但实用的做法。规范做法应改为log.info，并在logback-spring.xml中为com.monkey.general.common.config.ApplicationConfig logger单独设置INFO级别。
