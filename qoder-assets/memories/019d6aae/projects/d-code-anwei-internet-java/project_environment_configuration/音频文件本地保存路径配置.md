monkey-aluminium-api 项目的音频文件保存路径配置为 D:\project\java\monkey-aluminium-api\loulv-audio 目录，该路径为硬编码配置，不依赖 FileUploadConfig.getUploadPath() 动态生成。

适用边界：仅适用于 monkey-aluminium-api 项目。anwei-internet-java（monkey-monitor / monkey-monitor-api）工作区不适用——其嘉果/漏铝音频上传通过 OSSFactory.build().uploadSuffix(bytes, suffix) 走云存储抽象（由 sys_config 表决定具体 CloudStorageService 实现），代码中无上述硬编码路径，排查该工作区音频落地问题时应查 OSS 配置而非此路径。
