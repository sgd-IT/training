项目运行端口为 9090；MySQL 通过 dynamic-datasource + HikariCP 管理双库：master=anwei_mon_aluminum_local、iot=anwei_iot_db_local（连接池 minimum-idle:10 / maximum-pool-size:50）；MQTT 地址 tcp://127.0.0.1:1883（含 username/password 认证）；多个外部服务（漏铝 consume/person 接口、数据同步、复位按钮状态等）指向 IP 111.230.115.79。

关于 Redis 的重要事实：配置项 `spring.redis.open` 在代码中**没有任何读取点**（全库检索 spring.redis.open / isOpen / getOpen 均无匹配），它是历史遗留的死配置，写 false 既不会关闭 Spring Boot 的 Redis 自动配置，也不会让 RedisTemplate/RedisUtils 失效——RedisTemplate 仍会创建并在首次操作时尝试连接 spring.redis.host:port。嘉果漏铝链路（/lyxl/push 的 msgId Hash 池 hset、/api/lyxl/file 的 hget/hgetAll/hdel）强依赖 Redis，因此部署环境必须在 127.0.0.1:6379 真实运行 Redis 服务，不能因看到 open:false 就认为无需安装。
