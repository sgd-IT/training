语音播报重复次数的配置项按工作区不同：

- anwei-internet-java（monkey-monitor / monkey-service）：由 `dmpk.dmpks[].repeatCount` 控制，绑定 DMPKEntity.Dmpk（字段 castWellId / repeatCount / deviceCode），播报时按铸造井 id 匹配到对应 dmpk 条目后用 Collections.nCopies 复制 repeatCount 次消息；整个 `dmpk` 段缺失时 isopen 默认 false，漏铝语音静默不播报且不报错。本工作区不存在 alarm-voice 前缀。
- monkey-aluminium-api：由 `alarm-voice.repeat-count` 控制，默认值 5。

排查"播报次数不符/完全没有播报"时先确认所在工作区用的是哪一项，再检查该配置是否成段存在（含 castWellId 与 monkey.leak.videos 的铸造井对应关系）。
