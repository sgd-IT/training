项目运行时需记录'接收音频到开始播报间隔'这一关键耗时指标，用于诊断语音播报延迟问题。该指标覆盖file.getBytes()、设备端时间日志打印、文案拼接等播报前准备阶段，日志前缀为'[耗时追踪]'，单位为秒(s)。
