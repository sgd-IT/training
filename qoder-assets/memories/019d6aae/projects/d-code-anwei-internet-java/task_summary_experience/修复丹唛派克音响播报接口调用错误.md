## 任务描述
修复 JiagoDeviceService 中丹唛派克音响播报接口调用错误，确保语音报警正常触发。

## 任务总结
将错误的 danMaiPaiKe.SendInfo1(pushModel.getContent()) 替换为 danMaiPaiKe.SendInfo(alarmContent, deviceCodes)，并固化 alarmContent 为 "漏铝设备发送漏铝告警"；该方案确保音响API接收到合法JSON，避免解析失败，实现稳定语音播报。
