## 任务描述
为语音播报链路添加全链路耗时日志，定位现场5秒延迟原因，并统一日志时间单位为秒（s）。

## 执行过程
```mermaid
graph TD
    A[需求:排查语音播报5秒延迟] --> B[分析链路：HTTP入口→文件处理→HTTP调用]
    B --> C[在JiagoController.java添加API整体耗时日志]
    C --> D[在JiagoDeviceService.java添加getBytes/播报循环/本地保存等6处耗时日志]
    D --> E[在DanMaiPaiKe.java添加SendInfo1 HTTP请求耗时日志]
    E --> F[统一将所有耗时计算由long ms转为double s，除以1000.0]
    F --> G[验证3个文件日志输出格式正确、无编译错误]
```

## 任务总结
成功实现端到端耗时追踪：在Controller层记录API总耗时，在Service层细粒度记录file.getBytes、5次播报调用、播报总耗时、本地保存及方法总耗时，在DanMaiPaiKe层记录单次HTTP请求耗时；全部日志前缀统一为[耗时追踪]，单位统一为秒（保留小数），便于快速定位瓶颈（如多次HTTP调用累积延迟）。
