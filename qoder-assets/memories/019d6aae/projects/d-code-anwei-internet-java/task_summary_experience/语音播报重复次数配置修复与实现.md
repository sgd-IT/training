## 任务描述
修复语音播报重复次数配置不生效问题，使alarm-voice.repeat-count配置能真正控制播报次数。

## 执行过程
```mermaid
graph TD
    A[发现rcn硬编码为1] --> B[尝试在DanMaiPaiKe读取配置并拼接文案]
    B --> C[因缺少@RequiredArgsConstructor/@Value import导致编译失败]
    C --> D[补全import并清理冗余@Slf4j]
    D --> E[确认rcn参数在音柱侧无效，需调用方循环调用]
    E --> F[将repeatCount字段移至JiagoDeviceService并注入]
    F --> G[在JiagoDeviceService中循环调用SendInfo，每次追加\u200B零宽空格]
    G --> H[清理DanMaiPaiKe中无用的repeatCount字段和Value注解]
```

## 任务总结
成功实现可配置的语音重复播报：配置项alarm-voice.repeat-count生效，通过JiagoDeviceService循环调用DanMaiPaiKe.SendInfo，并用零宽空格\u200B区分每次播报文本，规避音柱去重机制。
