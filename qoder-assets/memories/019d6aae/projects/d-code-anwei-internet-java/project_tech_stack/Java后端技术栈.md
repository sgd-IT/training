技术栈：
- 开发语言：Java 8
- 核心框架：Spring Boot 2.1.5.RELEASE, Spring Cloud Greenwich.SR6
- ORM框架：MyBatis-Plus 3.2.0 (排除Activiti内置MyBatis)
- API文档：Swagger 2.7.0
- 工作流引擎：Activiti 7.1.0.M4
- 分库分表：Sharding-JDBC 4.0.0-RC2
- 多数据源：dynamic-datasource-spring-boot-starter 3.3.1
- 工具库：Hutool 4.1.1, FastJSON 1.2.70, EasyExcel 2.1.6
- 存储与支付：阿里云OSS, 腾讯云COS, 七牛云, 支付宝SDK, 微信支付SDK
- 云服务：百度OCR, 个推推送, 腾讯云SDK
- PDF处理：iTextPDF 5.5.13, Apache PDFBox 2.0.15
