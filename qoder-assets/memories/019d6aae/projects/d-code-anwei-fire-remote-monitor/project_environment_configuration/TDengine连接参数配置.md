TDengine连接配置定义在`application-dev.yaml`中，包含`td-datasource.url`（含数据库名eiot）、`db`（eiot）、`username`（root）、`password`（taosdata）和`driverClassName`（com.taosdata.jdbc.rs.RestfulDriver）。
