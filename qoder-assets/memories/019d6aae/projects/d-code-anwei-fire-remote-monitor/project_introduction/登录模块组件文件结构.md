项目登录模块包含以下组件文件：
- `BrandPanel.vue`：品牌展示面板，被`src/views/Login/components/index.ts`导入
- `PasswordStrength.vue`：密码强度指示器，被`src/views/Login/components/LoginForm.vue`导入
- `SafeInput.vue`：自定义输入框，被`src/views/Login/components/index.ts`导入
