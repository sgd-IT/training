项目使用Java 21作为运行环境，基于Spring Boot 3.4.1构建，集成Lombok 1.18.36和MapStruct 1.6.3。采用Maven多模块结构，包含dependencies（BOM）、framework（基础框架starter）、server（主服务）、module-system、module-infra、module-eiot（IoT核心，支持MQTT/TCP/CoAP/Modbus/GB/T 26875）、module-ai等模块。framework层提供spring-boot-starter-security、web、mybatis、redis、mq、websocket、excel、job、monitor、biz-tenant、biz-data-permission、protection等定制化starter。
