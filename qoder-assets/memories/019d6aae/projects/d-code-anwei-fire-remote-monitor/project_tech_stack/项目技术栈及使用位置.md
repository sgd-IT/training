项目技术栈如下：
- Spring Boot 3.4.1：作为基础框架，统一管理Web、Security、MyBatis、Redis、Kafka、WebSocket、定时任务、多租户、数据权限等模块；
- Netty 4.1.116.Final：被Vert.x底层依赖，项目中直接使用其MQTT协议常量（MqttQoS/MqttConnectReturnCode）和ByteBuf（Modbus解析）；
- Vert.x：IoT通信层核心，所有协议组件（MQTT/TCP/UDP/HTTP/CoAP/GB/T26875/EMQX/Modbus）均基于Verticle构建；
- Kafka：用于规则引擎数据流转与消息推送，通过Vert.x KafkaProducer实现；
- Akka Actor 2.6.21：封装在iot-message-actor模块中，提供消息总线能力（目前在主业务pom中被注释，未启用）；
- MyBatis-Plus：关系数据库ORM层，广泛用于module-eiot-biz和module-ai-biz等业务模块；
- Redis（Redisson 3.41.0）：通过自定义starter封装，用于缓存、分布式锁、消息队列、租户信息存储及设备状态缓存；
- 时序数据库：通过module-eiot-temporal实现可插拔架构，支持Elasticsearch（默认启用）、IoTDB（pom中注释）、TDengine（通过JDBC配置）。
