运行环境要求：
- Node.js: `^22.19.0` 或 `>=24.0.0`

启动方式：
1. npm 安装：`npx @deepseek-ai/dsh web` (默认端口 3080)
2. 源码运行：
   - `git clone https://github.com/deepseek-ai/deepseek-harness.git`
   - `cd deepseek-harness`
   - `pnpm install`
   - `pnpm run build`
   - `pnpm dsh web`

注意：项目处于开发者预览阶段，存在破坏性变更风险。
