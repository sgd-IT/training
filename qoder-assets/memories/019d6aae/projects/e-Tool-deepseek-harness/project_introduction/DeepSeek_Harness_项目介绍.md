项目概述：
- **DeepSeek Harness (`dsh`)**: 由 DeepSeek AI 开发的开源 agent harness（智能体框架）。
- **架构特点**: “一切皆插件” (everything is a plugin)，基于 [Cordis](https://github.com/cordiverse/cordis) 驱动。
- **当前状态**: 开发者预览版，迭代迅速，可能存在破坏性变更。
- **许可证**: MIT
