构建命令：
- `pnpm install`: 安装依赖
- `pnpm run build`: 编译库和 Web UI
- `pnpm test`: 运行单元测试
- `pnpm dsh web`: 启动 Web UI

构建细节：
- 使用 `tsc -b` 进行类型检查和编译
- 使用 `tsdown` 进行打包
