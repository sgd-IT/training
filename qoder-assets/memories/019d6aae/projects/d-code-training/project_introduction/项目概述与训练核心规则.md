项目定位：面向重度 AI 依赖型 Java 开发者（1年经验）的 72 天基本功强化计划。

核心目标：
1. 降低对 AI 的依赖，培养独立思考能力。
2. 打牢 Java 基础（OOP、集合、并发、JVM、设计模式）。
3. 掌握业务代码编写能力。

七大阶段：
Phase 1: 基础语法 + OOP (Day 1-8)
Phase 2: 集合 + 泛型 + 异常 + Stream/Lambda + 协议手写 (Day 9-21)
Phase 3: 并发 + 异步 + SSE + JVM (Day 22-34)
Phase 4: 设计模式 + Spring + MyBatis + Redis + MQ (Day 35-52)
Phase 5: AI Agent (Spring AI) (Day 53-58)
Phase 6: 前端 (HTML/CSS/JS/Vue 3) (Day 59-68)
Phase 7: 全栈综合项目 (Day 69-72)

核心铁律：
1. 只修改 TODO 标注的方法体，严禁改动测试文件。
2. 练习期间卡住先读报错/测试，禁止直接抄 AI 代码。
3. 伪代码先行，写在文件顶部注释中。
4. 任何修改必须立即 git commit，保留历史以便恢复。
