开发语言与工具：
- 核心语言：Java
- JDK 版本：JDK 21（正式特性如虚拟线程、Sequenced Collections、Record、Pattern Matching；预览特性仅讲解不启用）
- IDE：IntelliJ IDEA
- 测试框架：JUnit
- 构建管理：Maven (pom.xml)

核心原则：
- 禁止使用 AI 生成完整代码，必须手敲。
- 训练代码必须在标准 JDK 21 下编译运行，不加 --enable-preview。
- 每个中间件专题配手写底层练习（如手写线程池、IOC、协议帧等）。
