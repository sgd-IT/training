## Task description
- Core requirement: create a login account (sys_user) for an existing retail store, binding it via the retail_id field and assigning the appropriate role
- Task background: the fireworks system uses data scope isolation where RetailDataScopeHelper.getAccessibleRetailIds() returns the list of retail IDs accessible to the current user; sys_user.retail_id is used to bind a user to a specific retail store; the 'channel' role grants the exact menus needed for retail store operations

## Execution process
1. Verified the retail store exists in fireworks_retail_info table with id '2084542845535084545'
2. Verified existing retail-bound users (e.g., 'test') use the 'channel' role and have retail_id set
3. Confirmed the 'channel' role's menu permissions match retail store needs (报警管理, 设备管理, 风险预警, 零售店管理, 人员管理, 进出货管理)
4. Generated a BCrypt hash for the initial password '666666' using spring-security-crypto
5. Inserted a new sys_user record with user_id=2084542845535084546, user_name='13549539036', retail_id='2084542845535084545', and status='0'
6. Inserted a corresponding sys_user_role record to assign the 'channel' role (role_id=2081987464594104322)
7. Generated a new BCrypt hash for the updated password '123456'
8. Updated the sys_user record's password field with the new hash
