## Task description
- Core requirement: 演示大屏视觉微调——(1) 内容区整体上移贴近 header（先 30px 再追加 30px，累计 60px）；(2) 卡片标题 HTML 覆盖层与底图原标题像素级对齐（往左上移、再左移、最后修复右端残影）
- Task background: screen/index.vue 的 .top 高 173px，.screen-container 原为 height: calc(100% - 173px)；LeftColumn/CenterColumn 的 .card-title 覆盖层用于盖掉底图 safty.png"安全生产天数"、analysis.png"告警分析"原文字并写新标题

## Execution process
1. index.vue `.screen-container`：margin-top 设为 -60px、height 改为 calc(100% - 113px)，实现内容上移 60px 且底部仍铺满到 1080；副作用是中间栏（flex:1）视频区随之变高 60px，左右栏固定高度卡片底部留出约 40px 空隙
2. 用 PowerShell + System.Drawing GetPixel 对 src/assets/screen/*.png 做亮度扫描定位原文字：初版阈值 (R+G+B)>500 只量到卡片边缘高光（x≈0 起），改用接近白色判定 (R>195 && G>195 && B>195) 才测准——safty.png 文字 x≈44~156/y≈12~25，analysis.png 文字 x≈43~117/y≈13~26
3. LeftColumn.vue 与 CenterColumn.vue 的 `.card-title`：left 40→30→22px、top 12→6px，使覆盖区完整盖住原文字及左侧三角装饰
4. 用户截图反馈右端露出原文字残影 → 根因是 min-width:190px 且渐变 72% 即开始羽化，实心段仅到 ~159px < 原文最宽 170px；改 min-width 190→240px、渐变实心段 72%→78%（实心覆盖至 ~209px，尾留 53px 羽化避免硬边）

## Notes
- 覆盖层"盖不准"的排查顺序应先量底图原文字的真实像素区间，再反推覆盖层的 left/top/min-width，而不是凭感觉反复试数值
- 像素扫描必须区分"卡片边缘高光"与"文字白色"两种信号，阈值过宽会把装饰亮线当成文字导致误判
- 只有这两张卡需要覆盖层对齐，其余卡片（实时监测概况/未处置告警/核定药量等）直接沿用底图自带标题
