消防告警三级定级口径（用户 2026-10-08 拍板，已写入《消防告警字段语义定稿》）：

- **一级 = 凡探测到火灾迹象的事件**：火警（含烟感/温感/手动报警等部件触发）、热成像、烟火、高温。判定内核是"探测到的是不是火灾迹象"，与"从哪探测的"无关。
- **二级 = 其余类型（兜底）**：隐患、离岗、通道占用等既非火灾迹象也非故障类的事件。
- **三级 = 故障类为主**：故障；离线、信息类（含设备屏蔽通知）同类。

代码落点（2026-10-08 第3步已实现）：`AlarmSemantics.deriveLevel(alarmKind)` — 火警→"1"、隐患→"2"、其余（故障/离线/误报/信息）→"3"；一级内部再按 tier Ⅰ-Ⅳ 分缓急。
