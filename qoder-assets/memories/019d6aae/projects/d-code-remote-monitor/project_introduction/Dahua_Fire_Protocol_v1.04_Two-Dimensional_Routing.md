大华消防协议 v1.04 采用命令字（1B）与类型标志（1B）联合构成的二维路由机制，而非单一命令字一维路由。帧格式为：[命令字][类型标志][ADU][校验和]。

- 命令字 0x02（设备→平台）承载11种子类型：0x01（系统状态）、0x02（部件状态）、0x03（部件模拟量）、0x84/0x85/0x86（扩展帧）、0xBF（终端参数帧）、0x87（通用数据帧）、0x8A（删除能力集）、0x8D（系统状态扩展）、0x8E（部件状态）。
- 命令字 0x04（平台→设备）承载8种子类型：0x64/0x81（定长/不定长参数设置）、0x82/0x83（定长/不定长参数查询）、0xF9（远程消音）、0x88（查询通用帧）、0x89（设置通用帧）、0x8B（查询能力集）。
- 命令字 0x05（设备→平台）专用于应答，含0xBE/0xBF/0x88/0x8B等类型标志。
- 通用数据帧（0x02+0x87）是协议推荐的统一上报格式，ADU结构为嵌套TLV：类型标志+信息对象数 → 部件类型+地址+数据类型+长度+内容+时间标签；嵌套深度最多2级。
- 协议明确区分方向：0x02/0x05为设备→平台，0x04为平台→设备，0x01/0x03/0x06/0x07为双向或单向控制帧。

大华消防协议 v1.04 中，命令字 0x02 + 类型标志 0x87 构成的通用数据帧（Universal Data Frame）是协议推荐的统一上报格式。其 ADU（Application Data Unit）结构为嵌套TLV：
- 第一层：类型标志（1B=0x87）+ 信息对象数目（1B）；
- 每个信息对象包含：部件类型（1B）+ 部件地址（4B，小端，节点号2B+回路号2B）+ 数据类型（1B）+ 数据内容长度（2B）+ 数据内容（嵌套TLV）+ 时间标签（6B）；
- 数据内容的嵌套TLV最多2级：一级为数据类型（0=注册/1=事件/2=模拟量/3=定长参数/4=不定长参数/5=操作/7=能力/8=确认/9=加密），二级为具体值或子结构；
- 事件值编码为双字节小端：低字节=子类型，高字节=报警类型。
