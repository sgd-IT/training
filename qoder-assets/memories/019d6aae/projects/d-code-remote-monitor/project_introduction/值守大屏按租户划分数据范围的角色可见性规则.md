值守大屏（duty-screen，标题"安为智慧消防值守平台"）数据范围划分的最终角色可见性规则：仅 super_admin 在标题右侧显示租户下拉框，可在"全部租户"与指定租户之间切换查看；tenant_admin 与其余所有角色（含 monitor_role、企业普通用户）不出现任何租户切换入口，只在标题右侧显示当前登录租户的名称文本，数据恒为本租户。tenantId 参数仅对 super_admin 生效，其余角色传参一律忽略。非 super_admin 的租户名由后端按登录账号所属租户 id 反查后随统计接口响应返回，普通角色凭已有的值守大屏查询权限即可获得；前端不使用本地缓存的数字租户 id 自行展示，也不为该功能下发 system:tenant:query 权限（会同时解锁全量租户分页列表）。规则由来：需求清单中"设备状态按项目分开"未实现，设备表无项目归属字段，故改为按租户粒度划分。
