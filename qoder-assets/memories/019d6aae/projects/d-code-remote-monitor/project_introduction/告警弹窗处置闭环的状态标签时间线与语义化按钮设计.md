报警弹窗第一优先级功能需求：
- 展示处置状态（待处理/处理中/已处置/已关闭）并用颜色标签区分
- 中间面板改为处置时间线，基于alarm.alarmTime/alarm.handleTime/alarm.handler等已有字段构建
- 右侧面板替换为语义化处置按钮：确认火警、标记误报、关闭工单，按orderStatus动态显隐
- 所有操作调用已有API（confirmAlarm/markFalseAlarm/closeAlarmOrder），不新增后端接口

适用边界（2026-09-28 补充）：本条是"处置闭环"视角的功能设计，并非视觉稿。项目另有 alarm-popup/index.vue 采用不同交互形态——顶栏类型名+级别+已持续时长计时、左栏视频区/图片缩略图、右栏位置/设备/时间/级别/描述信息列、底部备注快捷标签（误报/已派保安/现场核实）+输入框+「稍后处置/立即处置」。当用户以截图或既有组件为基准要求统一弹窗界面时，以用户指定样式为准，不要把本条的时间线/语义化按钮当作强制约束。
