右侧告警设备栏卡片已抽取为独立组件 DeviceCard.vue（位于 alarm-screen/components/），父页面 index.vue 通过 <DeviceCard :device :selected @select @action /> 引用。\n\n组件内部结构：\n- 标题栏（.dc-title-bar）：位于SVG顶部凹槽区域，含品牌名（.dc-brand）、标题（.dc-title）和告警角标（.dc-alarm-dot）\n- 卡片主体（.dc-body）：三栏布局（左侧操作按钮、中央服务器机柜图标 icon-server-rack.svg、右侧状态指示）\n- 状态指示：疑似火警用 icon-alarm.svg（橙色）、故障用 icon-electric.svg（黄色），图标+标签/数字纵向堆叠\n- Tab切换（.dc-tabs）：子设备/总线/远程控制\n- 元数据（.dc-meta）：名称、告警、地址三行\n\n卡片背景使用 alarm-host.svg（通过 background-image），样式在组件内 scoped。父页面仅保留 .device-card-list 3列网格容器。\n\nProps: device(对象)、selected(布尔)；Emits: select(device)、action(device, actionType)
