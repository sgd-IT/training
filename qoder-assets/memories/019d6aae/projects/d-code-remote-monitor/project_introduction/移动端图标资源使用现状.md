The mobile project anwei-fire-remote-monitor-mobile uses three icon integration methods: uni-icons component library (with built-in iconfont), custom iconfont (defined in static/customicons.css), and SVG static icons (19 files in static/ directory). However, uni-icons usage is low (only used in 2 pages: profile/index.vue and profile/device-list.vue), while SVG icons are the primary method for functional entry points and TabBar navigation.
