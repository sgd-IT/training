系统中的'值守中心'是一个独立的租户实体，在 system_tenant 表中由 id=1 唯一标识，其名称为'安为科技值守中心'。该租户是整个智慧消防值守平台的运营方，负责为所有联网企业提供 7x24 小时远程值守服务。
