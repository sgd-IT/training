项目视频监控功能分为两个独立页面：
- `/eiot/video/video-manage`：后台管理视频监控页（树形+网格）
- `/eiot/firewatch/video-surveillance`：值守大屏视频监控页（全屏大屏风格）
当前改造仅针对`/video-surveillance`页面，不涉及`/video-manage`及其他使用VideoPlayer的页面。
