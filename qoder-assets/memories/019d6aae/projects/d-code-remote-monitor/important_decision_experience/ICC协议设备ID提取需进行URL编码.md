## 决策场景
视频设备接入时解析设备编码（deviceId）

## 决策内容
设备编码取视频通道编码中第一个'$'符号之前的内容，并进行URL编码（如1000004@001$1$0$2 → 1000004%40001）

## 适用范围
所有基于ICC协议接入的视频设备，需从通道编码字符串中提取标准化设备ID
