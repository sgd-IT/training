## 决策场景
视频设备接入时解析通道号（channelId）

## 决策内容
通道号取视频通道编码中最后一个'$'符号之后的内容（如1000004$1$0$2 → 2），从0开始编号

## 适用范围
所有基于ICC协议接入的视频设备，需从通道编码字符串中提取标准化通道序号
