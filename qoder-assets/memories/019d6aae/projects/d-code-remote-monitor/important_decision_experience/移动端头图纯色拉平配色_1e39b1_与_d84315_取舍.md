Conclusion: 移动端头图配色采用"纯色拉平"方案——底色只用单一主题色 #1e39b1，状态/警示色只用纯色 #d84315，删除全部渐变、光斑光晕、霓虹投影、内高光与描边发光；色彩仅承担语义（火警红/品牌蓝/状态色），不承担装饰。

Rationale (trade-off): 红蓝配色本身被用户认可，被否决的是"多段亮蓝→深蓝渐变 + 右上角光晕 + 发光阴影"这类生成式设计痕迹。纯色方案牺牲了"卡片压盖头图的层次感"和渐变的视觉丰富度，换来与既有页面风格的一致性和"像真人开发者写的"观感；用户明确以"AI味"作为否定理由，说明一致性权重高于表现力。

Rejected alternatives: (1) 保留渐变仅收敛色阶——仍带多段过渡，未消除生成式痕迹；(2) 深色玻璃拟态+发光强调——视觉更"高级"但与项目内其他纯色页面割裂；(3) 首卡负边距压盖头图——层次更好但与头图内边距相互抵消导致实际间距远小于设计值，且用户反馈"太近"。

Applicable / expiry conditions: 适用于本项目消防监控端所有面向生产的第一屏/头图区域；判断口径是"颜色是否只表达语义"。若后续引入品牌视觉升级或专门的设计系统提供受控渐变令牌，则本决策需重新评估。不适用于纯演示/营销性质的独立提案页。
