结论：消控室值班员 fire_watcher（id=165，tenant_id=1）最终开放 48 条菜单/按钮。除 L1 基础能力外，业主明确要求开放 iot:device:ctrl（设备控制）与 iot:device:instruction:send（指令下发）、维保单位/计划/合同三项查询、hazard:query + hazard:create、data-center:query、duty-phone:query、call-record:query + call-record:voice。

理由与取舍：PRD-09 原本把远程设备操作划给 L2 值守主管，现场改为值班员直接操作；但只开按钮不开父级，前端菜单树没有入口，设备控制位于设备详情页远程控制 tab，还必须同时给 2814 设备中心、2827 设备管理、2828 iot:device-info:query 与 2931 设备详情隐藏路由，否则列表 403、详情 404。

仍不开放：duty:create/update/delete、patrol:create/update/delete、repair:update/assign/complete/close、property 与 video 的写操作、规则引擎与告警配置整棵树。

适用条件：仅租户 1 的该角色行；企业租户需各自建同 code 角色行，否则跨租户分配不生效。迁移脚本 _sql/mysql/V20261019__fire_watcher_permission_trim.sql 第 2 段收回、第 3 段回开，生产需单独执行。
