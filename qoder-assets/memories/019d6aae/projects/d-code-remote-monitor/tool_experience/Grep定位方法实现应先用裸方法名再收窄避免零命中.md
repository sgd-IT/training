## Usage Scenario
Description: 在已知目标文件内定位某个方法的实现体时，选择搜索正则的宽严程度。
Examples: 需要确认某 Service Impl 中删除方法是物理删除还是逻辑删除；需要找到某个私有/带注解修饰的方法定义。

## Usage Method
Grep: 定位方法实现时先用「裸方法名」作为关键字命中，再按结果收窄；不要一开始就把可见性修饰符、返回类型、参数列表一起写进正则。方法签名可能因返回类型不同、无 public 修饰、跨行换行或存在重载而使完整签名正则零命中，而方法名本身一定出现在调用点与定义处。

## Notes
- 用带返回类型和修饰符的完整签名正则搜索导致命中数为 0，误判为"该方法不存在"，必须先用裸方法名搜索确认存在后再收窄；命中后同一轮即可读出实现语义（如 deleteById 属逻辑删除）。
- 用 grep -n "deleteById" <file> 命中后，再用 grep -A10 -B2 "public.*deleteById" <file> 收窄到具体实现，可一次完成定位；若直接用后者搜索，会因方法定义跨行或无 public 修饰而零命中。
