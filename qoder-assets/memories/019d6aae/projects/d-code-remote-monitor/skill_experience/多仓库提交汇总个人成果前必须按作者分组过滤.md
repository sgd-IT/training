## 使用场景
按时间段（日报/周报/月报）汇总 git 提交、或把提交整理成个人履历素材时。

## 使用方法
1. 先跑 `git log --since=<范围> --pretty="%an|%ae|%ad %s"` 并按作者 Group-Object 统计，确认仓库是否多人协作；再决定是否过滤。
2. 只统计本人邮箱的提交（`--author="<邮箱>"`），合并提交（Merge）单独剔除，口径里写明"不含合并提交"。
3. 混合提交（同一功能两人各做一半）必须拆分归属，不能整条计入本人；同事负责的模块单独列一段说明"未计入"。

## 注意事项
未做作者过滤就汇总，会把同事的提交算成自己的成果，对外汇报一旦被追问"这块谁做的"就会失分；同事常常在同一个模块前后脚提交，仅看 commit message 无法判断归属，必须核对 %an。
