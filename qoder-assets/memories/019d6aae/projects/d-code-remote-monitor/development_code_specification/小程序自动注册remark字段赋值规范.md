小程序侧自动注册的账号（陌生手机号建号路径）落库时，AdminUserDO 的 remark 字段必须显式赋值为固定文案「小程序自动注册」（注意：不是「微信小程序自动注册」，测试库 system_users 中现存记录的 remark 实测即为「小程序自动注册」）。该字段用于在 Web 用户管理里区分人工建号与自动注册来源；平台管理员手工建号时 remark 可为业务说明（如 admin 用户为「管理员」）或留空。
