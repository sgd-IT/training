工作记录体系必须包含面向面试简历的专用素材，当前为两类载体（均在 d:\code\remote-monitor\work-log\，不进任何 git 仓库）：

1. 06-面试素材.md：每条工作压成可讲要点供取材。同一主题已有条目时不重复添加，只在原条目上补新事实。其排版与字段口径以 IMMUTABLE 记忆「工作内容记录使用 work-log skill 并落盘到 work-log 数据目录」为准（H2 + 引用行 + 7 个列表项，含追问与答案至少 2 组、答不上来的不写）。

2. 面试八股/：按 18 个分类归档知识题（01-Java基础、02-并发与多线程、03-JVM、04-Spring全家桶、05-数据库与SQL、06-Redis与缓存、07-ORM持久层、08-消息队列、09-微服务与分布式、10-系统设计与场景题、11-计算机网络、12-操作系统与Linux、13-数据结构与算法、14-设计模式、15-安全与认证、16-工程化与工具、17-AI工程化、18-项目经历复盘）。结构为顶层 00-索引.md + 每类一个 README.md；README 固定四段：【本类范围】【高频考点】【与项目经历的关联】【待补题目】，新题按 `## <题面> · <YYYY-MM-DD>` 追加，字段用 `### 【答案】/【追问】/【关联】`。

定位口径（三处必须一致：00-索引、06 开头定位句、05 技能清单排序）：后端为主 + AI Agent 工程师——后端是定价锚点与底座证据，AI Agent 为并列第二主线，前端只作"能独立交付"的加分。优先级：17-AI工程化 与 18-项目经历复盘 为 P0 主推；05/07/04/15/02 为 P0 基础；08-消息队列、09-微服务与分布式、16-工程化与工具 降为 P2，且这三类只答"选型否定题"（本项目为单体多模块 + 轮询/WebSocket，不硬吹 MQ 与微服务）。
