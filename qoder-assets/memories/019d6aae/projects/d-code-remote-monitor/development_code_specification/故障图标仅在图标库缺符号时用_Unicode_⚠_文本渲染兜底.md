故障/告警类图标的常规实现是内联 SVG（描边风格，见报警弹窗与 PC 火警处置中心的禁用 emoji 规范）。仅当图标库（如 uni-icons）确实缺少对应符号且不便引入 SVG 资源时，才允许用 Unicode 字符 '⚠'（U+26A0）做纯文本渲染兜底，此时须保持与周边图标同尺寸同色（黄色三角感叹号语义）。不得把该兜底方案当作新项目图标的首选实现方式。
