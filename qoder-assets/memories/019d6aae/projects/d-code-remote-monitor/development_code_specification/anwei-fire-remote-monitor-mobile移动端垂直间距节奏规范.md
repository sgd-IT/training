The mobile project anwei-fire-remote-monitor-mobile enforces a strict vertical spacing rhythm to ensure visual hierarchy and breathing room across all UI components: 120rpx (Logo to title), 88rpx (title to card), 44rpx (card padding), 36rpx (input to button), and 28rpx (input icon margin). New pages or components must align to these rpx values rather than introducing ad-hoc spacing.
