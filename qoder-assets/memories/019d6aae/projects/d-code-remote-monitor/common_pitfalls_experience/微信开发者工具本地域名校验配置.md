微信小程序开发者工具默认拦截对 localhost 和局域网 IP（如 192.168.x.x）的网络请求。即使 manifest.json 中已设置 "mp-weixin" → "setting" → "urlCheck": false，该配置仅对真机预览生效；开发者工具模拟器需单独在 GUI 中开启：点击右上角「详情」→「本地设置」→勾选 ✅「不校验合法域名、web-view (业务域名)、TLS 版本以及 HTTPS 证书」。（来源：微信开发者工具 UI 行为）
