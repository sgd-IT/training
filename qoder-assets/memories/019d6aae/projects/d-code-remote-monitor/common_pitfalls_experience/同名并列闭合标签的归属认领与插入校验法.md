Bug class: 在含多个同名闭合标签的模板里插入结构节点时插错归属位置，形成编译器永不报告的静默错误
Root cause: 列表页工具栏模板中相邻按钮各占一个 col 容器，收尾都是完全相同的 `</el-col>`，肉眼按"第几个闭合标签"计数极易把新节点插到前一个容器之后；本次插槽被插进"新增"按钮容器末尾，渲染结果跑到导出按钮左侧，语法合法、无报错、功能仍可用，只有看屏幕才能发现。
Fix pattern: 插入前先锚定"身份可辨识的邻居"——用块内独有内容（按钮文案变量名、v-if 条件表达式）确认这个闭合标签属于哪个块，再把新节点插在该块闭合之后并声明其下一行应为何内容；插入完成后从上往下通读一遍兄弟顺序，并跑一次运行时目视验证，不能只看报错面板。
Reusable lesson: Don't 靠数第 N 个闭合标签来决定插入点，因为同名标签在连续并列结构中不可区分、插错后没有任何编译或运行时报错；instead 用块内唯一标识内容认领归属，并把"出现在屏幕上的哪里"列为必查项。适用于向并列结构（工具栏按钮组、卡片列表、表单项序列）中插入新节点；不适用于目标位置有唯一 id / name 等可直接搜索定位的锚点场景。
