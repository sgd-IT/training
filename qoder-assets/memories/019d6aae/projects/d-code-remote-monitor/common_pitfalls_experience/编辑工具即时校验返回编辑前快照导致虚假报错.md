Bug class: 编辑工具的即时语法校验返回陈旧结果（false positive）

Root cause: SearchReplace 批量替换成功后附带的内联校验可能基于替换前的文件快照计算诊断，表现为"错误引用的 source code 已是修改后的新内容，但报错信息仍是修改前的旧问题"（例如已改成无值 `disabled`、`:rows="4"`，仍报 string 不能赋给 number）。这种自相矛盾说明诊断结果与当前文件状态不一致。

Fix pattern: 出现"错误文本与新内容矛盾"时不回滚、不重复修改同一处，改为独立再调用一次 GetProblems 取最新诊断；以复跑结果为准判断是否真的存在问题。

Reusable lesson: Don't 依据编辑工具随替换返回的即时校验就回滚或再次改写同一段代码，因为该校验可能是编辑前快照的陈旧结果，重复改写会把正确代码改坏；instead 复跑一次独立的诊断工具确认。适用于批量 SearchReplace 后收到与当前文件内容自相矛盾的报错；不适用于诊断结果明确引用旧文本且文件确实未变更的情形（那属于替换未生效，需检查匹配是否命中）。
