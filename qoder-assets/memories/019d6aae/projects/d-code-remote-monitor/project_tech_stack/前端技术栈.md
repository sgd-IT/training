PC 管理台（anwei-fire-remote-monitor-vue）前端技术栈，经 package.json 与 src/config/axios/service.ts 核实：Vue 3.5.12 + Vite 5.1.4 + TypeScript 5.3.3 + Element Plus 2.9.1（组件库与 ElMessage 等提示）+ Pinia 2.1.7，pnpm 管理。并非 Ant Design 组件生态：代码中的 icon="ant-design:xxx" 只是 Iconify 图标集名称（如 ant-design:upload-outlined），做架构判断时不能当作 Ant Design。SVG 资源统一存放于 /src/assets/svg/。
