移动端反控码入口必须同时存在于两个位置：一是在「我的」页菜单（作为低频查看类操作的标准归口），二是在「消防运行」首页宫格（作为高频工作台的快捷入口）。在首页宫格中，需将原有的「巡检任务」入口直接替换为「反控码」。
