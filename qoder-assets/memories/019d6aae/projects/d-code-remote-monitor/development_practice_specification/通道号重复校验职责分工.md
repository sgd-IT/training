通道号重复校验应在后端服务层通过数据库查询实现，前端不进行本地列表查重，仅捕获并展示后端返回的校验错误信息。判断该分工是否为项目长期惯例时，应查看相关提交历史、同类接口实现和现行接口契约；若历史代码曾在前端本地查重，也应视为待修正的旧模式，而不是默认沿用依据。

## 补充说明
- 数据库表 `video_camera` 上已确认存在唯一索引 `uk_device_channel_id_tenant`，其字段组合为 `(tenant_id, device_id, channel_id)`，这是后端校验的物理基础。
