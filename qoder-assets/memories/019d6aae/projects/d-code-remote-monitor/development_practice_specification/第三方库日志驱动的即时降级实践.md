在集成第三方播放库（如dhflv.min.js）时，若其内部通过console.log输出关键错误（如'CodecUnsupported'）且不抛出可监听事件，应主动拦截该日志，在日志出现瞬间立即执行降级逻辑，赶在UI错误覆盖层渲染前完成切换。
