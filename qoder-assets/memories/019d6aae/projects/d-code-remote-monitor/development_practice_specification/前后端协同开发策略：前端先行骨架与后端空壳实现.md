后端开发采用分阶段空壳策略：先创建Controller、Service接口及其实现类、VO等骨架代码，所有方法体返回空集合或null，暂不实现Mapper和具体业务逻辑；前端同步实现完整页面，优先复用项目中已有的库（如ECharts、HUD样式组件）和代码结构。

## Notes
- 联调验证是该策略不可省略的收尾环节：后端接口改动完成后必须连接 PC 前端与移动端 APP 做端到端联调测试，仅做编译/单测/Swagger 接口自测不视为任务完成。此约束源于用户明确反问式纠正（"你不用连接前端和移动端测试吗"）。跨端联调前需分别确认各端接口基址指向同一后端实例（PC 与移动端基址可能不同），基址不一致会导致某一端看似无反应的假失败。
