anwei-fire-remote-monitor-vue 仓库执行 vue-tsc --noEmit 全量检查会报出大量存量类型错误（bpmnProcessDesigner、DiyEditor、infra demo、Login、system 等历史模块遍布，100 个文件以上量级；最近一次推送前实测输出 474 行、退出码 1），仓库历来不以此为提交/推送门禁。

验证口径：把全量输出落盘到 logs 下日志文件后按本次改动文件路径过滤，仅当改动文件出现高危错误（属性不存在、类型不兼容等非既有宽松模式）才阻塞；TS6133「未使用声明」为低危噪声可放行。判据是「与历史基线同文件同错比对、确认无新增」，而非错误总数或退出码。

补充：故意注释/停用某功能块（如关闭 3D 模型）后其回调函数变为 TS6133 未引用，属改动的预期结果，不算新增缺陷，无需为此恢复代码或制造空引用。
