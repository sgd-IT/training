hand-typing-training skill 的出题训练模板中，"可参考"字段不允许只给文件路径，必须在其下紧跟一行"为什么参考它"，用一句话指明打开参考文件后应重点看的方法或逻辑片段。

模板形态：
- 可参考：<项目里可参照的现有文件路径，只给路径不贴代码>
- 为什么参考它：<一句提示看什么，如"看它的 handleSearch 怎么组装请求参数">

理由：学员（前端零基础档）拿到裸路径不知道看什么，一句指向能把参考行为收敛到具体方法/逻辑，避免整文件通读。出题时该提示必须指向与本题手敲内容同类的实现点（如同样是请求参数组装、同样是插槽声明），而非泛泛的"参考写法"。
