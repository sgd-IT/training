Before executing any plan, one must first survey the existing framework capabilities (e.g., Spring Boot starters, exposed APIs/Services) and existing database tables (structure, field evolution, data debt, reserved fields). Based on this survey, decide the plan, prioritizing reuse and avoiding unnecessary new tables or columns.
