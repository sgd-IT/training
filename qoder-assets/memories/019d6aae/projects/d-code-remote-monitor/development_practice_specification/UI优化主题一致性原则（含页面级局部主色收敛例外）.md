UI组件优化需优先保持现有主题一致性，禁止为追求视觉统一而擅自变更全局主题色系；仅允许在当前主题下进行布局结构调整、动效增强、交互细节完善等非主题性优化。

例外（以用户明确口径为准）：当用户明确要求去 AI 味/禁用彩虹配色时，允许在单个页面作用域内做局部主色收敛——把 Element Plus 的 --el-color-primary 全套明暗变体在该页根节点覆盖为页面既定主题色；因 dialog/drawer/MessageBox 会被 teleport 到 body，须给弹层挂同名专用类并用非 scoped 全局样式块补一份同套变量（命令式调用用 customClass 传同名类），否则弹层内部仍显示组件库默认蓝。该例外不得改动其他页面的全局 primary；执行前须先确认该页既有主题色定义与语义保留项（火警/紧急红色等）。
