用户（全栈工程师）使用 work-log skill 持续记录工作内容与经验，用于工作总结、踩坑沉淀和简历/面试素材。skill 为用户级、位于 C:\Users\Administrator\.qoder\skills\work-log\（含 SKILL.md、reference.md、examples.md，所有项目可用）。数据统一落盘于 d:\code\remote-monitor\work-log\：00-履历总表.md（索引）、01-项目/（详细记录，含 消防告警分级响应系统.md、消防远程值守系统.md、烟花仓库安全监测系统.md）、02-专题/、03-踩坑手册.md、04-简历素材池.md、05-技能清单.md、06-面试素材.md。触发场景：记录工作内容、写工作日志、总结时间段工作、整理踩坑经验、检索过往记录（模式 E）、整理面试素材、提炼简历素材、更新技能清单；日期用 YYYY-MM-DD。层级规范（2026-10-19 定版）：文件首行 H1、记录 H2（`## <模块> · <日期>`）、标题下 `> 项目：`、字段 H3（`### 【类型】`），块间不空行，H1 仅文件标题。技术沉淀偏好（2026-10-19 用户明确）：记录与提炼技术深度优先于业务描述，优先级为 物联网设备对接（协议帧/在线状态/上报周期/平台回调）> 并发与多线程（竞态/CAS/线程模型/幂等）> 设计模式（策略/工厂/门面/注册表/规则链）> 逻辑设计（算法/状态机/口径同源/边界）；01 的【方案】至少写清一项。06 面试素材为 H2 + 引用行 + 7 个列表项：技术维度、场景与规模、我做了什么、难点与解决、结果、追问与答案（至少 2 组，答不上来的不写）、技能。
