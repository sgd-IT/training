在数据中心可视化设计中，每个数据模块必须使用互不相同的ECharts图表类型，避免重复（如柱状图、饼图系、折线图系内部均视为同类），确保14个数据模块对应14种独立图表形态（Number Card等纯CSS组件除外）。

在数据中心页面中，每个业务数据维度仅允许使用一种图表类型进行可视化展示，禁止同一数据重复使用不同图表类型渲染。
