权限放开类需求在本项目的落地口径（前端 + 后端两端同步，不残留单侧限制）：
- 后端接口：取消方法级权限注解（如 @PreAuthorize("@ss.hasPermission(...)")），改为仅要求已登录即可访问；是否保留平台位/角色门禁需当轮确认。
- 前端页面元素：按钮等元素保持对所有具备该功能权限的账号可见，不用隐藏/收缩可见性来表达业务限制；放行范围在实际修改动作处校验（后端方法内 + 前端 submitForm 同步拦截，两处口径一致）。
- 校验失败时给明确提示文案，而非静默不可点。
边界：本条是"放开限制"的执行方式约定，不等于安全策略永久关闭；涉及匿名访问（免登录）仍需单独授权，不得顺带移除认证要求。
