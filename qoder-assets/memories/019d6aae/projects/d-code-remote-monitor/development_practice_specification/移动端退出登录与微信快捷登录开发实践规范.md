移动端“我的”页面需添加带确认弹窗的红色警示色退出登录按钮；登录页需为微信快捷登录按钮添加loading态防止重复点击；前端需清除token、refreshToken、userId、tenantId等认证信息；微信授权需区分用户拒绝与网络异常；tenantId必须在登录成功后持久化存储。

## Notes
- 登录页后续改造已调整：「手机号快捷登录」按钮文案改为「获取当前手机号」（功能不变，仍走 getPhoneNumber 授权回填账号框），防重复点击实现为 disabled 禁用态而非 loading 态；「忘记密码?」入口及方法已从登录页整体删除。规范中关于登录页的两条描述请以本次改动后的现状为准。
