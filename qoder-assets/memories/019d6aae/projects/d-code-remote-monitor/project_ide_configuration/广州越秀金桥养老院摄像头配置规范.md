生产库（anwei-fire-remote-monitor-prod）video_camera 实测现状：租户"广州越秀金桥养老院"（tenant_id=178）共 8 条摄像头记录，其中 id=40~44 这 5 条为值班室通道，device_id 均为 1000032，channel_id 依次为 "0"、"1"、"2"、"3"、"4"（注意是单字符值，不是 ICC 四段式格式），pull_type=1，quality 除 id=41 为 "1" 外均为 "2"，deleted=0。channel_name 实际为"值班室中间左""安为值班室中间右""安为值班室前右""安为值班室后方右""值班室后方左"——部分带"安为"前缀，命名并不统一。

因此准确口径是：这是当前生产库已有的数据快照，而非新增强制配置规范。新增同租户摄像头时沿用 device_id=1000032 + 递增 channel_id 即可；若要让小程序消控室监控页筛出这些设备，不能只依赖 channel_name 包含"值班室"（现网存在带前缀与不带前缀两种写法），应以 device_id + tenant_id 为准做筛选。另需注意：测试库（192.168.250.160:3306 anwei_fire_remote_monitor）的 system_tenant 只有 id=1 和 166，不存在 178，同步这批数据前必须先补租户，否则按租户隔离查询不可见。
