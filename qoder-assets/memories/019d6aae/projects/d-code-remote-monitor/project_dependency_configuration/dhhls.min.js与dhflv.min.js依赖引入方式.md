项目集成大华定制播放器：
- dhflv.min.js: FLV播放器，支持H.264/H.265解码，存放于public/static/，index.html通过script标签引入，前端通过window.dhflvjs全局变量访问
- dhhls.min.js: HLS播放器，存放于public/static/，index.html通过script标签引入，前端通过window.HlsLib全局变量访问
- HLS播放器初始化流程：attachMedia → MEDIA_ATTACHED事件 → loadSource → MANIFEST_PARSED事件 → play
- 使用new HlsLib()无参构造，不传自定义配置
- 环境判断应使用import.meta.env.DEV（Vite项目不支持process.env.NODE_ENV）
