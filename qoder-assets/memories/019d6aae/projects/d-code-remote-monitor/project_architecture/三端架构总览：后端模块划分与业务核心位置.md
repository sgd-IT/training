智慧消防远程监控系统三端：后端 anwei-fire-remote-monitor（Spring Boot 3.4.1/Java 21，Maven 多模块：framework（common + 14 个 starter）、server 唯一启动类 ServerApplication（端口 48080，dev/prod 同端口）、module-system 认证/菜单/租户、module-infra 文件/任务/日志、module-eiot 业务核心（biz/iot-components/core/temporal/api/task 六个子模块）、module-ai 聊天/算法）；PC 管理台 anwei-fire-remote-monitor-vue（Vue3+Element Plus，页面集中在 src/views/eiot，接口走 /admin-api）；移动端 anwei-fire-remote-monitor-mobile（uni-app，10 个页面，dev 指向 192.168.250.130:48080/admin-api）。业务核心 module-eiot 的 controller/admin 按 24 个域分包，其中 firewatch 域承载消防主业务（告警工单/值守/巡检/维保/物业等 17 个 Controller）。跨端契约见 vue 仓 ARCHITECTURE.md 与 SYSTEM_INTEGRATION.md；需求/设计/库表文档在 backend 仓 doc/md/ 下。工作区根下 anwei-fire-monitor 为无文件的空目录残留。项目地图与速查索引已落盘于后端仓 docs/项目地图.md 与 docs/速查索引.md（2026-10-10 建立，保持未提交；后续"更新项目地图/刷新地图"先读这两份文件）。

## Notes
- 【module-eiot 六子模块均有真实代码，非空壳】2026-10-10 逐个统计 *.java 文件数核实：module-eiot-biz 569（controller/admin 24 域 + service 20 域 + dal，业务主战场）、iot-components 229（coap 等协议接入组件库）、module-eiot-core 123（常量/枚举/CodecUtil 编解码工具）、module-eiot-temporal 121（设备属性/规则日志/物模型消息写入 TDengine 的时序接口层）、module-eiot-api 55（跨模块 Api 接口）、module-eiot-task 9（定时任务）。
- 【包根不统一，检索时勿套用同一前缀】biz/api 用 com.enjoyiot.module.eiot.*，而 module-eiot-core 用 com.enjoyiot.eiot.common.*、module-eiot-task 用 com.enjoyiot.eiot.task.*；按 com.enjoyiot.module.eiot 通配搜索会漏掉 core 与 task 的代码。
- 【易误判为空壳的原因】Get-ChildItem -Directory -Recurse -Name 对部分子模块返回空输出，据此判断"无源码"是错的；应改用统计 *.java 文件数后再下结论。
