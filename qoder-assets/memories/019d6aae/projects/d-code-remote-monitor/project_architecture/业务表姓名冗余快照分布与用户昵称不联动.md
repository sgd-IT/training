system_users.nickname 被多张业务表以文本快照形式冗余存储，修改用户昵称不会自动传导到这些表，账号改名类需求必须逐表核对存量。经实测确认存在姓名列的表及字段：fire_duty_schedule.duty_user_id/duty_user_name（值班人）、fire_patrol_task.patrol_user_id/patrol_user_name（巡检人）、fire_patrol_record.patrol_person_id/patrol_user_name/patrol_person（巡检记录）、fire_handover_record.outgoing_person/incoming_person（交接班）、fire_repair_order.assignee/repair_person（维修单）、fire_alarm_order.handler（告警处理人）、eiot_duty_phone.name（座机名称）。另 oauth2_access_token.user_info 为 JSON 列，内含 nickname 快照，历史令牌过期或删除后由新登录刷新覆盖，一般无需订正。定位方式：一条 UNION ALL 计数 SQL 对候选列做等值匹配即可全量扫描；fire_duty_log.log_content、fire_sms_record.content 属历史内容记录，通常不改写。
