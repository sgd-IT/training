在多租户消防监控系统中，系统租户（tenant_id=1）账号在移动端查看数据时遵循以下可见性规则：
- 当分配「小程序用户」（wx_user）角色时，该账号可查看所有租户（包括 tenant 166 的 31207 条告警）的 firewatch 模块数据。
- 当分配「监管角色」（monitor_role）时，该账号的数据可见范围会受到其个人资料中 area_code 字段的限制（例如 test 账号 area_code="440000"），仅能查看该区域（如广东省）内租户的数据。
- 此规则由 TenantAreaTenantIdDataPermissionRule 实现，是系统架构的重要组成部分。
