TenantUtils.execute是项目的多租户契约，通过保存/设置/执行/恢复四步模式确保租户上下文隔离。FireDutyScheduleService核心方法标注@TenantIgnore注解，绕过默认tenant_id过滤，保证跨租户排班统计等关键流程正确性；所有调用必须经tenantAware()包装器执行。AdminUserService.getUserListByAccountIgnoreTenant是显式绕过租户插件自动过滤的参考方法，适用于跨租户查询或系统级操作。
