duty-screen、monitoring-center、remote-console 三端轮询未处置告警（/alert/recentUnprocessedAlerts、/alert/unprocessedAlertsByDevices）的默认时间窗口由"近5分钟"改为"当天0点起"，实现于 firewatch.api.ts 的 minutesSinceDayStart()，调用处不再显式传参。目的：服务重启/页面刷新后仍能恢复当天待处置提示（原5分钟窗口导致超过5分钟未处置的告警永久从大屏消失，即使库里仍是未处置状态）。约束：跨天不回捞，避免历史数据债（全库曾达3万条未处置）涌入大屏；当天未处置的一级告警会重新进入全屏弹窗队列；通知匣条目合并窗口5分钟、上限50条。后端无改动，minutes 参数仍可显式覆盖。页面内存态去重有两条独立机制：通知匣（二三级）用 alertShownIds 只推一次；一级弹窗用 heavyAlertLastShownAt + isHeavyRepeatDue，未处置的每 HEAVY_REMINDER_INTERVAL（60秒）重新入队弹出直到处置，duty-screen 与 monitoring-center 同构实现。
