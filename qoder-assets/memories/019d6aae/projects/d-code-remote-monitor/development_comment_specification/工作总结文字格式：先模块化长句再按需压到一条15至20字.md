工作总结分四档递进：第一轮按"模块名：主要动作 + 核心改动、关键细节、前后端与多端联动"一条一事长句展开，修复类写"现象→方案→效果"；第二轮去掉铺垫与提交号；第三轮压到 15–20 字，只留"模块：主干改动"，一行一条、不加编号与表格；第四轮是周报定稿（给老板和同事看）：用"通俗分类名：大白话说明，结果句"，术语全部换成业务说法，目标是外行也能看懂一半，每条必须补一句这次改动带来的结果，结果按"谁受益 / 风险降在哪 / 成本省多少"之一落，且必须能对回提交或实测数据，不写"更流畅、体验更好"这类空话；跨端细节与量化指标在精简档删除，需要时另出详版。
