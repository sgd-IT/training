## Task description
- Core requirement: 为移动端告警中心页面（index.vue）的两行筛选标签（告警类型/告警状态）实现滑动椭圆高亮效果
- Task background: 告警中心是消防远程监控系统的核心功能模块；用户提供了参考HTML代码，要求将其中的滑动椭圆高亮导航效果应用到告警中心的.chips容器上；该效果需支持点击切换、弹性缓动、安全区适配，并与现有主题色统一

## Execution process
1. 模板重构：移除原有的scroll-view包裹，改为普通view容器（5个chip在移动端不会溢出），并在每行.chips容器内添加一个绝对定位的.hl高亮块
2. 样式实现：.hl高亮块应用cubic-bezier(0.34, 1.2, 0.4, 1)弹性缓动、半透明背景var(--brand-100)、内描边和外阴影；.chips容器应用毛玻璃效果和胶囊外形
3. 交互逻辑：通过onTypeClick/onStatusClick方法触发，$nextTick后调用moveHl()函数，使用transform: translateX()和width属性平滑过渡到新选中chip的位置
4. 首屏初始化：通过initHl()函数在页面加载时无动画定位到默认选中项
