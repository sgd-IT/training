## Notes
- 用户语义歧义教训："X 直接不会再弹出来"既可能是 bug 报告也可能是期望陈述，先用记忆/代码确认现状口径再判断方向；本轮靠既有实测记忆（稍后处置约 2 分钟后照弹）确认这是新期望。
- git apply --cached 的局部 patch 必须保持 LF 行尾且内容逐字取自 git diff 导出（PowerShell 管道 Out-String 会破坏中文与空白）；--ignore-whitespace 能掩盖校验失败但会把错误行尾带进 index，造成全文件假差异——校验通过不等于安全，commit 前必须看 diff --cached --stat 的行数量级是否符合预期。
- core.autocrlf=true 仓库中，工作区 CRLF、blob LF，任何手写补丁都要按 blob（LF）侧对齐。
