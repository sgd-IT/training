视频监控页面(video-surveillance/index.vue)从单liveUrl模式改造为多流并发模式：
1. 用reactive Record<string, StreamState>（cameraStreams Map）替代旧的单个liveUrl/loadingUrl/videoError
2. getStream(id)函数惰性初始化每个摄像头的流状态
3. 模板中每个格子通过getStream(slot.id)独立绑定VideoPlayer，不再依赖selectedCameraId
4. selectCamera仅切换高亮框，不触发拉流
5. loadAllStreams()遍历gridSlots并发拉取所有在线摄像头流
6. 布局切换(layoutMode)使用lodash-es debounce 300ms防抖，避免频繁切换时重复请求
7. onMounted中await loadCameras()后立即loadAllStreams()实现页面加载即全部播放
