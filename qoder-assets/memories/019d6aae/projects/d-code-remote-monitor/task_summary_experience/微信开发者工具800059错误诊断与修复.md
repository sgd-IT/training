## Task description
- Core requirement: diagnose and fix the WeChat DevTools error "800059: app.js file not found"
- Task background: user opened the uni-app project root directory in DevTools, but the actual app.js resides only in compiled output directories (unpackage/dist/dev/mp-weixin/ and unpackage/dist/build/mp-weixin/); the root project.config.json lacked miniprogramRoot configuration, causing DevTools to search for app.js at the wrong location

## Execution process
1. Verified existence of app.js in both unpackage/dist/dev/mp-weixin/ and unpackage/dist/build/mp-weixin/ directories
2. Confirmed absence of app.js at the project root directory
3. Read root project.config.json and confirmed missing miniprogramRoot field
4. Added miniprogramRoot: "unpackage/dist/dev/mp-weixin/" to root project.config.json
5. Verified existence and validity of app.json in unpackage/dist/dev/mp-weixin/ (547 bytes, valid JSON)
6. Identified the root cause of the second error ("app.json not found") as DevTools cache — after changing miniprogramRoot, the tool must be closed and re-imported to re-resolve the path
7. Advised user to close the project in DevTools and re-import the root directory

## Related files
- d:\code\remote-monitor\anwei-fire-remote-monitor-mobile\project.config.json

## Notes
- The error is caused by DevTools' internal caching mechanism: after modifying miniprogramRoot in an already-open project, it does not re-resolve the path; closing and re-importing is mandatory to trigger re-resolution.

## Notes
- 【更正 2026-10】本条记录的处方（在根目录 project.config.json 添加 miniprogramRoot）已被后续任务证伪并回滚：HBuilderX 会把根目录配置同步进编译产物，产物内出现 miniprogramRoot 后开发者工具会再向下钻一层找 app.json，引发「在该目录下未找到 app.json」错误。正确做法：根目录永远不加 miniprogramRoot；出现 800059 "app.js file not found" 时，直接用微信开发者工具打开编译产物目录（上传发布用 unpackage/dist/build/mp-weixin，预览调试用 dev 目录），而非源码根目录。
