## Task description
- Core requirement: 用户先排查摄像头设备 parent_id=7 的来源，继而要求把 device_type（设备类型）字段加入前端"新增设备"弹窗，使新增时可一步选定设备类型。
- Task background: eiot_device_info 的 device_type 此前只能进设备详情页 detail.vue 编辑后设置（且下拉仅 6 个选项，少于数据库注释口径）；新增/编辑弹窗 DeviceInfoForm.vue 完全没有该字段，前端新增的设备 device_type 恒为 NULL。

## Execution process
1. Grep 后端 setParentId/parentId，定位 DeviceInfoServiceImpl.java 两处写入点：L451 协议注册时 deviceInfo.setParentId(registerDevice.getParentId()) 自动带入；L319-321 批量创建子设备时按传入 parentId 参数设置。据此解释摄像头 parent_id=7（挂在先注册的 transfer 网关下），这也是 findTransferDeviceId 沿父链跳远程控制页的前提。
2. DeviceInfoForm.vue：在「机构id」与「设备状态」之间新增「设备类型」el-select，formData 增加 deviceType 字段，10 个选项（transfer/camera/smoke/temperature/temp_humidity/door_magnet/gas/hydrant/manual/other），支持 clearable。
3. detail.vue：设备类型下拉从 6 项补全到 10 项，与新增表单及数据库注释对齐；文案统一（「用传」→「用传设备」、「门磁传感器」→「门磁」）。
4. 验证：vue-tsc --noEmit 过滤两个改动文件，零新增错误（ExitCode 1 为仓库既有基线错误）。
