## 任务描述
对工作台页面进行功能合并与结构重构，解决语义重叠问题（如值班管理/值班记录、告警工单/告警记录等），将24个入口精简为20个，并统一为模块化数据驱动结构。

## 执行过程
```mermaid
graph TD
    A[需求:功能合并与结构优化] --> B[创建4个SVG图标文件]
    B --> C[更新index.vue中值班/告警/消息的SVG引用]
    C --> D[修复告警大屏SVG清空导致的回退显示]
    D --> E[读取index.vue原始结构定位修改点]
    E --> F[将6组硬编码模块重构为1个modules数组]
    F --> G[按新分组逻辑填充items：大屏看板/值守管理/告警中心/日常管理/设备运维/系统工具]
    G --> H[模板层改为通用v-for="mod in modules"渲染]
```

## 任务总结
成功完成工作台重构：1）新增4个SVG图标（值班管理/告警工单/告警记录/消息中心）；2）修复告警大屏emoji回退；3）将index.vue中6个独立列表（screenList/dutyList/...）合并为统一modules数组，模板由6段重复代码简化为1段通用循环；4）功能入口从24个精简为20个，消除语义冗余。
