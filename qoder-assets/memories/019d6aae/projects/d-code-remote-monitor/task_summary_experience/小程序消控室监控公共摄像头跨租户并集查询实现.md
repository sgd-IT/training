## Task description
- Core requirement: 小程序消控室监控页需让每个租户都能看到"公共摄像头"（值守中心自身租户 166 下的所有摄像头），再叠加本租户自己的摄像头；管理员看到全部。
- Task background: 上一轮曾按设备编码（1000032）识别公共摄像头并新建 VideoConstants，但改动被回滚（VideoConstants.java 消失、getAppPage/取流兜底丢失，文件在 17:36 被外部还原）。本轮改按"租户"口径重新实现，不加字段、不新增类。

## Execution process
1. VideoCameraService.java：定义常量 PUBLIC_CAMERA_TENANT_ID = 166，新增 getAppPage 方法声明。识别口径从"设备编码"改为"租户"——166 以后新增任何摄像头自动成为公共，无需再改代码。
2. VideoCameraServiceImpl.java：实现 getAppPage —— 先取本租户可见列表，再用 TenantUtils.executeIgnoreWithResult 跨租户补查 tenantId=166 的记录，合并后按 deviceId#channelId 去重（优先保留 166 公共记录），最后内存分页。
3. AppVideoCameraController.java：列表接口改走 getAppPage；getLiveUrl 补跨租户兜底——普通租户 getById 拿不到时，用 executeIgnoreWithResult 重取，仅当 shared.tenantId==PUBLIC_CAMERA_TENANT_ID 才放行，避免越权拿到别的企业摄像头。
4. 编译验证：mvn -o -pl module-eiot/module-eiot-biz -am -DskipTests compile 通过。
5. 生产库只读模拟：166 有 5 路(1000032 ch0-4)、178 有 5 副本+1 自有(1000047)；去重后各角色收敛为预期数量。
6. 数据权限取证：TenantAreaTenantIdDataPermissionRule 第 81-85 行 if(TenantContextHolder.isIgnore()) return null，确认 executeIgnoreWithResult 忽略租户过滤时数据权限规则同样放行，跨租户补查不会被二次拦截。
