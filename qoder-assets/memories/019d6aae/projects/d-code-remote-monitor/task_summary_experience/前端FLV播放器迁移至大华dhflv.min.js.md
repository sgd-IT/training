## 任务描述
将前端视频播放器从标准 flv.js 迁移为大华 dhflv.min.js，以支持 H.265 编码解码。

## 执行过程
```mermaid
graph TD
    A[需求:支持H.265拉流] --> B[定位现有flv.js使用点]
    B --> C[Grep确认flv.js仅在VideoPlayer.vue和package.json中引用]
    C --> D[确认dhflv.min.js未在项目中存在]
    D --> E[修改index.html引入/static/dhflv.min.js]
    E --> F[重构VideoPlayer.vue：移除import、声明全局dhflvjs、封装getDhflvjs容错]
    F --> G[替换createPlayer调用与error事件监听为dhflvjs兼容API]
    G --> H[增强destroyPlayer异常捕获、统一日志前缀为[dhflv]]
```

## 任务总结
成功完成播放器SDK迁移：index.html 新增 script 引入，VideoPlayer.vue 彻底解耦 npm 包依赖，通过全局变量调用 dhflvjs，支持 H.264/H.265 双编码，错误提示更通用，销毁逻辑更健壮。
