## Task description
- Core requirement: PC 处置中心"告警详情"弹窗太窄，需改成标准宽版弹窗（上下短一些、左右宽一些）
- Task background: src/views/eiot/firewatch/alarm-order/index.vue 内该弹窗原为 width=600px + el-descriptions :column=2，窄宽度导致 label 列中文逐字竖排、内容被拉得极长近乎顶满屏幕

## Execution process
1. alarm-order/index.vue 模板：el-dialog width 600px→900px，新增专用类名 alarm-detail-dialog
2. el-descriptions：:column 2→3，加 label-width="84px" 根治标签竖排；告警描述/处理备注/告警标签三条长文本项 :span 2→3
3. 二次修正对齐瑕疵：首轮实测发现"告警描述"的 span=3 落在未满行上被 Element 截断成单列挤在右侧，给"告警设备"补 :span="2" 使后续整行项从行首开始
4. 非 scoped 样式块新增 .alarm-detail-dialog { --el-dialog-margin-top: 8vh } 与 body max-height: 62vh + overflow-y auto 控制高度；先核实 element-plus 版本 2.9.1 支持该 CSS 变量（变量级联不受 CSS 加载顺序影响，优于直接覆写 margin-top）
5. Browser 子代理两轮实测（dev server 3000 端口 vite）：最终宽 900、3 列标签全横排、高度占视口约 45%、告警描述值单元格 783px 整行铺开

## Notes
- Element Plus descriptions 的 item span 超过当行剩余列数时会被截断，整行项必须确保前面正好填满整行，否则不生效
- el-dialog 顶部位置用 --el-dialog-margin-top 变量控制比覆写 margin-top 更稳（规避 CSS 加载顺序问题）
- 附带发现的交互事实（未改）：点击告警卡片仅选中不弹详情，详情只能经卡片内"告警详情"按钮打开
