## Task description
- Core requirement: identify all "无功能" (unimplemented) API interfaces in the system and mark them as "开发中" in the frontend with consistent visual styling.
- Task background: FireDataCenterServiceImpl.java contains 15 endpoints that return empty collections/objects; frontend data-center pages fall back to mock.ts without user indication; other pages like ops-workbench and large-screen also show mock/fake data without clear labeling.

## Execution process
1. Identified FireDataCenterServiceImpl.java as the only backend module with fully stubbed endpoints (/eiot/firewatch/data-center/*)
2. Created src/components/DevelopingTag/index.vue: a reusable warning-colored tag component for "开发中" notices
3. Added DevelopingTag to data-center/index.vue title bar and inserted a descriptive strip below the tab bar
4. Added DevelopingTag to duty-screen/index.vue and alarm-screen/index.vue dropdown menu items for "数据中心" and "运维工作台"
5. Added DevelopingTag to large-screen/index.vue title bar with a tip about demo data
6. Added DevelopingTag to ops-workbench/index.vue placeholder header to unify the notice style
7. Updated FireDataCenterController.java Swagger @Tag description and javadoc to explicitly state "开发中：接口均为空壳占位"
8. Updated data-center/mock.ts header comment to link the mock data to the visible "开发中" notice
