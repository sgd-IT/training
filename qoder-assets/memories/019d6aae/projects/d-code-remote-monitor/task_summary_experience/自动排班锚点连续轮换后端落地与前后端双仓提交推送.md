## Notes
- 中途误判：git log / git status 经 PowerShell 管道回显中文全是乱码，一度得出"提交对象里存的是乱码"的错误结论。真实原因是控制台按 GBK 解释 UTF-8 字节，Write 工具写出的文件和 git 对象本身都是正确 UTF-8。判据是输出 hex（纯 ASCII 不受编码影响）或 Node 侧 Buffer 比对，而不是看终端回显。
- i18n.logOutputEncoding 与 i18n.commitEncoding 均未配置，可用来快速排除"git 主动转码"这一假设。
- git push 成功时 PowerShell 会把 git 的 stderr 进度信息报成 NativeCommandError，需以 "旧sha..新sha master -> master" 和 status -sb 无 ahead/behind 为准判定推送结果。
- 跨月连排同一人的隐患靠"锚点日期 + N 天"全局推算消除，而非按单月内 day-of-month 取模；注释中已固化该坑位预警。
