## Task description
- Core requirement: 落实李皇需求两项——①大屏(duty-screen)与监控中心(monitoring-center)实时告警列表项显示项目名称并置于摘要最前；②大屏右上角「功能菜单」九宫格按钮移到按钮排第一个位置
- Task background: 后端 FireDashboardServiceImpl.convertToRespVO 已通过 tenantApi.getTenantName 填充每条实时告警的 tenantName，duty-screen 弹窗与 monitoring-center 数据映射均已在使用该字段，仅列表项模板未渲染；duty-screen 右上角按钮排原顺序为 地图→功能菜单→设置→面板开关→全屏→用户

## Execution process
1. 链路盘点确认零后端改动：convertToRespVO 已 setTenantName；duty-screen alarmList 来自 /dashboard/statistics 的 realtimeAlarms（兜底 /dashboard/realtime-alarms），monitoring-center 已在 map 中显式保留 a.tenantName，WebSocket 推送项同样带 tenantName
2. duty-screen/index.vue 列表项：alarm-desc 行内前置 `<span class="alarm-tenant" v-if="alarm.tenantName">{{ alarm.tenantName }}</span>`，与摘要同行；样式在 .alarm-body 内新增 .alarm-tenant（color: $cyan、font-weight: 600、margin-right: 6px）
3. monitoring-center/index.vue 列表项：ai-desc 行内同构改动 `<span class="ai-tenant" v-if="a.tenantName">`；样式在 .ai-body 内新增 .ai-tenant（color: $accent）；注意 .ai-desc 有 nowrap+ellipsis，项目名前置会让摘要更早截断
4. duty-screen/index.vue header-right：将 Grid 功能菜单 el-dropdown 整块（含下拉菜单内容一字未动）移到 Map 地图按钮之前，最终顺序 功能菜单→地图→设置→面板开关→全屏→用户；.header-right > * 用 first-child margin 归零，换序无需改样式
5. 排查确认范围边界：alarm-screen 的功能菜单按钮本就是第一位无需改；监控中心/large-screen 无此按钮；移动端无大屏页面，均不在范围内
6. 验证：GetProblems 仅存量警告（background-clip、未使用变量），无新增错误；改动均未 git 提交，等用户确认
