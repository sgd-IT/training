## Task description
- Core requirement: 完善移动端“我的”页面的退出登录与重新授权登录功能
- Task background: profile/index.vue 页面需添加退出按钮并实现逻辑；login/index.vue 页面需优化微信手机号快捷登录流程；涉及 token 清除、微信授权处理、tenantId 存储等关键认证环节

## Execution process
1. profile/index.vue：在菜单卡片下方添加红色警示色“退出登录”按钮，点击后弹出确认对话框
2. profile/index.vue：onLogout 方法中清除 token、refreshToken、userId、tenantId 四个本地存储键，并跳转至登录页
3. login/index.vue：为微信登录按钮添加 loading 态，防止重复点击
4. login/index.vue：增强 onGetPhoneNumber 错误处理，区分用户拒绝授权与网络异常
5. login/index.vue：onLoginSuccess 中增加 tenantId 的持久化存储，与 profile 页保持一致
