## Task description
- Core requirement: 用户报告"火警处置页面视频播放出现错误：端口7096（HTTPS页面无法加载http视频流）"，需定位并给出处理办法。
- Task background: 报错文案"HTTPS 页面无法加载 HTTP 视频流，请联系管理员配置 HTTPS-HLS（端口 7096）"唯一出处是 VideoPlayer.vue（HLS 与 dhhls 两处守卫）。处置中心右栏视频在提交 d3024e8（2026-10-28 19:34）已整包改为 WsPlayerWrapper（RTSP over wss://域名/wsplayer-proxy），全项目已无任何文件 import VideoPlayer.vue。

## Execution process
1. 全仓 grep "7096" 确认源码中仅 VideoPlayer.vue 两处含该文案；grep 确认 VideoPlayer.vue 已成孤儿组件、getLiveUrl/getCameraLiveUrl 均无调用方。
2. git show d3024e8^ 的 alarm-order/index.vue 核实改造前写法正是 VideoPlayer + getLiveUrl 只取 urlRes.url 丢弃 flvUrl，HTTPS 页面拉 ICC http m3u8 触发混合内容拦截。
3. 关键定位证据：检查生产构建产物目录 anwei-fire-remote-monitor-vue/dist-prod，index.html 与 assets 时间戳均为 2026-10-26 11:35（早于 10-28 修复）；用 node zlib 解压主包 index-DuBp7TFC.js.gz 后仍含 "7096" 字符串，证明线上 nginx-frontend 镜像对应的是改造前代码。
4. 结论：代码无需改动，只需重新构建并发布前端镜像（deploy/build-push.ps1 -Version vx.x.x），发布后 Ctrl+F5 强刷验证 Network 不再出现 http m3u8/ts 请求、改现 wss /wsplayer-proxy 且状态 101。

## Notes
- "已修复却仍报错"类问题的判据顺序：先 grep 报错唯一文案定位源码落点 → 确认当前分支代码是否还走该路径 → 再比对最近一次构建产物（dist-prod 时间戳 + 解包 grep 特征串）判定线上是否为旧构建，避免误改代码。
