移动端登录链路重构（删除 /wx-ma-login 免密直登、登录面收敛为 POST /system/auth/mobile-login 单一路径）的落点文件清单。方案结论与取舍理由见记忆「删除小程序免密直登端点，登录面收敛为 mobile-login 单一路径」，本条只存档实际改动的文件位置。

后端（anwei-fire-remote-monitor）：
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/controller/admin/auth/AuthController.java（删 wx-ma-login 端点）
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/service/auth/AdminAuthService.java（删 wxMaPhoneLogin 声明）
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/service/auth/AdminAuthServiceImpl.java（删实现；mobileLogin 改用 reqVO.getAccount()）
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/service/user/AdminUserService.java（删 createWxMaUser 声明）
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/service/user/AdminUserServiceImpl.java（删 createWxMaUser 及 RoleService/RoleDO 注入；getUserListByMobileIgnoreTenant 改名 getUserListByAccountIgnoreTenant，内部按 ValidationUtils.isMobile 分流查 mobile 或 username）
- /module-system/module-system-api/src/main/java/com/enjoyiot/module/system/enums/ErrorCodeConstants.java（删 AUTH_LOGIN_DEMO_CONFIG_INVALID）
- /server/src/main/resources/application-dev.yaml 与 application-prod.yaml（删 platform.login.demo-tenant-id / demo-role-id）
- /module-system/module-system-biz/src/main/java/com/enjoyiot/module/system/controller/admin/auth/vo/AuthMobileLoginReqVO.java（mobile 字段改名 account，校验注解 @Length(4,16) + @Pattern(^[A-Za-z0-9]+$)）

移动端（anwei-fire-remote-monitor-mobile）：
- /anwei-fire-remote-monitor-mobile/pages/login/index.vue（placeholder 改「请输入账号」、去 type="number"、maxlength=16、正则 /^[A-Za-z0-9]{4,16}$/、payload 字段 mobile→account）

验证方式：mvn compile 通过；Swagger 文档与 YAML 注释中「手机号」描述统一替换为「账号」。遗留边界：Web 端 /auth/login 仍只按 username 匹配，未纳入账号分流。
