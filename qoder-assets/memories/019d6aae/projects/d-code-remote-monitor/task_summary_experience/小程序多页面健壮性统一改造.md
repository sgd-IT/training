## 任务描述
对微信小程序多个核心页面（登录页、首页、个人中心、统计页、告警中心）进行健壮性统一改造，解决硬编码、无状态反馈、内存泄漏、mock 数据未替换、API 调用不规范等问题。

## 执行过程
```mermaid
graph TD
    A[诊断登录页域名校验失败] --> B[发现 rawPost 与 BASE_URL 硬编码]
    B --> C[统一替换为 '@/utils/request' 封装调用]
    C --> D[为登录页添加 sending/loading 状态、countdown 定时器 onUnload 清理]
    D --> E[为个人中心页实现 userInfo 动态加载 + 退出登录完整清缓存逻辑]
    E --> F[为首页/统计页/告警中心页替换 mock 数据为真实 API，补全 loading/empty/refresher]
    F --> G[全局修正 @click → @tap，增加 :active 反馈，错误处理统一 e?.msg]
```

## 任务总结
完成小程序多页面健壮性升级：统一请求入口、消除硬编码、完善状态管理（loading/sending/timer）、修复内存泄漏、动态加载用户信息、实现安全退出、补全空/加载/刷新交互，显著提升生产可用性。
