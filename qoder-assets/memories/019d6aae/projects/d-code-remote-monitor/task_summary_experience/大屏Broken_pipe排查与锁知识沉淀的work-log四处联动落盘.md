## Notes
- 落盘方式陷阱：work-log 数据文件带透明加密，PowerShell `Get-Content` 读到的是密文（且提示 Node fallback 执行、可能缺 PATH），禁止用 PowerShell 做追加或读改写；必须用 IDE 侧 Read/SearchReplace/Write 工具，写后再 Read 回读校验。
- 02-专题 常规门槛是"同一主题跨项目或跨月累计 ≥3 条才建专题"，本次因用户明确要求沉淀该知识点而破例新建单条专题，交付时需向用户说明这一点。
- 必须纠正用户的因果表述："多个大屏访问同一个实例"不是"单实例扛不住并发"，日志证据是同一出口 IP（NAT 共享公网 IP）下每台浏览器对同域只有 6 个 HTTP/1.1 连接、页面跑 5 组轮询互相排队；因此这不是加分布式锁能解决的问题，面试按错误口径讲会被追问击穿。
- 日期按当天 2026-10-27 记录，实际排查若发生在更早需同步改 01/00/06 三处。
