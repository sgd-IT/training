## Task description
- Core requirement: diagnose and resolve the inconsistency where the device center UI shows "5 bound cameras" for device 8, but the database has zero binding records
- Task background: user provided screenshots showing device 8 (fire alarm camera) with 5 bound cameras in the UI, yet queries to the LAN and cloud databases' device_camera_relation table returned no results; this indicates a data sync or caching issue between frontend display and backend persistence

## Execution process
1. Confirmed the UI component CameraBindPanel.vue calls getCamerasByDevice() → /eiot/video/relation/list?deviceId=8 to fetch bound cameras (not /eiot/video/camera/list)
2. Verified via MCP and mysql CLI that both LAN (192.168.250.160:3306) and cloud (gz-cdb-nmt6uclj.sql.tencentcdb.com:26671) databases have zero records for device_id=8 in the device_camera_relation table
3. Ruled out common causes: checked for deleted records (none found), confirmed the correct MCP instance names and connection parameters, and validated the query syntax
4. Concluded the UI display is either stale cache or reflects an earlier state before the bindings were physically deleted; recommended user refresh the page (Ctrl+F5) and rebind if necessary
