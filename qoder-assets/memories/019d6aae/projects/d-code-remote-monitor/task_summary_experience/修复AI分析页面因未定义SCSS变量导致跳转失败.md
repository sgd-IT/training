## 任务描述
解决AI分析页面（/eiot/firewatch/ai-analysis）点击菜单后无响应的问题，根因为SCSS中使用了未定义变量$cyan，导致组件编译失败、无法渲染。

## 执行过程
```mermaid
graph TD
    A[现象:点击智能分析无跳转] --> B[排查路由注册与菜单命令]
    B --> C[确认路由存在且命令映射正确]
    C --> D[检查页面组件加载失败原因]
    D --> E[发现index.vue中SCSS使用未定义变量$cyan]
    E --> F[定位到$accent为项目统一定义的主色调变量]
    F --> G[将$cyan替换为$accent]
    G --> H[验证编译无错误，跳转恢复正常]
```

## 任务总结
成功修复AI分析页面跳转失效问题：根本原因是index.vue中SCSS使用了未声明的$cyan变量，将其统一替换为项目已定义的$accent变量后，组件可正常编译加载，路由跳转功能恢复。
