## Notes
- 并行调用 Bash(commit) + Write(提交信息文件) 导致首个提交误用了尚未更新的旧信息（内容正确、信息串位），靠 git reset + commit --amend -F 修正；教训：**同一文件的写入与其消费命令绝不能同轮并行**。
- PowerShell 管道 Out-File -Encoding utf8 仍会把 git log 中文转码污染，最终改用 node execFileSync('git', ['log','--format=%h %s']) 做 UTF-8 精确 MATCH 校验才可信。
- SearchReplace 的 replace_all 实测只命中模板处、漏改注释处，需再逐条精确补齐并用 grep 复查残留。
- 提交前必须逐文件 diff 甄别"会话外遗留改动"（本次 duty/index.vue、以及 AlarmVideoDialog 中前人 WSPlayer→VideoPlayer 的未提交改动）并向用户确认归属。
