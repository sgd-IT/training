## 任务描述
对远程监控系统数据中心的4个分析组件（告警/设备/巡检/工单）实施图表去重改造，确保14个图表全部采用唯一 ECharts 类型，并匹配业务语义。

## 执行过程
```mermaid
graph TD
    A[需求:图表去重] --> B[扫描@element-plus/icons-vue可用图标]
    B --> C[逐个修改4个Analysis.vue组件：替换图标+重构图表类型]
    C --> D[AlarmAnalysis：Pie→Rose、Histogram→Funnel、Timer→Clock、Bar→PolarBar]
    E[DeviceAnalysis：Monitor→Odometer、PieChart→Coin、OfficeBuilding→Tickets、Pie→Gauge、Pie→Treemap、HBar→PictorialBar]
    F[PatrolAnalysis：TrendCharts→DataBoard、GroupedBar→Radar]
    G[WorkOrderAnalysis：TrendCharts→Stamp、Line→StackedBar]
    H[发现TreemapChart未注册→补全echarts插件index.ts]
    I[修复index.vue模板中误写的<script>标签]
```

## 任务总结
成功实现图表类型零重复：14个图表覆盖 Line、Rose、Funnel、PolarBar、Gauge、Treemap、PictorialBar、Radar、StackedBar、HBar 共10种唯一类型；同步完成图标语义化替换（如告警等级用 SetUp、设备状态用 Odometer）；插件注册与模板错误均已修正，ESLint 验证通过。

## Notes
- 本记忆的"14图零重复类型"成果是历史快照：这批 Rose/Funnel/Gauge/Treemap/Radar/PictorialBar 等图表后来因 Vue 3 slot 容器尺寸问题被整体移除 ECharts，改回数据列表。
- 最新有效结论（数据中心重规划轮）：重新引入 ECharts 时按业务语义收敛为少数几种可靠类型（趋势双折线、档位/类型环形饼、24h柱状、排名横向柱 TOP5、数字卡 StatGrid），不再追求"图表类型全局唯一"；本轮未动用 Treemap/Gauge/Radar/PictorialBar。复用本记忆前须先确认目标页面处于何种形态。
