## Task description
- Core requirement: 使用静态数据（mock data）实现告警详情页，并与告警中心页面完成导航集成
- Task background: 告警中心页面已存在，需为其卡片添加跳转能力；详情页需展示设备信息、事件信息、处置记录等结构化内容；使用静态数据可快速验证UI布局和交互，避免依赖后端接口

## Execution process
1. 新建 pages/alarm-detail/index.vue 页面文件，使用静态数据构建完整布局：顶部横幅（告警类型图标+设备名+严重等级徽章）、事件信息卡、设备定位卡、设备信息卡、处置记录时间线、底部固定栏（标记误报+立即处置）
2. 在 pages.json 中注册 alarm-detail 页面路由
3. 修改 alarm-center/index.vue，为告警卡片整体添加点击跳转至详情页的逻辑
4. 为 alarm-center/index.vue 中的底部操作按钮（标记误报/立即处置）添加 .stop 修饰符，阻止事件冒泡导致重复跳转
