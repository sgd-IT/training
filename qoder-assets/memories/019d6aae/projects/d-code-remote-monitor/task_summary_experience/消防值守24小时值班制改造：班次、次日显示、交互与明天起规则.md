## Task description
- Core requirement: 按"2人上班、24小时制、早上8点到次日8点"的值班制度，完成值班模板与班次定义改造；后续追加三轮要求：①日期要清楚（模板示例日期定死+界面上"到第二天"要可见）②要考虑使用者的交互③自动排班和导入只从当天的后一天开始排。最终输出完整汇总版覆盖所有分散修订。
- Task background: 现状班次是两班倒三件套（day白班08:00-18:00 / night夜班18:00-08:00 / wholeday全天班08:00-08:00）。方案确定沿用 wholeday 全天班作为24小时制班次、每天1条隔日轮换；前端由 agent 直接实现，后端由用户手敲（hand-typing-training模式）。
