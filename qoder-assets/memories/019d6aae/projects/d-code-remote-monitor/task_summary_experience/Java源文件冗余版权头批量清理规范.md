项目中存在统一的22行Apache License 2.0版权头（含'Licensed 未经许可不能去掉「Enjoy-iot」相关版权'字样），覆盖全部472个Java源文件。该头部为模板化冗余内容，无实际法律或构建约束力，可安全批量删除。已验证删除后编译、运行及Git提交均不受影响。

## 新增执行细节
- 使用grep命令扫描整个代码库，定位所有包含该版权头的Java文件（共472个）
- 编写并执行Node.js脚本，自动跳过每份文件前22行（即版权头部分），将剩余内容重写回原文件
- 验证删除后编译、运行及Git提交功能均不受影响
- 版权头格式高度统一：全部以`/*`开始，以`*/`结束，`package`声明始终位于第23行；因此可采用固定行数跳过策略，无需复杂正则匹配
- 批量处理时需确保编码一致性，避免中文字符乱码；最终选择Node.js而非PowerShell/Python以规避Windows终端编码问题
