## Task description
- Core requirement: 统一移动端值班首页（duty/index.vue）的UI样式，包括header标题右偏移、页面内容整体下移避免遮挡、以及card-body左右间距一致
- Task background: 值班首页与其他页面（如工作台、告警中心）在UI细节上存在不一致；用户明确要求header右偏移35px、内容整体下移30px、card-body左右间距对称；任务涉及CSS样式调整和布局修复

## Execution process
1. duty/index.vue：添加::v-deep .aw-navbar__title-wrap.is-center { margin-left: 35px; }规则，实现header标题右偏移35px，与其他页面保持一致
2. duty/index.vue：将.page容器的padding-top增加30px，使页面内容整体下移，避免被固定header遮挡
3. duty/index.vue：为.schedule-list添加box-sizing: border-box样式，确保padding: 0 24rpx正确应用，解决card-body右侧贴边问题，实现左右间距对称
