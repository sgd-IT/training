## Task description
- Core requirement: make the "现场视频" (live video) and "AI智能分析" (AI analysis) panels in the disposal center page follow the page scroll (sticky behavior)
- Task background: the alarm-order/index.vue page uses ElScrollbar for full-page scrolling; the right-column was previously a normal flex item that scrolled out of view; the fix requires CSS position: sticky with proper alignment and height constraints

## Execution process
1. Identified the target file: anwei-fire-remote-monitor-vue/src/views/eiot/firewatch/alarm-order/index.vue
2. Located the .right-column style block (lines 2688–2707)
3. Added position: sticky; top: 8px to enable viewport-relative sticking
4. Added align-self: flex-start to prevent the flex item from being stretched, which would eliminate sticky movement space
5. Added max-height: calc(100vh - var(--top-tool-height) - var(--tags-view-height) - 16px) + overflow-y: auto to ensure content remains visible when taller than the viewport
6. ESLint validation passed
