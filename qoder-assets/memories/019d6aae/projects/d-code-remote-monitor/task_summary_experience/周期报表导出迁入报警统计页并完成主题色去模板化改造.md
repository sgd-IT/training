## Task description
- Core requirement: 判断数据中心页头「月度/季度/年度 + 导出报表」这节功能移植到哪里更合适，并按用户决策完成迁移；随后对目标页面（报警统计）做去 AI 味的视觉改造，且强调色须跟随系统主题色。
- Task background: 该区块调用 GET /eiot/firewatch/monthly-report/export-pdf 生成月/季/年 8 章节运行报告 PDF，属低频正式交付物，原先挤在数据中心深色看板页头；大屏下拉里的"数据中心"入口处于注释状态，但数据库 system_menu 中消防值守分组（parent_id=3000）确有数据中心菜单（id 3209），另有一个顶级空目录"数据中心"（id 2919，数据债）。

## Execution process
1. 盘点候选位置：查 system_menu 得到消防值守分组下的业务页清单（单位管理/监控中心/火警处置/值班管理/巡检任务/维修工单/报警统计/维护保养/隐患管理/数据中心/座机号码/通话记录），据此给出四方案对比表（独立运行报告页最优、并入报警统计、留数据中心调位置、放大屏头部不推荐），经 AskUserQuestion 由用户选定"并入报警统计页"。
2. data-center/index.vue 移除：删除 header-right 中的周期类型下拉、月份/季度/年度选择器、导出按钮（保留"返回值守大屏"关闭按钮）；删除 reportPeriodType/reportPeriod/exporting/periodTypeOptions/defaultPeriod/quarterOptions/handlePeriodTypeChange/periodTypeName/handleExportReport；删除 .report-period-type/.report-month-picker/.export-report-btn 深色控件样式；从 @element-plus/icons-vue 导入中摘掉 Download。移除前先用 Grep 确认这些符号仅被导出区块使用（request 因 loadProperties 仍在用故保留）。
3. alarm-record/index.vue 加入：搜索卡片下方新增「周期运行报告」卡片（左侧说明文字 + 右侧周期下拉/日期选择/导出按钮），逻辑原样迁入（默认上一完整期、季度近 8 个选项、文件名带周期）；因该页原本没有 computed，import 行补上 computed；刻意与该页"报警记录明细"卡片已有的 Excel/PDF 导出分开摆放，避免两类导出混淆。接口与后端零改动。
4. 去 AI 味改造（用户以 skill 触发）：删除 5 张渐变彩色图标统计卡（#667eea→#764ba2 那套）与悬浮上移动效，改为控制面板内的一条指标带（等宽数字 tabular-nums、窄字距标签）；搜索区与指标合并为单块面板用细线分隔，不再卡片叠卡片；卡片统一 2px 直角 + 1px 边框 + 无阴影；区块头改为「编号 + 标题 + 延伸细线」并去掉重复图标；表格去斑马纹、表头小号大写字距；导出按钮由绿/黄实心改描边，全页只保留报表导出一个实心主按钮；报表卡片改为一条工具带。
5. 主题色收敛（用户追加要求）：先 Grep 全局 --el-color-primary 定义，确认项目未做全局覆盖（Element Plus 默认蓝 #409eff），仅 alarm-order 页面局部覆盖为 #199b96；故样式层把 $red 全部替换为 $accent: var(--el-color-primary)，hover/active 用 --el-color-primary-dark-2，工具带底色用 --el-color-primary-light-9；页头竖线、火警数字、主按钮均走变量。
6. 图表 JS 配色同步：脚本顶部加 `const THEME_COLOR = getComputedStyle(document.documentElement).getPropertyValue('--el-color-primary').trim() || '#409eff'`，报警趋势线/维度柱/火焰分类色改用 THEME_COLOR，处置数量保留低饱和墨绿 #2f6b4f 做区分，去掉 echarts LinearGradient 面积渐变与高饱和默认色，levelToColor 与 getAlarmTypeColor 两套映射一并换成低饱和体系。
7. 验证：两文件 ESLint 通过；vue-tsc 过滤 data-center/alarm-record 无报错。

## Notes
- SearchReplace 的 replace_all 按整串精确匹配：用不带尾逗号的 original 替换带逗号的原语句会吞掉分隔逗号，导致 TS 语法错误；批量改颜色这类短片段时应带上完整上下文或先 Read 核对写法差异（同一字符串在不同行的尾随符号不同会造成部分未被替换）。
- Bash 里 Select-String 取行号与 Read 工具的 1-based 行号存在偏移，定位 style 段起点应改用 Grep 精确匹配 `<style lang="scss" scoped>`。
- THEME_COLOR 是模块加载时一次性读取，运行时通过设置面板改主题色不会即时反映到图表，刷新后生效——已接受该权衡。
- 页面骨架仍保留暖纸底色不跟主题变化，避免整页被主题色铺满。
