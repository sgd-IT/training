## Task description
- Core requirement: 取消大屏值守台（duty-screen）实时告警列表的自动滑动（自动滚动）。
- Task background: duty-screen/index.vue 中实时告警列表由 setInterval 驱动的 startAlarmAutoScroll 每 50ms 让容器 scrollTop += 1，滚到底回顶部循环；配套有 scrollPaused 悬停暂停（mouseenter/mouseleave）与 alarmScrollRef 容器引用。用户希望列表不再自己动。

## Execution process
1. duty-screen/index.vue 脚本：删除 scrollPaused、alarmScrollRef、alarmAutoScrollTimer 三个响应式状态与 startAlarmAutoScroll 函数本体。
2. 模板：移除告警列表容器的 ref="alarmScrollRef" 与 @mouseenter/@mouseleave 绑定；alarm-inner 包裹节点保留以维持既有 DOM 结构。
3. 生命周期：移除 onMounted 中的 startAlarmAutoScroll() 调用与 onUnmounted 中的 clearInterval 清理。
4. 样式核查：全仓 Grep 确认 .alarm-scroll / .alarm-inner 在 src 下无独立样式定义，滚动能力来自公共 .card-content 的 overflow-y: auto（滚动条已隐藏），因此删除 JS 后手动滚轮/触控板仍可翻页，无需补样式。
5. 注释同步：改写 .alarm-item 上方遗留注释，去掉"自动滚动/滚轮才能手动翻"旧语境，改为说明容器不要再覆盖 overflow、超出靠滚轮手动翻。
6. 校验：Grep 确认残留引用为 0；GetProblems 仅 3 条存量警告（两处 -webkit-background-clip 兼容提示、DevelopingTag 未使用），无新增错误。
7. 提交：按用户选择只提交该单文件（工作区另有 alarm-record/index.vue 的周期报告入口移位改动，经询问后保留未提交），提交信息 feat(duty-screen): 取消实时告警列表自动滚动，结果 e4ef336，1 file changed +3/-31，未 push。
