## Notes
- 同一功能的前后端改动不能合为一笔（跨物理仓库无法原子提交），但两者语义必须同口径：本轮 ThingComponent 间隔与前端提示文案的矛盾就是"分别提交却各自成立"造成的，改这类有全局承诺的参数时须同步检索所有对它做时长表述的文案/文档。
- 终端用 node 打印中文文件内容会得到 GBK 误解码的乱码，不能拿它当 SearchReplace 的 original_text 来源；必须先 Read 工具取准确原文再改，否则会改错字节或匹配失败。
- 注释里引用的跨文件类名（如"和 XxxTask 保持一致"）在重命名后会失实，且编译与 IDE 诊断都无信号；同类"改名只改了一半"应通过 git grep 该类名是否还存在来核验。
- 用户以"1.一开始是5秒是吧 2.入库 3.检查一下这个问题"这种逐条回答形式给决策时，不代表已授权提交，仍需等明确的提交指令。
