用户资料页采用双重弹窗交互模式：点击头像区域触发微信原生 `chooseAvatar` 弹窗（`button[open-type="chooseAvatar"]`）；点击昵称文字区域触发自定义模态弹窗，弹窗内嵌 `input[type="nickname"]` 输入框，支持确定保存或取消关闭。禁止直接替换昵称文本为可编辑输入框，确保交互意图清晰、权限触发可控、符合微信最新授权规范。
