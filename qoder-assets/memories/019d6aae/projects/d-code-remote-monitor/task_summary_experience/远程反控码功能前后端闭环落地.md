## Task description
- Core requirement: 完整实现远程反控码功能，支持移动端查看、PC端指令下发校验、PC端管理员二次验证查看。
- Task background: B1-B3已实现移动端取码；B4/B5需补全消费端（指令下发）与管理员查看入口；前端需在移动端和PC端同步落点。

## Execution process
1. 移动端：pages.json注册新页面；profile/index.vue新增「反控码」菜单入口；pages/index/index.vue将「巡检任务」替换为「反控码」宫格；新建pages/remote-control-code/index.vue页面（含6位码卡片、倒计时、刷新按钮、使用说明）。
2. PC端：remoteConsole.api.ts封装getControlCode API；VerifyModal.vue将「操作指令」改为「反控码」并加提示文案；RemoteConfigDialog.vue底部新增「反控码」区块，点击弹密码框验证后显示码与有效期；remote-console/index.vue页头新增「反控码」按钮，点击同样弹密码框验证。
3. 后端B4：RemoteControlCodeService接口增加verifyCode方法声明；RemoteControlCodeServiceImpl实现该方法（读Redis比对）；DeviceInstructionServiceImpl修改校验块，删除旧静态密码比对，改为调用verifyCode。
4. 后端B5：ErrorCodeConstants新增REMOTE_CONTROL_PASSWORD_ERROR错误码；新建RemoteControlCodeVerifyReqVO VO；RemoteConsoleController新增POST /eiot/remote-console/control-code接口，校验登录密码后返回当前租户反控码。
5. 校验：pages.json JSON解析通过；移动端三个Vue文件script提取后node --check语法校验通过；PC端vue-tsc --noEmit零新增错误；所有class时间戳确认为本次重编。
