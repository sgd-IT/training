## Task description
- Core requirement: Diagnose and fix the WeChat Mini-Program hot-recompile failure; add 'under development' prompts for all mobile pages without backend API integration.
- Task background: The alarm-detail page had inconsistent header styling (margin-left) and the project.config.json contained invalid JavaScript-style comments that broke JSON parsing, causing hot-recompile to fail. Several mobile pages (alarm-detail, stats, messages) lacked real API integration and needed user-facing prompts.

## Execution process
1. Confirmed the compiled output files were up-to-date, proving HBuilderX compilation was working correctly.
2. Identified that the WeChat DevTools service port was disabled, which is required for HBuilderX communication.
3. Fixed project.config.json by removing JavaScript-style // comments that caused JSON parsing failures.
4. Updated alarm-detail/index.vue's ::v-deep .aw-navbar__title-wrap.is-center margin-left from 35px to 20px to align with other pages.
5. Added '功能开发中' toast notifications to action buttons in alarm-detail/index.vue (onMarkFalse, onHandle), stats/index.vue (onToday, onExportReport, onExportRisk), and messages/index.vue (onRefresh).
