1. 用 node 直调 git status --porcelain=v1 -uall 盘点三仓，再导出两个 vue 文件 diff 到 _temp 逐个读取，判定二者是同一特性两端：duty-screen 把「企业总览」跳转目标从 /alarm-screen（页面未完成）改为 /device-screen 并携带 propertyId + propertyName；device-screen 新增 focusProperty 按 query 定位企业（选中、加载父设备、展开省市区路径并高亮节点），点击树节点时同步写回 URL，无 query 时仍走 sessionStorage 恢复逻辑。
2. 读 src/views/system/changelog/data.ts 现状后在 CHANGELOG 数组首位插入 V1.6.0 / 2026-10-30 / 「大屏性能优化与配置生效提示」，共 7 条（1 feature + 6 improve），条目全部翻译成业务语言，覆盖上一轮已推送的 10 笔 + 本轮 2 笔。
3. 校验：node 直调 node_modules/eslint/bin/eslint.js 对三个改动文件得 exit=0；内联 node -e 因中文引号转义失败，改落盘 _chk_cl.cjs 才跑通，验证版本序列 V1.6.0→V1.5.0→…→V0.9.0、CURRENT_VERSION = CHANGELOG[0] 自动指向新版、type 分布 1/6/0。
4. 以清单形式展示 2 笔完整提交信息（含两文件合笔的理由说明）获用户「提交」后，用 node 脚本 _commit1030b.cjs 逐笔 reset→add→commit -F，内置暂存清单比对与 git cat-file commit 原始字节 hex 校验（e4bc81=企、e696b0=新），落地 56c2ab2 feat(firewatch)、45a8d59 docs(changelog)。
