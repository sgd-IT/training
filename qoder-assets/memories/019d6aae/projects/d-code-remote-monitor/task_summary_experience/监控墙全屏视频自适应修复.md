## 任务描述
解决监控墙全屏后视频画面不随屏幕尺寸自适应的问题。

## 执行过程
```mermaid
graph TD
    A[定位全屏按钮与容器] --> B[发现.video-wall-card调用requestFullscreen]
    B --> C[分析全屏后尺寸丢失：脱离原flex上下文]
    C --> D[确定缺失:fullscreen伪类控制全屏态样式]
    D --> E[设计三层修复：容器撑满+重建flex+网格拉伸]
    E --> F[在index.vue中为.video-wall-card添加:fullscreen样式块]
```

## 任务总结
通过为.video-wall-card添加:fullscreen伪类，设置width:100%;height:100vh;display:flex;flex-direction:column，并确保.wall-grid和.wall-cell继承flex:1/min-height:0，使全屏后视频网格及内部video-element能正确拉伸填满视口。
