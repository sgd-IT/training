## Task description
- Core requirement: 去掉值守大屏「今日警情」卡片中「待处理」格子上方那块橙色/黄色气泡提醒（文案为"二级报警，请处置"）
- Task background：值守大屏页面在二级告警到达时同时做两件事——给「待处理」格子加橙色光圈闪烁（pendingFlash），并在格子上方弹一个 3 秒自动消失的橙色气泡（pendingToast）。气泡会遮挡卡片内容，用户要求只去掉气泡、保留光圈闪烁

## Execution process
1. 定位实现：检索"二级报警""请处置"命中值守大屏页面，确认气泡由 pendingToast 状态 + Transition(toast-fade) + .pending-toast 样式构成，触发函数 flashPendingToast 同时驱动 pendingFlash 与 pendingToast
2. 模板改动：删除 <Transition name="toast-fade"> 及其内部 .pending-toast 节点
3. 脚本改动：删除 pendingToast ref 与 3 秒定时器；flashPendingToast 更名为 flashPendingCell（仅保留光圈闪烁）；两处调用点（60 秒兜底对账、WebSocket 推送回调）同步改名
4. 样式改动：删除 .pending-toast 与 .toast-fade-enter/leave 系列规则
5. 首轮验证用 Grep 复查 pendingToast/pending-toast/toast-fade/flashPendingToast 全部 0 命中，GetProblems 仅剩一条与本次无关的 DevelopingTag 未使用告警，据此判定完成
6. 用户回报 vite 编译错误 "Element is missing end tag"（指向右侧面板 aside）；排查发现删除气泡节点时把跨行书写的 </div\n><div class="sl"> 中的收尾 > 一并删掉，使内层统计值 div 未闭合，父层容器被判定缺结束标签
7. 二次修复先误补出一个重复的 >，再修正为原有跨行写法，最后用 vue/compiler-sfc 直接 parse + compileTemplate 校验，SFC 错误 0、模板错误 0

## Notes
- 该文件模板存在跨行闭合写法（`</div` 换行后接 `><div ...>`），删除相邻节点时必须连同这个游离的 `>` 一起考虑，否则会破坏前一个标签的闭合而报错位置指向远端父容器
- GetProblems 与 Grep 零命中都无法证明模板结构合法：前者只对语言服务已解析部分给警告、后者只查标识符残留，必须跑一次不依赖语言服务的编译器级校验才能确认
- node -e 内联 require('@vue/compiler-sfc') 在本环境不可用（该包未平铺在 node_modules 顶层），改用 import('vue/compiler-sfc') 动态导入才成功
