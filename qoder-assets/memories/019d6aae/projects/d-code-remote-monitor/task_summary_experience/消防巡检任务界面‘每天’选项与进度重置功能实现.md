## Task description
- Core requirement: add a "每天" (every day) option in the patrol task plan date selector and implement corresponding backend logic in refreshPatrolOverdueTasks to handle this selection; when tasks are reset, the frontend progress display must also reset to initial state
- Task background: existing plan date picker only supports specific dates; user requested recurring daily tasks with proper overdue handling and progress reset

## Execution process
1. index.vue: added planDateMode ref with radio toggle between "指定日期" and "每天"; replaced simple date picker with conditional rendering; added formatPlanDate helper function to handle Jackson's LocalDate array serialization [2027,6,24]; table column and detail dialog show "每天" tag when planDate is null
2. FirePatrolTaskCreateReqVO.java: removed @NotNull validation on planDate to allow null for "每天" tasks
3. Backend fix: added @TableField(updateStrategy = FieldStrategy.ALWAYS) annotation to FirePatrolTaskDO.planDate field to force updateById to include NULL values in UPDATE SQL; reverted FirePatrolTaskServiceImpl.updateTask() back to using firePatrolTaskMapper.updateById(updateObj)
4. Database: ALTER TABLE fire_patrol_task MODIFY COLUMN plan_date DATE DEFAULT NULL required (manual execution)
