## Task description
- Core requirement: 移动端首页「消防运行」区块的「设备状态」入口改名为「设备总览」，并让用户按所属租户 ID 查看设备（原先点击提示"待接入"，功能缺失）
- Task background: 首页 pages/index/index.vue 的 D01 入口在 onTodo 中无处理分支；工作台 messages/index.vue 已有「设备列表」入口指向 pages/profile/device-list.vue；后端 AppDeviceInfoController(/eiot/device/page) 用 @ss.hasMobilePlatformAccess() 放行移动端账号，DeviceInfoServiceImpl.getDeviceInfoPage 对系统租户走 TenantUtils.executeIgnoreWithResult、普通租户由拦截器过滤，EiotDeviceInfoMapper 保留 eqIfPresent(tenantId) 显式条件

## Execution process
1. pages/index/index.vue：D01 标题「设备状态」→「设备总览」；onTodo 新增 D01 分支 uni.navigateTo('/pages/profile/device-list')，替换原"待接入"提示
2. pages/profile/device-list.vue：NavBar 标题「设备列表」→「设备总览」；fetchList 查询参数显式带上 tenantId（来自 ensureTenant：本地缓存或 /system/user/profile/get 返回的 data.tenantId），使原有 ensureTenant 逻辑真正用于查询
3. pages.json：profile/device-list 的 navigationBarTitleText 同步为「设备总览」
4. 验证：语言服务未就绪导致 GetProblems 不可用，改用 node -e JSON.parse 校验 pages.json 合法性 + Read 复查两个 vue 改动区域结构完整；实际效果待用户在微信开发者工具用企业账号点验
