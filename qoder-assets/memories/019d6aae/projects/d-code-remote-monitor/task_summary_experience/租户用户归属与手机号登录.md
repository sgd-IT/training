## 需求口径
- 租户即零售店，用户需归属指定租户（非系统租户）
- 小程序支持手机号+密码登录，绕过验证码
- Web端用户管理支持为用户指定归属租户
- 登录失败时统一提示「账号或密码不正确」

## 探索结论
- `system_tenant` 表即零售店主数据源；`system_users.tenant_id` 已存在且 NOT NULL
- `TenantDatabaseInterceptor` 对系统租户（tenant_id=1）自动跳过 `tenant_id = ?` 过滤，实现跨租户可见性
- `wxMaPhoneLogin` 已验证可复用：`TenantUtils.executeIgnoreWithResult` 跨租户查手机号，`TenantUtils.execute(tenantId, ...)` 切上下文发 token
- `validateCaptcha` 校验 `captchaVerification` 字段；移动端未传该字段导致拦截，故需新端点

## 改动清单
### 后端
1. `UserSaveReqVO.java`: 新增 `tenantId` 字段
2. `AdminUserServiceImpl.java`: `createUser` 用 `TenantUtils.execute(targetTenantId, ...)` 包裹，含越权防护；`updateUser` 忽略 `tenantId`
3. `UserRespVO.java` + `UserPageReqVO.java`: 新增 `tenantId`/`tenantName`
4. `UserController.java` + `TenantService(+Impl).java`: 新增 `getTenantMap` 批量查询，`getUserPage`/`getUser`/`exportUserList` 批量拼 `tenantName`
5. `AdminUserMapper.java`: `selectPage` 增加 `eqIfPresent(AdminUserDO::getTenantId, reqVO.getTenantId())`
6. 新建 `AuthMobileLoginReqVO.java`（不含 `CaptchaVerificationReqVO`）
7. `AdminAuthService.java` + `AdminAuthServiceImpl.java`: 新增 `mobileLogin`（nonce→跨租户查手机号→`authenticate`→发 token）、`getWxMaPhoneNumber`（phoneCode→手机号）
8. `AuthController.java`: 新增 `/mobile-login`、`/wx-ma-phone` 两个 `@PermitAll` 端点
9. `application.yaml`: `ignore-urls` 追加 `/admin-api/system/auth/mobile-login` 和 `/admin-api/system/auth/wx-ma-phone`

### Web端
1. `UserForm.vue`: 新增「归属租户」下拉（仅平台租户可见），新增模式可选、编辑模式禁用回显
2. `user/index.vue`: 「部门列」改为「租户列」；查询区加租户筛选下拉（仅平台租户）
3. `user/index.ts`: `UserVO` 补 `tenantId`/`tenantName` 字段

### 移动端
1. `login/index.vue`: 
   - 账号框右侧 `#ifdef MP-WEIXIN` 微信授权按钮（`open-type="getPhoneNumber"`）
   - `doLogin` 改调 `/mobile-login`，一步到位
   - `onGetPhoneNumber`: POST `/wx-ma-phone` 回填手机号

## 依赖关系
- `mobile-login` 复用 `authenticate()` 的失败锁定、禁用校验、日志记录逻辑
- `wx-ma-phone` 复用 `socialClientService.getWxMaPhoneNumberInfo()`
- Web端租户下拉复用 `videoCamera.api.getTenantOptions()`（平台租户专用、跨租户列表）

## 测试计划
1. 平台租户管理员（tenant_id=1）在 Web 用户管理中创建用户并指定租户 166 → 查 `system_users.tenant_id` 应为 166
2. 小程序手输手机号+Web设置的密码登录 → 成功，token 中 `tenantId` 正确
3. 小程序微信授权获取手机号 → 自动填充账号框 → 登录成功
4. 非平台租户管理员尝试在 Web 用户管理中选择租户 → 下拉不可见

## 风险与对策
- **风险**：`createUser` 中 `TenantUtils.execute` 抛异常时事务未回滚 → **对策**：`execute` 内部已封装事务，无需额外处理
- **风险**：`mobile-login` 端点被恶意重放 → **对策**：复用 `validateLoginNonce`，同 Web 登录安全等级
- **风险**：前端 `tenantOptions` 数据未更新 → **对策**：`onMounted` 加载，与设备管理页一致

## Rejected Alternatives
- **跨库直读 fireworks_retail_info**：参考库属另一系统，且 `fireworks_retail_info.id` 为 UUID 字符串，与主库 `bigint` 不兼容
- **租户管理建号替代用户管理**：已有租户（165-168）无法补账号，且一店仅限 1 个管理员账号，覆盖不全
