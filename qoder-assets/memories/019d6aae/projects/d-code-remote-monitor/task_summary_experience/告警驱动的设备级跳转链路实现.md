## 任务描述
实现值守大屏（duty-screen）→ 实时告警弹窗（alarm-popup）→ 设备控制室（device-screen）→ 远程控制中心（remote-console）的端到端跳转链路，要求：告警弹窗跳转时携带 deviceId；device-screen 仅展示该告警关联的单台设备；remote-console 根据 query 中 deviceId 自动选中对应设备并加载其摄像头与功能。

## 执行过程
```mermaid
graph TD
    A[需求:告警驱动的设备级跳转链路] --> B[分析告警数据结构确认 device_id 字段存在]
    B --> C[alarm-popup:goToDeviceScreen 读取 alarm.deviceId/device_id 并 router.push 带 query]
    C --> D[device-screen:onMounted 读取 route.query.deviceId → alarmDeviceId.value]
    D --> E[filteredDevices 计算属性优先按 alarmDeviceId.value 过滤设备列表]
    E --> F[remote-console:loadDeviceTree 完成后调用 autoSelectDeviceFromQuery]
    F --> G[遍历 treeData.devices 匹配 String(d.id) === query.deviceId]
    G --> H[调用 handleSelectDevice 触发设备选中、摄像头加载、功能加载]
```

## 任务总结
成功打通告警驱动的精准设备跳转链路：1）alarm-popup 支持从告警对象安全提取 deviceId（兼容 deviceId/device_id 字段）；2）device-screen 实现 query 驱动的单设备聚焦模式；3）remote-console 实现 query 驱动的设备自动选中与联动加载，无需用户手动操作。
