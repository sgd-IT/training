## 任务描述
修复监控墙全屏后视频画面无法填满的问题。

## 执行过程
```mermaid
graph TD
    A[用户反馈全屏视频不填满] --> B[定位.video-wall-card全屏无尺寸]
    B --> C[添加:fullscreen伪类设置width/height/flex]
    C --> D[验证仍不填满→深入VideoPlayer.vue布局]
    D --> E[发现.video-player-wrapper依赖flex居中导致拉伸失效]
    E --> F[VideoPlayer.vue中.video-element改用position:absolute;inset:0]
    F --> G[父组件.cell-video中:deep(video)同步加固absolute+inset:0]
```

## 任务总结
根本解决路径：放弃依赖flex交叉轴拉伸（align-self: stretch），统一采用position: absolute; inset: 0强制四边贴满。在VideoPlayer.vue中加固.video-element定位，在video-surveillance/index.vue中通过:deep()双重覆盖，确保全屏/普通模式下video均100%填满容器。
