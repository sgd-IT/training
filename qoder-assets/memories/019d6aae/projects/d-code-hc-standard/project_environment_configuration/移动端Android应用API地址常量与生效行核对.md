移动端Android应用API地址在 other1/app/src/main/java/com/sckj/other1/http/HttpInterface.java 中以硬编码常量 IP 定义（全工程唯一定义点，RetrofitUtils.baseUrl 引用），候选地址：
- 生产主地址 http://220.203.23.144:28080/（源洹）
- 备选域名 http://fireworks-admin-api-zs.gdawkj.com/（源洹线上域名）
- 内网调试地址 http://192.168.0.200:28080/ 与 http://192.168.0.202:28080/
注意：生效行随开发/发布动作切换（2026-08 实测当前行为 192.168.0.202 内网地址，生产地址被注释），判断环境必须以文件当前未注释行为准，不能凭记忆假定。改地址后必须重新构建 APK 才生效。

## Notes
- 生效行最新取证（三端地址核查会话）：磁盘上该文件当前未注释行为本机联调地址 http://192.168.250.130:28080/（恰为本机局域网 IP），生产 220.203.23.144 与 192.168.0.200、192.168.0.202 均处于注释态；上述 2026-08 的 192.168.0.202 记录已过期仅作历史参考。核对环境时要把 192.168.250.x 本机段一并纳入判断，勿只在生产与 192.168.0.x 之间二选一。
- 核对该文件生效行不能只看编辑器视图：同一会话出现编辑器显示已改为生产地址、而磁盘仍是旧值（文件 mtime 未变、git hash-object 结果与 HEAD blob 一致）的情况，须以读盘证据为准；改动未按 Ctrl+S 落盘则重新打包出的仍是旧 IP。
