线上环境事实（2026-08-31 实测更新）：
1. 线上接口地址 http://220.203.23.144:28080，线上库 220.203.23.144:3306/tgr-gz-vue（@@hostname=anwei1-0001）。
2. 本地 IDEA 后端（localhost:28080）的 application-druid.yml master 实际指向生产库 220.203.23.144（root/Hbhy@2024#），开发库 192.168.250.160（root/t@m7Iici2i）已被注释。本地 API 测试直接写生产库，造数必须清理。
3. 后端进程 TCP 显示连 192.168.250.160:3306/6379，但实际读写发生在 220.203.23.144——存在代理转发层，环境判断以数据验证为准，勿信 TCP 目标。
4. MySQL MCP（tgr-gz-vue）连的也是 220.203.23.144 生产库，与本地后端同库。
5. 前端 dev server localhost:80，代理 /dev-api → http://localhost:28080。
6. 上线打包前务必核对 yml master 指向，避免环境错连。
7. Swagger/OpenAPI 文档随 Spring Boot 服务同端口暴露，本地地址为 http://localhost:28080/swagger-ui/index.html（RuoYi/SpringDoc 默认路径）；线上对应 http://220.203.23.144:28080/swagger-ui/index.html。若该路径 404，需检查是否被安全拦截配置放行及 springdoc 依赖是否引入。
