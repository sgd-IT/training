前端按钮权限控制应使用 v-hasPermi 指令配合后端权限标识（如 'base:leaderDutySchedule:edit'），禁止硬编码 v-hasRole 限定特定角色（如 ['admin']），确保权限控制与后端一致。
补充边界（2026-10 人员证书模块用户实证）：业务级限制不应通过隐藏/收缩前端按钮可见性实现——按钮保持对所有拥有该功能权限的账号可见（如 system1）；放行范围在修改动作处校验（后端方法内 + 前端 submitForm 同步拦截，两处口径一致），人员证书当前放行为「管理员、系统管理角色（common）、本人」，不满足时提示“只能管理员、系统管理和本人可以修改”。
