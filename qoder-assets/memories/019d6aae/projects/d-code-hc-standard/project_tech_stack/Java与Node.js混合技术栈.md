后端技术栈：
- 语言: Java 1.8
- 框架: Spring Boot 2.5.15
- 核心组件: Druid (数据库连接池), PageHelper (分页), Swagger3 (API文档)
- 工具库: Hutool, Fastjson2, Commons IO, POI & Poi-tl (Excel/Word处理), Velocity (代码生成模板), JWT (Token解析), Paho MQTT
- PDF处理: pdfbox, pdf2dom

前端/脚本技术栈：
- 运行环境: Node.js
- 核心库: pdfkit (^0.18.0)
