作业票 operatorInfo/operatorId 字段实际存储格式（生产库 base_work_special 实测校准）：多个作业人员之间用英文逗号','拼接；每人格式为 '姓名:身份证号,证书名称,证书编号'，例如 '宋鹏:420582198503040095,熔化焊接与热切割作业,T420582198503040095'。operatorId 同样以逗号存多人 syncId(UUID)。注意：早期规范所述"多人用分号;分隔、每人仅姓名:身份证号"与实际线上数据不一致，以本条逗号+证书明细格式为准。（提示词/前端输入校验如另有约定需与本存储格式对齐核对。）
