新功能菜单需分配给所有启用的角色（sys_role.status = '0'），确保所有用户均可访问。

注意适用边界：该规则仅针对「菜单级」授权（sys_role_menu）；页面内元素级的可见性可另行按角色收紧，例如某些下拉框控件仅允许「管理员」「监管员」角色查看，此时不适用"授权所有启用角色"的做法。
