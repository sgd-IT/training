项目双重预防机制模块包含'分析对象'核心功能，对应接口/openapi/risk_device/saveOrUpdateBatch，支持批量新增或修改分析对象。必填字段包括id、deptName、deptManager、hazardCode、deviceName、deviceLevel（取值：100一级/200二级/300三级/400四级/900非重大）、processType、createTime；非必填字段包括chemprocessType（危化工艺分类，参考7.1.15）、interlockingCount、mainSwitchStatusTargetCode、bypassSwitchTotalTargetCode。
