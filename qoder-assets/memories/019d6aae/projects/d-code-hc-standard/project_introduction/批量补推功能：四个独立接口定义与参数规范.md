项目批量补推功能为多个完全独立的接口，取消一键全推能力：
- `POST /push/workSpecial`：仅推送作业票主数据、传感器、安全措施、审批流转；
- `POST /push/workVideo`：仅推送视频数据；
- `POST /push/riskTask`：仅推送风险排查任务。
以上接口均支持 `startDate`、`endDate`（格式 yyyy-MM-dd）和 `onlyUnsynced`（默认 true）参数。

后续新增独立接口 `POST /push/deletedWorkSpecial`：补推已删除作业票（推送 deleteMark=1 + 最新 updateTime，跳过93项本地预校验）；startDate/endDate 可选（按删除时间 updateTime 过滤），onlyUnsynced 默认 true（只推 sync_status 为 null/'0'/'2' 的），逐条容错并返回"总计/成功/失败+失败明细"摘要。

## Notes
- `/push/workVideo` 已支持卢博祥平台视频URL的同步推送
- 已删票查询走 mapper 的 selectUnsyncedDeletedOuterIdsByDateRange / selectAllDeletedOuterIdsByDateRange
