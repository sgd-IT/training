特殊作业电子围栏人员管控需满足4项核心规则：
- 授权管控：仅票证上4名指定人员可进入围栏；
- 国标上限：围栏内总人数不得超过6人；
- 离岗即停：4名授权人员任一离开围栏，作业必须立即停止，否则触发报警；
- 入侵报警：非授权人员进入围栏立即触发报警。
