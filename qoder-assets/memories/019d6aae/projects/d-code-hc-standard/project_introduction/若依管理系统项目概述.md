**项目定位**：若依（RuoYi）是一个开源的Java快速开发平台，面向企业级后台管理系统场景。

**核心架构**：采用多模块Maven聚合工程，分层清晰——`admin`为Web入口，`framework`提供基础支撑，`system`实现业务功能，`quartz`/`generator`/`common`分别负责定时调度、代码生成与通用能力。

**功能特色**：集成权限控制、数据监控（OSHI）、Excel/Word导出（POI/POI-TL）、验证码（Kaptcha）、MQTT通信（Paho）、PDF处理（PDFBox）及JWT鉴权。
