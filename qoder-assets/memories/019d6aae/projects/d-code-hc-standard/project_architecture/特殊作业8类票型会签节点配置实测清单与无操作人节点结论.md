base_work_approve_config 实测数据（tgr-gz-vue 库，source_type 11-18 对应动火/高处/临电/受限/吊装/动土/断路/盲板，wanGong=1 均为"完工验收"收尾）。会签节点（wanGong=0，按 sort）：动火：作业负责人意见→所在单位意见→安全管理部门意见→动火审批人意见→当班班长意见；高处：作业负责人意见→所在单位意见→审核部门意见→审批部门意见；临电：作业负责人意见→用电单位意见→配送电单位意见；受限：作业负责人意见→所在单位意见；吊装：作业指挥意见→所在单位意见→审核部门意见→审批部门意见；动土：作业负责人意见→所在单位意见→水电汽工艺设备消防安全等部门会签意见→审批部门意见；断路：作业负责人意见→所在单位意见→消防安全等管理部门意见→审批部门意见；盲板：作业负责人意见→所在单位意见。结论：系统对"负责人"有现成签字节点（作业负责人意见/吊装为作业指挥意见），对"操作人"无任何签字节点（操作人是可变更的 curOperatorId 字段，非签字环节）。config 的 person 列实测为占位值"小志"，初始化 INSERT 时被丢弃未使用。落实"某节点由外施队/公司签"需新增节点-签署方属性与校验；"所在单位意见"节点对外施队票归属哪方需业务明确。
