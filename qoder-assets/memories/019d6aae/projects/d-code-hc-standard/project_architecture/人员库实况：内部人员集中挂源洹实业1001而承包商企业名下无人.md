tgr-gz-vue 库实测（2026-10）：base_contractor 共 4 家正常企业——1001 湖北源洹实业投资有限公司（company_type=1，本单位）名下挂有 136 名 base_contractor_people 人员（含邻醛车间/安全部/机修/电仪等岗位，多数持有定位卡 position_card_no），包括车间主任、班长、安全员等内部员工；1039 宜昌华直能源（company_type=2 承包商）、1040 湖北盛廷建设、1041 宜昌晟玮机械三家承包商企业名下人员数为 0。base_contractor_people 实际无 company_name 列（企业名需关联 base_contractor 或 resultMap 别名查询）。syncContractorPeople 从人员定位系统同步时把人员统一挂 contractorId=1001L，是人员集中于 1001 的成因。"内/外"判定依据已存在：企业公司类型 company_type（1=本单位内部、2=承包商），无需新建内外字典。推论：需求"双人监护内外各一人"落地时"公司1人"可直接从 1001 名下选；"外施队1人"因承包商企业名下无人暂选不出，需先把外施队人员录入到对应承包企业（管理员 PC 录入或企业码注册）。
