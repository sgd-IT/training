人员定位功能（含定位卡、围栏、聚集、SOS、低电量报警）为外包第三方平台实现，通过 WebSocket 推送报警消息接入本平台。接入点：ruoyi-system 的 WebsocketServiceImpl.sendMsg（实现 com.ruoyi.common.service.IWebsocketService），消息字段仅 posX/posY/groupId/mapId/id/type/mac/timestamp，无人数/半径/级别字段。type 映射：1=SOS、4=围栏、5=聚集、8=低电量。报警判定（聚集半径、人数分级、声光）均在平台侧完成，本平台仅负责报警入库 base_alarm_record、按部门+岗位(postCode=3)分配接收人、确认处理闭环。若需人数分级落库，需先要求外包平台在消息中补充聚集人数字段。
