## Task description
- Core requirement: 严格按用户提供的原文逐句解析并精简《预警报警信息远传与闭环处置需求清单》
- Task background: 用户要求删除 FR-04（短信）、FR-06（流程可配置）、FR-10（统计报表），并将“支持设置处理流程”并入闭环流转项；后续用户追问 FR-02 是否即对接声光报警器接口，经确认现场硬件情况不确定，最终将 FR-02 改为双选项规范（硬件接口对接 + 软件声光提醒）

## Execution process
1. 首轮精简：根据用户指令，删除 FR-04、FR-06、FR-10 条款，重排为 8 项，同步更新工期、里程碑和边界条款
2. 用户追问 FR-02 本质：明确其标准本意是对接物理声光报警器（控制室硬件），而非纯软件弹窗
3. 硬件情况确认：通过 AskUserQuestion 确认现场声光报警器状态为“不确定”，触发双选项方案
4. 双选项规范制定：将 FR-02 更新为“对接声光报警器接口（启动/停止指令下发）+ Web 弹窗/音频同步提醒”，并添加备注“报警器型号与接口形式待甲方确认后定对接方案”
5. 边界条款同步更新：明确硬件采购不在我方范围，接口协议确认前按网络型估
