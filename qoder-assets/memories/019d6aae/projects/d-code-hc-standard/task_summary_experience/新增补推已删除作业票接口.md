## Task description
- Core requirement: 为项目新增一个补推已删除作业票（deleteMark=1）的独立接口
- Task background: 现有补推接口（/push/workSpecial, /push/workVideo）均过滤 deleteMark=0，导致已删票无法被补推；用户需求是提供一条专用通道，按 updateTime 过滤并推送已删票，且跳过本地 93 项预校验以兼容历史脏数据

## Execution process
1. PushDataController.java#L82-L100: 新增 POST /push/deletedWorkSpecial 端点，支持 startDate/endDate/onlyUnsynced 参数，日志前缀为 [批量补推-删除]
2. IBaseWorkSpecialService.java: 在接口中声明 rePushDeletedBatchToPlatform 方法
3. BaseWorkSpecialServiceImpl.java#L564-L622: 实现服务方法，逐条查询、推送、留痕，失败不中断
4. BaseWorkSpecialMapper.java: 新增 selectUnsyncedDeletedOuterIdsByDateRange 和 selectAllDeletedOuterIdsByDateRange 两个 Mapper 接口方法
5. BaseWorkSpecialMapper.xml#L401-L421: 新增对应的 SQL 查询，按 deleteMark=1 和 updateTime 范围过滤
