## Task description
- Core requirement: 用户询问桌面文件《GB 危险化学品企业特殊作业安全规范30871-2022.pdf》是否包含气体检测标准，需给出条款级结论。
- Task background: 附件内容为空，该 PDF 位于 c:\Users\Administrator\Desktop\源洹\作业票模版\，共 31 页；项目 hc-standard 的特殊作业票模块后续要按国标对齐气体分析字段，需要精确到条款号与阈值数值。

## Execution process
1. 环境探测：机器无 Python（python/python3/py/pdftotext 均不可用），node_modules 仅有 pdfkit（生成器，不能抽取）；确认存在 JDK 21 与本地 Maven 仓库中的 Apache PDFBox 3.0.7 + pdfbox-io + fontbox + commons-logging 1.3.6。
2. 文本抽取失败：自写 .tmp\ExtractPdf.java 用 Loader.loadPDF + PDFTextStripper 导出 gb30871.txt，31 页全部无文字，Select-String "气体" 命中 0 —— 判定为纯扫描件、无文字层。
3. 改走图像路线：自写 .tmp\RenderPdf.java 用 PDFRenderer 按页输出 JPEG；首次 150 DPI 渲染到第 6 页抛 operatorException 中断，改为逐页 try/catch 后 31 页全出图，但多数页面呈空白。
4. 定位空白根因：自写 .tmp\InspectPdf.java 枚举各页 XObject 图像 Filter，发现仅封面/目次/前言少数页为 DCTDecode（可正常渲染），其余正文页均为 JPXDecode（JPEG 2000），PDFBox 缺解码插件时静默渲染空白。
5. 补齐解码器：本地仓库只有 jai-imageio-core 1.3.1；用 mvn dependency:get 拉取 com.github.jai-imageio:jai-imageio-jpeg2000:1.4.0 与 jai-imageio-core:1.4.0（落点 D:\Tool\apache-maven-3.9.15\repo），加入 -cp 后重跑，31 页全部有内容且无 FAILED。
6. 页序映射校准：目次声明的正文页码与 PDF 物理页存在偏移，靠读图逐页校准得出「正文第 N 页 = PDF 第 N+9 页」，据此定向读取 p10-p13（通用要求/动火/受限空间）与 p20、p22（附录 A 票样）。
7. 视觉读取取证并输出结论：以表格给出 5.3.2 a)/b) 可燃气体 0.5%/0.2% 分档、5.2.7 富氧 ≤23.5%、6.4 a) 氧 19.5%~21%、6.4 b) 有毒符合 GBZ 2.1、6.4 c) 回引 5.3.2，以及 5.3.1/6.3/6.5 的取样代表性与 30 min/60 min/连续检测每 2 h 记录等频次要求，附对应渲染图片链接。
