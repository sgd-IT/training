## Task description
- Core requirement: 排查并解决用户报告的手机号18607201733无法接收验证码的问题
- Task background: 项目使用阿里云短信服务发送验证码；该手机号在sys_user表中存在且状态正常；系统无手机号黑名单机制；后端接口无频率限制逻辑；需定位是前端、后端、阿里云侧还是运营商侧问题

## Execution process
1. 定位核心链路：确认`/api/base/sendPhoneCode`为唯一入口，并检查`SendMsgUtils.sendAlSms`调用阿里云的配置（sign=小志，template=SMS_123799421）
2. 数据库验证：查询`sys_user`表确认该手机号账号存在（user_name=18607201733，status=0），`phone_number`字段加密存储但不影响发送流程
3. 排查其他可能性：检查从业人员表（base_contractor_people）无该记录；grep代码确认无手机号黑名单机制；确认App端参数传递正确
4. 根因分析与结论：问题最可能源于阿里云限流（isv.BUSINESS_LIMIT_CONTROL）或手机号被阿里云拉黑；其次为手机/运营商拦截；建议通过线上日志中的`短信发送成功/失败`日志及错误码进一步确认
5. 代码改进建议：后端增加60秒重复发送Redis限流；移除`System.out.println`打印验证码的安全风险
