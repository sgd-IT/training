- 上述"建议改法(1)主表删除增加条件推送"已实现：BaseHiddenTroubleServiceImpl.deleteBaseHiddenTroubleById 首行调用新增私有方法 pushDeleteToPlatform(id)，取 mapper 的 selectBaseHiddenTroubleById（非 service 层会 NPE 的同名方法），仅当记录存在且 "1".equals(syncStatus) 时调 api.deleteCheck(new String[]{String.valueOf(id)})；成功口径同时接受 code==200 或 data==true，否则 log.error；整体 try/catch 包裹，失败只留日志、不阻断本地删除（用户拍板"不阻断，记 sync_result"，但因行删后 sync_result 无载体，实际留痕只能落应用日志）。改动仅一个文件，mvn -pl ruoyi-system -am compile 通过，未提交。
