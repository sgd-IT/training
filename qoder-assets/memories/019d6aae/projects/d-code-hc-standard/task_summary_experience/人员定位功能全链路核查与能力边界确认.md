## Task description
- Core requirement: 核查系统是否具备图示「基于定位的人员聚集预警功能」
- Task background: 用户提供截图，要求包含：1）覆盖内部员工/承包商/外来人员；2）预警半径≤15m；3）颜色预警模型（3人黄/4-6橙/≥7红）；4）24小时内推送至控制室/值班室；5）现场实时声光报警；6）预警确认与闭环流程；7）处置流程与责任人设置。系统通过WebSocket接入外包平台报警，需验证各环节实现情况。

## Execution process
1. WebsocketServiceImpl.java：定位报警接收入口，type=5为「聚集报警」，消息字段仅含posX/posY/groupId/mapId/id/type/mac/timestamp，无人数/半径/级别字段
2. BaseAlarmRecord.java：报警记录领域对象，含alarmStatus(未处理/已处理)、confirmUser/confirmTime/solution，但无预警级别/聚集人数/半径字段
3. alarmRecord/index.vue：前端报警台账页面，支持按部门+岗位(postCode=3)分配接收人、确认处理闭环

## Notes
- 无预警半径配置、无颜色分级模型、无24小时推送时限管理、无现场声光报警逻辑、无处置流程与责任人配置
- 外包平台消息若补充「聚集人数」字段，可在WebsocketServiceImpl.sendMsg入口处映射落库，实现分级预警
- 人员定位功能的架构事实（外包平台实现、本平台仅负责接收和闭环）请参考IMMUTABLE记忆：'人员定位为外包平台接入本平台的架构事实'

## Task overview
部分具备：系统有「人员定位聚集报警」的接收通道、报警记录台账、确认处理闭环；缺少图示要求的核心量化功能（15m半径、人数颜色分级、24小时推送、人员类别区分、处置流程与责任人配置）。结论为「部分具备」，责任边界在外包平台侧。
