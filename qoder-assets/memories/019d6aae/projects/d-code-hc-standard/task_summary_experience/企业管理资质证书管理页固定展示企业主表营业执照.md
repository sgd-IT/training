## Task description
- Core requirement: fix the 'business license image missing' issue on the 企业管理 → 资质证书管理 page by displaying the enterprise's business license image and unified social credit code from the main enterprise table
- Task background: the 资质证书管理 page only queries base_contractor_cert (certificate table), while the business license is stored in base_contractor.file_path (enterprise main table); this disconnect causes the page to be blank; the fix is a frontend-only change that adds a fixed read-only row at the top of the page

## Execution process
1. Identified the root cause: base_contractor_cert table is empty for all enterprises in the test DB, and production DB has orphaned records, so no business license appears on the page
2. Designed solution C: add a fixed read-only row above the certificate table showing the enterprise's business license image and unified social credit code, fetched via getContractor API
3. Modified contractorCert/index.vue: added HTML template for the fixed row, added contractorInfo data field, and updated getContractorInfo to fetch and store full enterprise data
4. Verified the change with GetProblems: no errors found
5. User confirmed 'c' (solution C) before the edit was applied
