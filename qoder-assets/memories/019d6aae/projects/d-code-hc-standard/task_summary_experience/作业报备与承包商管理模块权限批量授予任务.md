## Task description
- Core requirement: grant permissions base:TicketBb:add, base:TicketBb:edit, base:contractor:list, and base:contractorPeople:list to all administrator roles
- Task background: RuoYi system uses sys_role.status='0' to identify enabled roles; the super-admin (userId=1) automatically receives *:*:* permissions and does not require manual assignment; the script must target other enabled roles like '管理员'

## Execution process
1. Verified RuoYi's permission bypass logic in SysPermissionService.java: user.isAdmin() returns true only for userId==1, and grants *:*:* to that user
2. Confirmed existing menu permissions for contractor list endpoints via grep of BaseContractorController.java and BaseContractorPeopleController.java
3. Wrote SQL script grant_ticket_bb_perms.sql to: (a) insert missing button menus for TicketBb add/edit/query under the parent menu, (b) assign all 5 required permissions to all enabled roles (sys_role.status='0')
4. Script includes safety measures: INSERT IGNORE to prevent duplicates, and a final SELECT for verification
5. Noted that permissions take effect only after re-login due to caching in LoginUser

## Notes
- The super-admin (userId=1) does not need this script as it receives *:*:* by default; the script is intended for other enabled roles like '管理员'
- Local environment lacks MySQL MCP, so the script must be manually executed on the production database
- Permissions only become effective after re-login or clearing the login token cache
