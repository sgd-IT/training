## Task description
- Core requirement: 解析风险单元页面「工作状态」切换的完整逻辑（前端开关 → 本地状态 → 停机记录 → 园区平台推送 → 定时自动启停 → 手动提前启用）
- Task background: 风险单元页面用开关控件启用/停用单元，切换需同步影响本地数据库、关联排查任务并推送到园区平台，同时存在定时任务处理到期自动启停

## Execution process
1. 前端定位：riskUnit/index.vue 的 handleStatusChange 区分 status=0（启用）与 status=1（停用）两条路径
2. 启用路径：确认框后调用 changeStatus(id,"0") → PUT /base/riskUnit/changeStatus → 更新 base_risk_unit.status 并级联 base_risk_task.status
3. 停用路径：弹出停机记录对话框填写 stopTime/activationTime/reason；提交 POST /base/riskunitlog → 插入 base_risk_unit_log 并调用 PlatementRiskCheckUnitApi.saveEnable() 推送至园区平台 /openapi/enableLog/saveOrUpdateBatch
4. 手动提前启用：BaseRiskUnitServiceImpl.updateStatus() 在 status="0" 时查最新停机记录，把其 activationTime 更新为当前时间后再调 saveEnable() 推送
5. 相关代码文件已逐一审查确认（见 Related files）
