## 决策场景
构造具备唯一性、不可预测性且含业务标识（如手机号）的字符串ID

## 决策内容
采用「固定长度随机前缀 + 业务字段」组合方式，例如6位随机数 + 手机号，确保全局唯一、抗猜测、类型兼容

## 适用范围
需要生成唯一ID且要求包含可识别业务信息（如用户手机号、身份证号片段）的系统设计
