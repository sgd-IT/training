开发语言: Java 8

核心框架与组件：
- Spring Boot 2.1.13.RELEASE（基础框架）
- Spring 5.3.39（核心容器）
- MyBatis-Plus 3.2.0（ORM）
- Sharding-JDBC 4.0.0-RC2（分库分表）
- Activiti 7.1.0.M4（工作流）
- Swagger 2.7.0（API文档）
- FastJSON 1.2.70（JSON处理）
- 多云对象存储：七牛、阿里云OSS、腾讯云COS
- 第三方SDK：微信支付、支付宝、百度OCR、腾讯云、个推、MQTT、Netty
