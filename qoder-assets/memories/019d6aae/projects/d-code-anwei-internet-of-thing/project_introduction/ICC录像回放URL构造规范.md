ICC录像回放URL参数规范：
- 设备编码：取通道编码第一个'$'前的内容，并做URL编码（如'1000001$1$0$1'→'1000001'）
- 通道号：取通道编码最后一个'$'后的数字（如'1000001$1$0$50'→'50'）
- 码流类型：1为主码流，2为辅码流
- 中心录像类型：1普通/2报警/81补录/82报警预录；设备录像类型固定为0
- 时间约束：startTime与endTime不得跨录像文件（ICC按固定时长切片存储）
