大华ICC拉流接口的码流类型由`bz_camera`表的`quality`字段决定：
- `quality = "1"` → 主码流（streamType=1）
- `quality` 为其他任意值（含`"2"`、空、null等）→ 辅码流（streamType=2）
- 若数据库未查到Camera记录，`getHuifang()`方法兜底使用`quality = "2"`（辅码流）
