## 任务描述
为支持海康与大华ICC双平台摄像头拉流，改造视频地址获取接口，实现根据数据库字段 `pullType` 动态路由至对应厂商SDK。

## 执行过程
```mermaid
graph TD
    A[前端请求 /geturl 或 /getAlarmPopUpWindowVideoUrl] --> B[后端查 bz_camera 表获取 Camera 实体]
    B --> C[判断 camera.getPullType()]
    C -->|pullType == 1| D[调用 getDahuaVideoUrl]
    C -->|pullType == 0 or null| E[调用 hikVisionUtil.getVideoUrl]
    D --> F[iccDeviceService.getDeviceDetail(deviceCode)]
    F --> G[遍历 units/channels 匹配 channelSeq == channelNo 得 channelCode]
    G --> H[构建 VideoStreamRequest 并调 getRealtimeStream]
    H --> I[返回 HLS 视频流 URL]
    E --> J[直接调海康云API返回URL]
```

## 任务总结
成功实现双平台拉流适配：在 CamerasController 和 MonitorCenterController 中新增 `getVideoUrlByPullType` 统一分支逻辑，封装 `getDahuaVideoUrl` 完成大华ICC设备详情查询、通道匹配、流地址生成全流程；`getHuifang` 接口对大华返回空提示；所有修改通过编译且无语法错误。
