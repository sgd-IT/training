## 任务描述
为支持海康与大华ICC双平台拉流，改造视频地址获取接口，实现根据企业配置 `Customer.pullType` 动态路由至对应厂商SDK。

## 执行过程
```mermaid
graph TD
    A[前端请求 /camera/geturl 等拉流接口] --> B[后端通过 camera.customerId 查询 Customer 实体]
    B --> C[判断 customer.getPullType()]
    C -->|pullType == 1| D[调用大华ICC SDK：iccDeviceService.getRealtimeStream]
    C -->|pullType == 0| E[调用海康云API：hikVisionUtil.getVideoUrl]
    D --> F[返回 HLS 视频流 URL]
    E --> F
```

## 任务总结
完成拉流方式企业级升级：所有拉流接口（/camera/geturl、/camera/geturlStr、/camera/getHuifang、/mon/getAlarmPopUpWindowVideoUrl）均从Customer维度读取pullType；新增企业级配置接口 /bz/camera/getPullType 和 /bz/camera/setPullType；新摄像头自动继承所属企业pullType。
