Bug class: 批量API调用可靠性缺陷
Root cause: getDmpkDeviceIds()方法未过滤null/empty deviceCode，DanMaiPaiKe.SendInfo()将所有设备编码打包为一个JSON数组并一次性发送，DMPK平台对任意无效设备编码返回整体失败。
Fix pattern: 在getDmpkDeviceIds()中过滤掉null和空字符串的deviceCode；或重构SendInfo()为逐设备独立调用，实现故障隔离。
Reusable lesson: 不要将未经验证的设备编码列表直接打包发送给批量API，因为单个无效项会导致整批失败；而应在发送前过滤无效项，或改用逐项调用。适用于任何批量API调用场景（如批量设备控制、批量数据推送）；不适用于单设备API调用场景。
