## 任务描述
针对非法入侵报警TTS不响且无日志的“静默失败”问题，在AlramInfoServiceImpl中补全关键跳过路径的日志。

## 执行过程
```mermaid
graph TD
    A[问题:非法入侵不响+无日志] --> B[代码诊断：grep+read定位静默点]
    B --> C[识别5类静默路径：@Async异常吞掉、speaker调用无try-catch、车闸无syncId跳过、save条件不满足跳过、查询无记录跳过]
    C --> D[聚焦第3、4类：车闸无syncId分支 & save入口alarmStatus非0分支]
    D --> E[编写SearchReplace补全日志：记录报警ID、deviceCode、跳过原因]
    E --> F[执行修改并验证diff：+6行，精准覆盖目标位置]
```

## 任务总结
成功补全两处关键静默路径日志：1）车闸无syncId时记录报警ID和deviceCode；2）save成功但alarmStatus非0时记录跳过原因及alarmType。使“跳过播报”行为可观测，显著提升故障排查效率。
