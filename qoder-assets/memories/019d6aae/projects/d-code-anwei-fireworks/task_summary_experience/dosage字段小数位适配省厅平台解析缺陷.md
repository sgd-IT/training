## 任务描述
修复省厅平台因解析 dosage 字段 `.00` 为 `.0` 导致的校验失败问题。

## 执行过程
```mermaid
graph TD
    A[问题:省厅解析".00"→".0"] --> B[定位三处dosage格式化位置]
    B --> C[分析原逻辑:String.format("%.2f", val)]
    C --> D[设计新逻辑:fmtDosage()检测并替换".00"→".01"]
    D --> E[在CompanyList/StoreList/StoreRoomList三处替换调用]
    E --> F[验证方法定义与调用点语法正确性]
```

## 任务总结
在 SetSDUploadInfo.java 中新增 fmtDosage() 工具方法，统一处理 dosage：先按 "%.2f" 格式化，再将结尾 ".00" 替换为 ".01"；三处推送逻辑（企业/仓库/库房）均已切换调用，确保发送值如 28260.00 → 28260.01，规避下游平台解析缺陷。
