## 任务描述
为预警信息推送（EarlyWarningInfoPushRecord）增加丹唛派克语音播报能力，并确保预警播报固定为1次，区别于报警的可配置重复次数。

## 执行过程
```mermaid
graph TD
    A[需求:预警保存后播报且固定1次] --> B[分析现有报警播报链路]
    B --> C[确认AlramInfoService缺少指定次数接口]
    C --> D[第一轮：扩展接口+注入+调用]
    D --> E[发现无法区分预警/报警播报次数]
    E --> F[第二轮：新增三参重载方法]
    F --> G[AlramInfoServiceImpl中两参方法委托至三参]
    G --> H[三参方法用repeatCount控制循环]
    H --> I[TopicMethonUtil调用时显式传入1]
```

## 任务总结
成功实现预警语音播报差异化控制：在AlramInfoService新增三参重载方法，AlramInfoServiceImpl统一委托并用参数驱动播报次数，TopicMethonUtil调用时传入1，确保预警仅播报1次，报警仍沿用voiceRepeatCount配置。
