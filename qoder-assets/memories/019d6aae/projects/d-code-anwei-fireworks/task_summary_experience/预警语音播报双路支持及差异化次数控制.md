## 任务描述
为预警超阈值场景同时支持华皓音柱与丹唛派克双路语音播报，并确保华皓固定播报1次、丹唛派克按配置重复播报。

## 执行过程
```mermaid
graph TD
    A[需求:华皓音柱也需预警播报] --> B[读取AlramInfoService/Impl/TopicMethonUtil分析现状]
    B --> C[发现sendAlarmVoice已从接口移除且逻辑统一]
    C --> D[接口AlramInfoService.java重新添加三参sendAlarmVoice方法]
    D --> E[TopicMethonUtil.java注入AlramInfoService并调用sendAlarmVoice(..., 1)]
    E --> F[确认双路行为分离：华皓走repeatCount=1路径，丹唛派克保持voiceRepeatCount配置]
```

## 任务总结
成功实现双路语音播报差异化控制：在AlramInfoService中恢复sendAlarmVoice(List, String, int)接口，在TopicMethonUtil中注入并调用该接口传入repeatCount=1，使华皓音柱固定播报1次，而丹唛派克仍按原有voiceRepeatCount配置执行。
