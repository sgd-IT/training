## Task description
- Core requirement: 实现非法入侵报警（alarm_type=4）的语音播报间隔/去重逻辑，并完成代码提交
- Task background: 当前代码中非法入侵报警每次入库都触发语音播报，无任何间隔控制或去重机制；记忆中描述的复杂逻辑（3分钟窗口、syncId检查、Redis去重、固定2次播报）尚未实现；用户要求简化为2分钟窗口、device_code长度区分车闸/人闸、固定2次播报

## Execution process
1. AlramInfoServiceImpl.save()方法：增加alarm_type==4判断，调用sendIllegalIntrusionVoice()替代原有逻辑
2. sendIllegalIntrusionVoice()方法：查询最近2分钟内该企业的未消警非法入侵记录，选择一条进行播报
3. isCarPlateLength()辅助方法：通过device_code长度（7或8位）区分车闸/人闸
4. 丹唛派克语音播报逻辑：固定播报2次，不受voiceRepeatCount配置影响
5. 全链路添加[语音播报]日志，便于排查问题
6. DanMaiPaiKe日志从System.out.println改为slf4j
7. git pull origin prod拉取最新代码
8. git add并git commit -m "feat: 非法入侵报警语音播报逻辑重构，固定2次播报，添加全链路日志"
9. git push origin prod推送至远程仓库
