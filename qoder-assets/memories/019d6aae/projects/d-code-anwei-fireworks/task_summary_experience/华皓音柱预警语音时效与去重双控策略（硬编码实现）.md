## 任务描述
为华皓音柱预警语音播报增加双重控制逻辑：① 数据同步时间距当前超过80秒（WARNING_MAX_AGE_SECONDS=80）则跳过播报；② 同一企业30秒内（VOICE_RATE_LIMIT_SECONDS=30）只播报一次（Redis原子去重）。

```mermaid
    B --> C[定位TopicMethonUtil.setLocalAlarmInfo入口]
    C --> D[确认RedisUtils.setNx可用性及签名]
    D --> E[修改TopicMethonUtil.java：添加Redis依赖与硬编码常量]
    E --> F[扩展setLocalAlarmInfo参数，传入syncTime]
    F --> G[插入时效检查：now - syncTime > 80s?]
    G --> H[插入Redis去重：setNx(alarm:voice:ratelimit:{companyCode}, 30s)]
    H --> I[两者均通过才调用sendAlarmVoice]
```

## 任务总结
成功实现预警语音双控策略：1）时效性由硬编码常量 WARNING_MAX_AGE_SECONDS=80 控制；2）去重由硬编码常量 VOICE_RATE_LIMIT_SECONDS=30 与 Redis `setNx` 原子操作保障；3）预警记录始终保存，仅语音播报受控；4）Key 按企业隔离，多线程安全。
