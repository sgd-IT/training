## 任务描述
修复山东平台企业推送逻辑，避免误推非山东企业（如内蒙古银山商贸有限责任公司）。

## 执行过程
```mermaid
graph TD
    A[问题:山东推送含非山东企业] --> B[定位PushingSDDataService.forEachCompany方法]
    B --> C[发现QueryWrapper缺少upload_company_code前缀过滤]
    C --> D[确认应限制为"37"开头的山东编码]
    D --> E[在QueryWrapper中新增.likeRight\(Information::getUploadCompanyCode, "37"\)]
```

## 任务总结
在PushingSDDataService.java的forEachCompany查询中，补充了.upload_company_code LIKE '37%' 条件，确保仅推送山东省企业（编码以37开头），杜绝跨省误推。
