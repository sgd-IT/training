## 任务描述
实现音柱设备的企业级隔离播报：当通过/em/gateDeviceInfo/save添加音柱后，报警语音仅向该企业关联的音柱设备（device_type=5/6且access_status=1）定向播报。

```mermaid
    B --> C[分析现有sendAlarmVoiceForSingle/sendAlarmVoice逻辑]
    C --> D[发现缺失companyCode传递与设备过滤]
    D --> E[设计三步改造：①传参升级 ②设备查询 ③定向调用]
    E --> F[在sendAlarmVoiceForSingle中传入a.getCompanyCode()]
    F --> G[重载sendAlarmVoice增加companyCode参数并集成设备查询]
    G --> H[新增getVoiceDeviceIds方法：按company_code+device_type+access_status查询em_gate_device_info]
    H --> I[修改speakerService调用：设置vo.setSelectedDeviceId(deviceId)]
```

## 任务总结
成功实现企业级音柱隔离播报：在AlramInfoServiceImpl中增强sendAlarmVoiceForSingle与sendAlarmVoice方法，新增getVoiceDeviceIds工具方法，通过companyCode精准筛选华皓/DMPK音柱设备，并利用device_code作为selectedDeviceId完成定向TTS广播。
