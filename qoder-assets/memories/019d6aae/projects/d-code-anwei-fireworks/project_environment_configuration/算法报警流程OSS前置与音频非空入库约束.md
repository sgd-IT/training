算法触发报警时，语音播报成功但数据库无记录的根本原因是：OSS上传（getOSSImageUrl）在入库操作之前执行，若该步骤抛出异常，则整个流程中断，不会进入后续的数据库保存和语音播报逻辑。

音频相关数据的入库约束：无音频文件或音频文件字段为空的数据不允许入库，此类记录应在入库前被过滤或拦截。
