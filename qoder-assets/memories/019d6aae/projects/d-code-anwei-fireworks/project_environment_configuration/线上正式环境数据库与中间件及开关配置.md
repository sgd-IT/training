线上正式环境配置包含：
- MySQL数据库：`jdbc:mysql://127.0.0.1:3306/anwei_mon_fireworks_local`，账号root/root
- Redis：`open:true`，`host:localhost`，`port:6379`
- WebSocket：`socketUrl:ws://139.196.197.176/api/websocket/notify/`
- 第三方API：`qing-tian.host:https://g.qtck.work/park-data-api`，`yn-upload-jg.url:https://220.163.82.253:5321`
- 开关配置：`monkey.isupload_gz:true`，`redis.open:true`，`alarm-voice.repeat-count:5`
- 路径配置：`monkey.data.file.path:D:/data/local/tmp`

## Notes
- MQTT（local / sensor 模块）的 host、端口、账号等以「prod环境MQTT服务配置」记忆为准，本条不再重复。
- 本条 MySQL 连接指向**本地部署形态**（127.0.0.1 / anwei_mon_fireworks_local）。项目 prod 分支 `application-prod.yml` 配置的云端生产库实为腾讯云 CDB：`gz-cdb-dnqlqqwx.sql.tencentcdb.com:60477`，库名 `anwei_mon_fireworks`；测试库为 `175.178.237.103:26671/anwei_mon_fireworks`。用 MySQL 8.x 客户端直连该旧版实例须加 `--ssl-mode=DISABLED`，否则报 SSL unsupported protocol。排查线上数据时勿误用本条的 127.0.0.1 配置。
