技术栈：
- 开发语言：Java 8
- Web框架：Spring Boot 2.1.13.RELEASE / Spring Cloud Greenwich.SR6
- ORM：MyBatis-Plus 3.2.0
- 数据库驱动：MySQL Connector J 9.1.0
- 网络通信：Netty 4.1.115.Final (用于JT808协议)
- 任务调度：XXL-Job 2.4.0
- 工作流引擎：Activiti 7.1.0.M4
- 分库分表：Sharding-JDBC 4.0.0-RC2
- 动态数据源：dynamic-datasource-spring-boot-starter 3.3.1
- 文档生成：Swagger 2.7.0
- JSON处理：Fastjson 1.2.70, Jackson 2.9.10.8
- 对象存储：七牛云、阿里云OSS、腾讯云COS
- PDF处理：iTextPDF 5.5.13, PDFBox 2.0.15
- Excel处理：EasyExcel 2.1.6
- 二维码：ZXing 3.3.0
