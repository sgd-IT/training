音柱定向播报改造核心设计：
1. 从 em_gate_device_info 按 company_code + device_type IN (5,6) 查询企业音柱设备
2. device_type=5 为华皓音柱，device_type=6 为丹唛派克音柱
3. 数据库中 device_code 可能为逗号分隔多值（如"9C0CA428,B270E069,9E9AB31B"），需 flatMap + split(",") + trim 拆分
4. 华皓：通过 SpeakerVo.selectedDeviceId 设值后调原有 startTTSBroadcast(vo)，无需改 SpeakerService/SpeakerServiceImpl
5. 丹唛派克：新增 DanMaiPaiKe.SendInfo(String text, List&lt;String&gt; targetDeviceCodes) 方法支持指定设备编码
6. 只需改 AlramInfoServiceImpl + DanMaiPaiKe + GateDeviceInfo（deviceTypeStr），SpeakerService层无需修改
