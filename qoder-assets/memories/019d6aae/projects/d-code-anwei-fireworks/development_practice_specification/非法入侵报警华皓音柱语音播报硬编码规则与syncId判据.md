非法入侵报警（alarm_type=4）的语音播报硬编码规则仅适用于华皓音柱：以 syncId 是否为空作为判断车闸/人闸同步数据的唯一可靠依据——syncId 为空时跳过播报，有 syncId 即视为同步数据直接触发播报；报警时间距当前超过1分钟视为过期；固定播报2次。禁止改用额外数据库查询来判断是否播报，避免因事务未提交或时序问题导致静默跳过。该规则不适用于丹唛派克音柱，后者须严格维持原有配置驱动逻辑，禁止应用任何硬编码干预。
