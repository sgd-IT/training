为适配省厅平台对小数位的特殊解析规则（将'.00'识别为'.0'导致校验失败），所有dosage字段的数值格式化必须将'.00'结尾强制替换为'.01'，确保发送JSON中dosage值的小数部分始终为'.01'而非'.00'。
