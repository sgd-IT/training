辨别Spring异步线程池耗尽问题的关键线索：①堆栈中出现TaskRejectedException/RejectedExecutionException + AsyncExecutionInterceptor + 具体业务类名；②ThreadPoolExecutor状态中pool size = active threads且queued tasks > 0；③裸@Async（未指定执行器名称）方法触发时，默认执行器容量不足是主因；④需检查AsyncConfig是否定义了@Primary默认执行器。
