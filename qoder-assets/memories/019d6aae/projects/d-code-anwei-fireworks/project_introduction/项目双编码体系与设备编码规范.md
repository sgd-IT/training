项目采用双编码体系：
- 数据库内部使用`company_code`（如`5202814103`）组织数据；
- 向省平台推送时使用`upload_company_code`（如`520281920001`）；
- 仓库编码`store_num`、库房编码`storeroom_num`均由`upload_company_code`派生（如`520281920001101`）；
- 设备编码`device_code`在数据库中存储为简单序号（`1`, `2`, `3`, `4`），非全量GZ编码。
