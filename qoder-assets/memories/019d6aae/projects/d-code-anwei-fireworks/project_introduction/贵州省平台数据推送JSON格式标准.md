贵州省平台数据推送采用标准化JSON格式，包含JCXX（企业基础）、RYXX（人员）、CKXX（仓库）、KFXX（库房）、FWQXX（服务器）、SBDY（设备）、ZBDY（指标）、ZBSS（实时数据）、ZBBJ（报警）、BJCZ（报警处置）、RYCRJL（人员出入）、CLCRJL（车辆出入）共12类数据；所有编码遵循统一规则：企业编码（52开头12位）、仓库编码（企业编码+2位序号）、库房编码（仓库编码+3位序号）、设备编码（企业编码+设备类型01/02+4位流水号）、指标编码（设备编码+001/002）。
