项目数据存在严格级联依赖关系：CKXX（仓库）是顶层基础数据，KFXX（库房）依赖CKXX的store_num，SBDY（设备）依赖KFXX的storeroom_num，ZBDY（指标）依赖SBDY的device_code。若前置表（如CKXX）缺失或无效，则后续所有关联表（KFXX/SBDY/ZBDY/ZBSS/ZBBJ/BJCZ）均会触发级联校验失败。因此数据修复必须严格按CKXX → KFXX → SBDY → ZBDY → ZBSS/ZBBJ/BJCZ顺序执行。
