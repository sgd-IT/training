项目对接山东平台的数据格式规范：
- 数值型字段（如storeroomArea、reservoirArea）必须精准保留2位小数（例如"2016"→"2016.00"）
- 企业信息JSON中必须包含deleted字段，取值为company.getDeleteFlag()（null时默认0）
- 所有socialCredit相关字段（socialCreditFile、socialCreditEstablished等）及principalPersonPhone、safetyPerson、safetyPersonPhone均为必填项，空值将导致整条记录校验失败
