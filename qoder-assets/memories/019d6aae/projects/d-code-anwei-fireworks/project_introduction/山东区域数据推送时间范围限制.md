山东（SD）区域的数据推送服务仅处理最近三天内的数据，所有相关推送方法（人员、仓库、库房、设备、服务器、报警、温湿度、人员进出、车辆进出）均需添加对应时间字段的'最近三天'过滤条件，企业基本信息（saveCompany）除外。
