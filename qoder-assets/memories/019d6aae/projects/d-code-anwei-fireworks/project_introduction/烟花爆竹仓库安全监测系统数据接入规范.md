项目为烟花爆竹企业仓库安全风险监测预警系统，遵循《数据接入规范-V1.3》：
- 设备编码（equip_code）为18位：企业编码(12位)+设备类型(2位)+流水号(4位)，如温度传感器`520281920001010001`、湿度传感器`520281920001020002`；
- 指标编码（target_code）为21位：设备编码+指标流水号(3位)；
- ZBSS实时数据推送必须使用18位equip_code，频率为每5分钟全量上传；
- 推送失败根因为温湿度表device_code字段错误存为设备类型值（3/4），而非规范要求的18位编码。
