项目报警类型共8种，按业务语义划分为3个大类：1. AI智能分析报警（alarmType=1,2,3）、2. 入侵报警（alarmType=4,7,8）、3. 设备异常（alarmType=5,6）。该分组已通过AlarmCategoryEnum枚举固化，用于后端查询时将alarmCategory映射为alarmType列表进行IN查询。
