项目预警语音播报新增双重控制策略：
- 时效性：数据同步时间（syncTime）距当前超过80秒（1分20秒）则跳过语音播报，但预警记录仍保存；
- 频次限制：同一企业30秒内只允许触发一次语音播报，通过Redis setNx原子操作实现去重；
- 两者叠加效果：在80秒有效窗口内最多播报2次（约0s和30s）。
