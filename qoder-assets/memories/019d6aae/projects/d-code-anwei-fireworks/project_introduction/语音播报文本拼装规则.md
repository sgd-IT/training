语音播报文本拼装逻辑如下：
- 前缀固定为'警告，'（硬编码）
- 主体内容根据报警类型动态生成：非法入侵类为'公司名发生报警类型'，其余为'设备名发生【报警类型】'
- 多条消息用分号';'连接
- 每次重复播报追加零宽空格\u200B以绕过去重
- 数据来源包括information表（公司名）、device_yh_info/em_gate_device_info表（设备名）、AlramInfo实体（报警类型描述）
