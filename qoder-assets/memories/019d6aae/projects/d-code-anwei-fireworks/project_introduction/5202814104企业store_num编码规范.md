企业5202814104（upload_company_code: 520123920001）的数据规范要求：所有模块中的store_num字段必须为15位仓库编码（如520123920001101），禁止使用18位库房编码（如520123920001101001），否则会导致KFXX/SBDY/ZBDY/ZBSS/ZBBJ等模块因编码不匹配而报错。
