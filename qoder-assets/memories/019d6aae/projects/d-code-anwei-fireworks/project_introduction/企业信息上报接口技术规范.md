企业信息上报接口规范:
- 接口路径: `/v2/data/receive/yhbz/CompanyList`
- 请求方式: POST
- 请求头: `Content-Type:application/json;charset=utf8`、`Authorization:加密后的请求头`
- 核心字段: `companyCode`(省平台统一下发的企业编码，必填且不可自编)、`socialCreditCode`(统一社会信用代码)、`socialCreditFile`(营业执照base64图片)、`businessLicense`(经营许可证编号)、`businessLicenseFile`(许可证base64图片)、`longitude`/`latitude`(经纬度，保留6位小数)等
- 关键业务规则: 所有推送必须使用省平台提供的`upload_company_code`作为`companyCode`
