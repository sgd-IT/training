项目已切换至新分支，采用纯丹唛派克（DMPK）语音播报方案：
- 移除华皓音柱支持与定时轮询任务（pollIllegalIntrusionForVoice）
- 移除配置文件兜底逻辑（dmpk.deviceCode），设备列表严格按 company_code + device_type=6 从数据库查询
- 生产环境 dmpk.isopen=true，dmpk.deviceCode=9C0CA428，alarm-voice.repeat-count=5
- DanMaiPaiKe类精简为单SendInfo重载，volume=40，日志使用slf4j（log.info/log.warn/log.error），异常处理简化
