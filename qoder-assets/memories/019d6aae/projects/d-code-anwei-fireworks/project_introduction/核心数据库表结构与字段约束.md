项目核心数据库表结构定义：
- em_warehouse（仓库表）：包含company_code、store_name、store_num、acreage、danger_level、dosage、person_limit、created_by、modified_by、created_date、modified_date、delete_flag等必填字段，示例记录中modified_date已正确填充；
- em_storeroom（库房表）：包含company_code、store_num、storeroom_name、storeroom_num等必填字段，其中storeroom_num需严格基于归属store_num生成（如store_num=520281920001102 → storeroom_num前缀必须为520281920001102）。
