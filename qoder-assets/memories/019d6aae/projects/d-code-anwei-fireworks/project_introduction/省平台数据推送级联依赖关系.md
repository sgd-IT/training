项目数据推送存在严格的级联依赖关系：
- CKXX（仓库）必须先注册成功
- KFXX（库房）依赖CKXX的`store_num`字段
- SBDY（联网设备）依赖KFXX的`storeroom_num`字段
- ZBDY（联网指标）依赖SBDY的`device_id`字段（生成`device_id_T`/`device_id_H`）
- ZBSS（指标实时）依赖SBDY的`device_id`和ZBDY的`target_code`
该链路决定了SQL补全UUID和XXL-JOB推送任务的执行顺序。
