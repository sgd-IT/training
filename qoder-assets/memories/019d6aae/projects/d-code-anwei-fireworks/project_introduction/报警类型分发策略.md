项目报警类型处理策略：
- alarm_type=1/2/3/5：全部走`save()`主路径，经`voiceMaxAgeMinutes`时效检查后调用`sendAlarmVoiceForSingle`播报`voiceRepeatCount`次；
- alarm_type=4（非法入侵）：单独走`handleIllegalIntrusionAlarms`分支，按syncId和设备类型分流至轮询或人闸兜底路径。
