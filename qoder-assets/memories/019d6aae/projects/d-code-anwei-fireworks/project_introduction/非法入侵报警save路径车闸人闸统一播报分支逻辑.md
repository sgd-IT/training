非法入侵报警（alarm_type=4）语音播报在 AlramInfoServiceImpl.save 中统一处理车闸与人闸，判据与 c98697b4 硬编码规则保持一致：

1. 以 syncId 是否为空作为区分同步数据（车闸/人闸同步）的唯一可靠依据——有 syncId 视为同步数据直接触发播报，固定播报 2 次（不受 voiceRepeatCount 影响）；syncId 为空时跳过播报。禁止改用"额外数据库查询最近记录"来判断是否播报，避免事务未提交或时序问题导致静默跳过。
2. 报警时间距当前超过时效阈值（如 1 分钟）视为过期，不再播报。
3. 车闸 device_code 为车牌号码（7位油车/8位新能源），由外部系统同步直写数据库（见 301e2cc6），save 方法须能覆盖到这些直写记录的播报。

注意：上述硬编码规则仅适用于华皓 IP 音柱；丹唛派克音柱须维持原有配置驱动逻辑，禁止施加硬编码干预。
