丹唛派克模块采用分层调用结构：应用层（AlramInfoServiceImpl、AlramInfoService、TestDanMaiController）负责调用和编排，底层工具类（DanMaiPaiKe、DMPKEntity、DMPKResponse）仅作为被依赖组件；只要应用层代码被注释/移除，底层类虽仍存在但无任何调用入口，自动失效，无需额外注释。
