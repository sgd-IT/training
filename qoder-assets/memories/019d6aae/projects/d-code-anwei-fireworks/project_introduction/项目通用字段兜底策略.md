项目通用字段兜底策略：
- 所属行政区划编码为空时，默认使用贵州省编码'52'
- 设备型号为空时，生成6位随机字母数字字符串
- 设备品牌为空时，默认为'大华ICC'
- 经度/纬度为空或值为0时，统一使用企业信息中的经纬度
- 修改人为空时，默认为'test'；修改时间为空时，默认为当前时间
- 部署算法为空时，默认为'201,202,203,204,205'
