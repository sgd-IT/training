项目中报警语音时效阈值和去重间隔配置不再通过@Value从配置文件读取，而是使用硬编码常量：
- WARNING_MAX_AGE_SECONDS = 80（1分20秒）
- VOICE_RATE_LIMIT_SECONDS = 30（30秒）
