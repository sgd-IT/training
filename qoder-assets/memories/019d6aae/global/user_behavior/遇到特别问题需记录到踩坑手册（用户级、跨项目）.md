用户级约定，适用于所有项目，不限于 remote-monitor：工作中遇到特别或疑难问题（含会再犯、可复用的坑）时，要同步记录到当次 work-log 数据目录的 03-踩坑手册.md，而不是只口头说明或留在线程里。手册位置按 work-log skill 的数据目录规则定位：优先当前工作区根目录下的 work-log/，不存在时用 d:\code\remote-monitor\work-log\（跨项目共用）。记录遵循手册既有规范：分区固定为后端（Java/Spring）、前端（Vue/UniApp）、数据库（MySQL/Redis）、基础设施/部署、AI 应用（LLM/Agent）、其他；条目标题用 H3，正文四行——问题 / 根因 / 触发条件 / 做法；写纯结论，一次性环境问题（密码错了、服务没启动）不记。该规则已同步写入用户级 work-log SKILL.md。
