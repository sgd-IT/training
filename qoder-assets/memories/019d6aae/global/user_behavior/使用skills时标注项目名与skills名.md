使用 skills 时，输出开头需标注【项目名·skills名】：项目名取当前工作区根目录名（如 hc-standard、remote-monitor），skills 名为对应 skill 名称（如 work-log、pdf、database-design）。示例：【hc-standard·work-log】。该约定已写入用户自定义 skill（work-log、code-conciseness-check、decision-driven-coding、hand-typing-training、project-map、code-comment-style）的 SKILL.md。
