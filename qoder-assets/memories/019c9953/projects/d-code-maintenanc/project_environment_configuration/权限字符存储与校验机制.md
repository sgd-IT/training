项目权限字符（如weibao:standardItem:list）存储在数据库sys_menu表的perms字段中；用户登录时，系统从sys_menu表读取其角色关联的所有perms值并加载到Sa-Token会话缓存；接口上@SaCheckPermission注解通过比对缓存中的权限字符串完成运行时校验。
