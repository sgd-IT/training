## Goal
在维保模块中实施计划-任务-工单三级状态与进度联动，并完成标准项与计划的多对多关联；适用于同类业务模块（如巡检、检测）的跨实体联动改造

## Steps
Step 1: Phase 1 - 清理冗余字段：统一并删除重复的状态/周期/责任人字段，确保模型语义清晰
Step 2: Phase 2 - 增强执行实体：为任务实体新增planId/deviceId/executorId等关键字段，建立与计划的显式关联
Step 3: Phase 3 - 实现进度反馈：工单完成时反馈任务进度，任务完成时联动刷新计划进度
Step 4: Phase 4 - 设备日期联动：计划完成时自动刷新设备lastMaintenanceDate和nextPlanDate
Step 5: Phase 5 - 维保记录联动：工单完成时自动生成wb_maintenance_log记录
Step 6: Phase 6 - 标准项关联：新建中间表WbPlanStandardItem，支持计划与标准项多对多关联

## Notes
- 跳过Phase 1清理冗余字段会导致后续阶段状态混乱；必须先统一模型语义
- Phase 2未增强任务实体则无法建立计划-任务关联；必须先完成实体建模再实现业务逻辑
- Phase 6已完整落地：WbPlanStandardItem实体、Mapper、Service、前端多选下拉、SQL脚本均已实现，非仅'新建'概念
