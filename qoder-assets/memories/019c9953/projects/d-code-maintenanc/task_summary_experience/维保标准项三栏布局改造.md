## Task description
- Core requirement: 实现维保标准项三栏布局功能（左栏标准规范、中栏设备分类、右栏维保项目明细），支持层级编码、重要等级标识（A/B/C）及GB标准对标
- Task background: 现有wb_standard_item表缺少inspect_type/maintenance_type/guidance/importance字段；前端index.vue为旧版单列表；需新增SQL迁移脚本、后端服务层level过滤支持、前端API与三栏页面重写，并完成菜单配置与权限校验

## Execution process
1. 数据库：执行ALTER TABLE添加4个新字段，并INSERT示例数据（GB25201/GB50166等标准及子项）
2. 后端：修改WbStandardItem.java/WbStandardItemBo.java/WbStandardItemVo.java新增4个字段；更新WbStandardItemServiceImpl.java的buildQueryWrapper支持level/category过滤
3. 前端：新增types.ts/index.ts定义新字段类型与API；重写index.vue为三栏布局（左栏标准搜索、中栏设备分类联动、右栏表格渲染+重要等级色标+子项└缩进）
4. 权限：菜单配置中设置上级菜单为'标准管理'、路由地址'standardItem'、组件路径'weibao/standard/item/index'、权限字符'weibao:standardItem:list'
5. 验证：确认菜单显示正常、三栏数据联动正确、重要等级A/B/C颜色标识生效、子项缩进渲染无误
6. 提交：分批提交后端与前端变更
