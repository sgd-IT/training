## 任务描述
修复维修单模块 TS2339 字段不存在错误及 prettier 格式问题，实现前端字段与后端 WbRepairOrderVo/WbRepairOrderBo 实体完全对齐。

## 执行过程
```mermaid
graph TD
    A[TS报错: repairNo/urgencyLevel等不存在] --> B[全局搜索repair相关文件]
    B --> C[定位index.vue视图与types.ts类型定义]
    C --> D[读取后端WbRepairOrderVo.java/WbRepairOrderBo.java确认真实字段]
    D --> E[比对发现字段名不匹配：repairNo→orderNo, urgencyLevel→level等]
    E --> F[修正types.ts中RepairOrderVO/RepairOrderForm/RepairOrderQuery接口]
    F --> G[重写index.vue模板：字段绑定、搜索条件、下拉选项、el-button/el-date-picker换行格式]
    G --> H[参照system/dict/index.vue等已有prettier换行规范统一格式]
```

## 任务总结
成功修复维修单模块：1）types.ts 中 RepairOrderVO/RepairOrderForm/RepairOrderQuery 全部按后端 VO/BO 字段重定义；2）index.vue 视图彻底重构，移除无效字段（reporterName/planFinishTime等），补充必填字段（deviceId/source），Tab筛选改为 level 值驱动，状态文案与后端枚举严格一致；3）所有 el-button/el-date-picker 等长标签按项目既有 prettier 规范换行。
