## Task description
- Core requirement: 修复维保计划新增页面中客户/设备无法关联、负责人下拉为空、计划分类变更时起止日期未自动填充的问题
- Task background: 维保计划模块已存在，但表单中customerOptions、deviceOptions、userOptions仅声明未加载；缺少handleCategoryChange逻辑；编辑已有计划时设备列表不回显

## Execution process
1. 定位问题：读取index.vue发现三个下拉选项变量均未加载数据
2. 确认API可用：检索并确认listCustomer/listDevice/listTeamMember API均已实现且可用
3. 导入API并添加加载逻辑：在index.vue中导入三个API，并新增loadCustomerOptions/loadDeviceOptions/loadUserOptions函数
4. 实现分类日期计算：新增handleCategoryChange函数，根据月/季/年分类设置对应日期
5. 修复编辑回显：在getMaintenancePlan后调用loadDeviceOptions，确保编辑时设备列表正确回显
6. 统一初始化：在onMounted中触发三类下拉的初始化加载
