## 任务描述
解决设备界面（设备台账）空白问题，根本原因为前端菜单组件路径配置错误，导致动态路由无法加载对应 .vue 文件。

## 执行过程
```mermaid
graph TD
    A[用户反馈设备界面空白] --> B[全局搜索设备相关Vue文件]
    B --> C[定位到views/weibao/device/index.vue存在]
    C --> D[查询数据库sys_menu表获取菜单配置]
    D --> E[发现menu_id=1901300000000000000的component值为'weibao/deviceAsset/index']
    E --> F[比对实际文件路径，确认应为'weibao/device/index']
    F --> G[确认前端import.meta.glob('views/**/*.vue')机制依赖路径精确匹配]
    G --> H[输出SQL修复语句：UPDATE sys_menu SET component = 'weibao/device/index' WHERE menu_id = 1901300000000000000]
```

## 任务总结
成功定位并解决设备台账页面空白问题：核心是菜单表 `sys_menu.component` 字段路径与真实 Vue 文件路径不一致（`deviceAsset` → `device`），导致前端路由加载失败。修复只需更新数据库该字段，无需修改前端代码。
