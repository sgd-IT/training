新增维保工单时，reporterId（上报人）必须由后端通过LoginHelper.getUserId()强制覆盖，忽略前端传值，依据是RuoYi框架安全惯例与身份可信来源原则，防止伪造上报人导致审计链污染、工单号分配作弊及社会工程攻击。
