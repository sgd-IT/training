维保标准项仅定义操作规范（做什么、怎么做、周期），不绑定具体设备；设备关联由后续环节完成：
- 维保计划 → 创建时选择客户及设备
- 维保任务 → 继承计划的设备或自行指定
- 维修工单 → 通过客户级联选择设备
