新增维保工单时，后端仅在 deviceId 非空时调用 WbDeviceMapper 校验其所属 customerId 是否与前端传入的 customerId 一致；若 deviceId 为空，则跳过归属校验。此举确保强关联前提下的灵活性，防止跨客户脏关联，同时兼容设备字段非必填的业务需求。
