维保计划自动生成维保任务的核心逻辑：
- 触发时机：新增计划时为每个关联标准项生成一条任务；编辑计划时仅对新关联的标准项增量生成任务，已有任务保持不变。
- 字段映射：wb_task 的 planId、projectId、customerId、deviceId、executorId、planStartTime、planEndTime、type、month、progress、status 均从维保计划中取值；name 取标准项名称；description 合并标准项的 content 和 guidance。
- 编辑增量控制：通过比对已有任务名称集合，避免重复生成；移除的标准项对应任务不自动删除。
