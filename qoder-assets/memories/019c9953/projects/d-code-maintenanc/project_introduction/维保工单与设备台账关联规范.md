维保工单模块需与设备台账建立强关联:
- 前端新建工单时，设备字段改为下拉选择，按所选客户级联筛选该客户名下的设备列表
- 后端新增工单时校验deviceId必须归属于所选customerId，防止跨客户脏关联
- 设备字段非必填，deviceId为空时跳过归属校验
