维保标准项是系统功能模块，采用三栏布局管理：
- 左栏：维保标准规范列表（如GB 25201、GB 50166），支持搜索
- 中栏：按所选标准展示设备分类列表，与左栏联动
- 右栏：表格展示维保项目明细（序号/维保项/巡检类型/维保类型/维保指导），子项以缩进+『└』前缀表示层级关系
- 重要等级：A(红)/B(黄)/C(蓝)三级标识，对应关键/重要/一般执行级别
