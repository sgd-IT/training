客户管理模块（3.1.4）核心功能：
- 客户列表展示客户名称、联系人、电话、项目地址、设备数、合同状态、到期日，支持按名称/联系人/地址模糊搜索；
- 状态筛选支持全部/正常/即将到期/已过期Tab切换；
- 支持有效客户与作废客户Tab切换；
- 合同即将到期客户需红色闪烁标识（动画提醒）。

设备台账模块（3.1.5）核心功能：
- 设备分类树包含15个大类（消防供水设备、火灾自动报警…智慧感知终端），支持展开/折叠与搜索；
- 设备列表展示编号/名称/类型/位置/状态/健康度/上次维保/下次计划；
- 设备详情以右侧滑出面板形式呈现，含7天健康趋势折线图、维保记录、状态信息；
- 设备状态分为在线(绿)/告警(黄)/离线(红)三色；
- 健康度以百分比+进度条展示，颜色按阈值变化（≥90绿/≥70黄/<70红）。
