维保工单模块核心功能需求：
- 工单列表：展示工单号、设备、位置、来源、故障描述、优先级、负责人、时间、状态，支持排序与筛选；
- 状态Tab切换：全部/待处理/处理中/已完成/已验收，各Tab需带数量统计；
- 新建工单：弹窗表单含设备选择、P1-P4优先级、负责人、来源、故障描述，需表单验证；
- 工单详情：侧滑面板或弹窗形式，含6个Tab（基本信息/故障详情/处理时间线/配件使用/验收记录/关联告警）；
- 工单状态流转：严格按待处理→处理中→已完成→已验收四阶段状态机执行；
- 工单来源：计划维保、值守联动、巡查发现、合规检查、客户报修，以标签形式展示；
- 优先级体系：P1(紧急)/P2(高)/P3(中)/P4(低)，前端需用颜色区分。
