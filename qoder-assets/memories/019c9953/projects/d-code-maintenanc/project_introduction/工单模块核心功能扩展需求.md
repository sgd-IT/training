工单模块需支持以下4项核心功能：
1. 设备关联：工单新建/编辑时，设备选择需从已创建的`wb_device`设备台账表中下拉选择，支持按客户筛选并自动带出设备名称与位置；
2. 工单详情：以侧滑抽屉形式展示6个Tab（基本信息、故障详情、处理时间线、配件使用、验收记录、关联告警），其中前2个Tab展示真实数据，后4个为占位态；
3. 状态流转：基于状态机（0→1→2→3）校验，仅允许顺序流转，提供「处理」「完成」「验收」操作按钮；
4. Tab数量统计：各状态Tab标签动态显示对应数量，通过`/weibao/repairOrder/statusCount`接口按状态分组统计。
