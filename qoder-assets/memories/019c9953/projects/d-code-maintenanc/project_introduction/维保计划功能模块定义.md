维保计划是系统核心功能模块，支持按月度/季度/年度/专项四类分类管理。功能包括：
- 计划列表：卡片式展示（3列网格），含计划编号、名称、日期、负责人、进度、状态
- 分类Tab：支持「全部计划」「月度维保」「季度维保」「年度检测」「专项维保」五类切换筛选
- 进度跟踪：进度条可视化（颜色随进度动态变化）
- AI智能推荐：基于数据分析生成预测性维保建议卡片，含置信度指标（P1优先级）
- 创建计划：弹窗表单，支持选择设备/系统、设定周期、指派人员
