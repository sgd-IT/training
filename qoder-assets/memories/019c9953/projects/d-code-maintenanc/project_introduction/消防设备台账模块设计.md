项目新增消防设备台账模块，对应数据库表`wb_device`，包含设备编号、名称、分类(7种消防设备)、型号、客户、位置、楼栋楼层、厂家、安装/到期/维保日期、状态等核心字段；后端提供CRUD+导出接口(`/weibao/device`)，前端实现设备管理页面（列表+筛选+新增/修改弹窗）；菜单挂载在「维保管理」下，支持查询/新增/修改/删除/导出5种权限。
