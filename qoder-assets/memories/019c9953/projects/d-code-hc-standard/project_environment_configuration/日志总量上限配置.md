所有日志appender均配置了`totalSizeCap`总量上限，防止磁盘被日志撑满：
- sys-info.log: 1GB
- sys-error.log: 500MB
- sys-user.log: 500MB
- sys-gas.log: 500MB
- sys-platment.log: 200MB
