数据推送时，实体字段必须与数据库实际存储字段严格对应。例如：`checkUserId` 应映射数据库 `check_user_id` 字段（值为用户ID列表如"691,693,840"），而非 `create_by`（值为用户名"李小姑"）；`checkUserName` 应映射 `check_user_name` 字段（值为用户名列表如"黄雪晴,李小姑,马燕"），而非 `create_by`。字段映射错误会导致下游平台校验失败（如返回500错误）。
