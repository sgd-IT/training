用户认为 MCP 数据库查询工具（mcp_server_mysql）非常有用，希望在开发过程中灵活使用。适用场景包括：排查数据问题、调试业务逻辑、验证代码修改效果、了解表结构和数据分布以辅助开发决策。遇到需要查看数据库的场景应主动使用 MCP 查询，而非让用户手动查库。
