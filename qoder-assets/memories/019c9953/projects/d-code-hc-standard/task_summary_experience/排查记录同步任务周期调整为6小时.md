## 任务描述
将排查记录的自动同步任务频率从每5分钟一次调整为每6小时一次。


## 任务总结
成功将排查记录同步任务周期由5分钟改为6小时，仅修改 SyncShuangKongTask.java 中 @Scheduled 注解的 fixedDelay 参数，保持 initialDelay 不变，确保服务重启后3分钟首次执行。
