## 任务描述
为包保履职模块实现全量补推功能，支持将本地已存在的PlatementImplementTask数据批量推送至园区平台，并记录同步状态（sync_status）与同步结果（sync_result）。

## 执行过程
```mermaid
graph TD
    A[需求:补推包保履职] --> B[确认数据库表结构，发现无create_time字段]
    B --> C[在PlatementImplementTask.java新增syncStatus/syncResult字段及getter/setter]
    C --> D[更新Mapper.xml：映射新字段、补充select字段、新增updateSyncStatus SQL]
    D --> E[更新Mapper.java接口：声明updateSyncStatus方法]
    E --> F[在PlatementImplementPersonApi.java新增taskBatch批量推送方法]
    F --> G[在PushDataServiceImpl.java实现rePushImplementTask：全量查询+createTime兜底填充+调用API+更新状态]
    G --> H[在PushDataController.java暴露无参POST /push/implementTask端点]
    H --> I[根据平台报错'createTime不能为空'，在Service中增加startTime→createTime的自动填充逻辑]
```

## 任务总结
成功交付包保履职补推功能：支持无参全量推送；通过startTime兜底填充createTime解决第三方平台校验失败；同步状态与结果持久化到数据库；所有修改均经代码审查与逻辑验证。
