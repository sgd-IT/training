## 任务描述
为双控5个子模块（分析对象、风险单元、风险事件、管控措施、任务排查）实现基于@Scheduled注解的定时自动同步功能，替代手动点击「同步」按钮。

## 执行过程
```mermaid
graph TD
    A[需求:定时自动同步双控数据] --> B[确认Spring Scheduling是否启用]
    B --> C[在RuoYiApplication.java添加@EnableScheduling]
    C --> D[为5个Mapper XML添加selectUnsyncedIds SQL]
    D --> E[为5个Mapper接口添加selectUnsyncedIds方法声明]
    E --> F[新建SyncShuangKongTask.java]
    F --> G[注入5个Mapper和5个Service]
    G --> H[编写5个@Scheduled方法，错峰启动+固定间隔]
    H --> I[每个方法：查ID→判空→调sync→日志记录]
```

## 任务总结
成功构建双控定时同步能力：启用Spring调度框架，为5个模块统一扩展了未同步ID查询能力，并通过错峰（30s间隔）+固定周期（5分钟）的5个独立定时任务实现全自动、幂等、可重试的园区平台推送。
