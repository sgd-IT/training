## 任务描述
解决动火/临时用电作业票在开工/完工推送时操作证列表（certificateList）为空导致平台拒绝的问题。

## 执行过程
```mermaid
graph TD
    A[问题:推送时certificateList为空] --> B[grep定位BaseWorkSpecialMapper和ServiceImpl]
    B --> C[读取ServiceImpl确认mapper查主表不加载子表]
    C --> D[对比service方法发现selectBaseWorkSpecialByOuterId含certificateList加载]
    D --> E[调用数据库验证certificate数据实际存在]
    E --> F[定位到endWork第343行和startWork第265行使用mapper而非service]
    F --> G[采用方案一：手动补加载certificateList]
    G --> H[SearchReplace修改两处：266行startWork & 345行endWork]
```

## 任务总结
根因是推送路径误用 mapper 方法（只查主表），未加载 certificateList；修复方式为在 startWork 和 endWork 的 mapper 查询后，显式调用 baseWorkCertificateMapper.selectWorkCertificateList(outerId) 并 set 到实体，确保推送数据完整性。
