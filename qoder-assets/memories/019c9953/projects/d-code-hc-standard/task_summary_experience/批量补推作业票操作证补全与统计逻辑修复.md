## 任务描述
修复批量补推作业票时因base_work_certificate表为空导致certificateList为空的问题，并修正补推统计逻辑。

## 执行过程
```mermaid
graph TD
    A[需求:补推作业票操作证不为空] --> B[定位rePushBatchToPlatform方法]
    B --> C[发现certificateList从base_work_certificate查询但该表为空]
    C --> D[插入补全逻辑：若certificateList为空则调用buildCertificateList]
    D --> E[执行batchInsertBaseWorkCertificate保存到base_work_certificate]
    E --> F[设置fullData.certificateList确保推送有值]
    F --> G[同步修复主数据失败时success/fail计数不准问题]
    G --> H[添加fail++、log.error、continue跳过子数据推送]
```

## 任务总结
在BaseWorkSpecialServiceImpl.java中新增证书补全逻辑：补推时自动从base_contractor_people_cert构建并持久化到base_work_certificate；同时修正统计逻辑，主数据失败时准确累加fail并跳过后续推送，确保返回结果真实反映执行状态。
