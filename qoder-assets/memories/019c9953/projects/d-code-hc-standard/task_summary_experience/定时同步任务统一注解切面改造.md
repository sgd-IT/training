## 任务描述
为双控定时同步任务统一添加 `@SyncTask` 注解驱动的切面能力，实现日志记录、异常吞没、耗时统计的自动化，消除各任务方法中重复的 try-catch 和 log 代码。

## 执行过程
```mermaid
graph TD
    A[需求:统一同步任务切面] --> B[确认注解 SyncTask.java 已存在]
    B --> C[补全 SyncTaskAspect.java 切面逻辑]
    C --> D[定义 @Pointcut 匹配 @SyncTask 注解]
    D --> E[实现 @Around 方法：前置日志、proceed、后置日志、异常捕获+return null]
    E --> F[在 SyncShuangKongTask.java 中为6个 sync 方法添加 @SyncTask\("模块名"\) 注解]
    F --> G[删除各方法内重复的 try-catch、log.info/error 代码，仅保留核心业务逻辑]
```

## 任务总结
成功构建基于注解的同步任务切面体系：1）`SyncTask` 注解声明模块名称；2）`SyncTaskAspect` 统一处理日志、异常与耗时；3）`SyncShuangKongTask` 精简至仅含业务逻辑，代码行数减少约40行，可维护性显著提升。
