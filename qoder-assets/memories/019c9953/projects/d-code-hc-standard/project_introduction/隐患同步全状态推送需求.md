隐患数据同步需支持全状态推送，覆盖平台4个业务状态：
- businessState=0（待治理）：隐患新增时推送
- businessState=1（待验收）：申请关闭时推送
- businessState=2（验收不通过）：关闭驳回时推送
- businessState=4（验收通过）：确认关闭时推送
确保平台侧状态流转完整（0→1→2→4），满足监管平台的状态机校验、时效性指标统计和容错可追溯要求。
