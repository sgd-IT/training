项目视频上报功能需确保所有推送路径都正确设置filePath字段。当前已覆盖开工、完工、刷新视频、批量补推视频接口；用户新增要求：作业票批量补推接口（/push/workSpecial）也必须支持视频推送，并在推送前将videoPath赋值给filePath。
