隐患数据原录入并上传至`tgr-gz-vue.base_hidden_trouble_upload`表；本次需求要求支持4种业务状态（待治理、待验收、验收不通过、验收通过）的推送，并确保同一条隐患在状态流转时能通过平台`saveOrUpdate`接口正确更新（而非重复新增），需使用稳定唯一标识（如outer_id）关联各次推送。
