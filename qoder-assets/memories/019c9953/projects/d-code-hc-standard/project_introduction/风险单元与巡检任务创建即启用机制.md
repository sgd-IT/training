项目风险单元与巡检任务采用'创建即启用'设计：数据库status字段默认值为'0'（启用），前端表单不提供status配置项，后端插入逻辑不主动设置status，导致新建单元和任务自动进入启用状态，触发定时任务每小时生成检查记录。
