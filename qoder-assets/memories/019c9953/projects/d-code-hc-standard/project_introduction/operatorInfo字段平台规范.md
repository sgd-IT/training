operatorInfo字段为作业人员信息，必需字段。
- 格式要求：`姓名:身份证号,特殊作业工种,特殊工作证号`，所有类型统一使用此完整格式
- 多人时用英文分号`;`隔开，最后一人末尾不加分号
- 数据库存储格式为多人用逗号`,`分隔（如 `张三:ID1,证名1,证号1,李四:ID2,证名2,证号2`），推送时需转换为分号分隔
- transformOperatorInfo方法负责此转换：通过检测"逗号后是否为中文姓名+冒号"来智能拆分多人记录
- 示例：`张三:32013020083058,电焊工,T3201320083058;李四:32013020083059,电焊工,T32013020083059`
