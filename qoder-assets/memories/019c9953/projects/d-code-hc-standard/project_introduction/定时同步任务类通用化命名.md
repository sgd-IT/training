项目中定时同步任务类已从`SyncShuangKongTask`重构为更通用的`DataSyncTask`，对应Spring Bean名称为`dataSyncTask`，旨在支持多业务模块（如隐患、作业票等）的统一数据同步能力，不再绑定特定业务场景。
