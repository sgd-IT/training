管控措施数据存储在`base_risk_measure`表中，核心字段包括`id`（主键）、`risk_event_id`（关联风险事件）、`risk_unit_id`（风险单元ID）、`risk_measure_desc`（管控措施描述）、`sync_status`（同步状态：1=成功，2=失败）、`sync_result`（同步结果信息）、`create_time`（创建时间）。
