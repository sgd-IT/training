项目园区平台数据推送功能存在字段映射缺陷：
- `checkUserId` 字段错误地使用 `r.create_by`（人名），应改为 `r.check_user_id`（用户ID字符串，如"691,693,840"）
- `checkUserName` 字段错误地使用 `r.create_by`（单人），应改为 `r.check_user_name`（多人姓名字符串，如"黄雪晴,李小姑,马燕"）
该缺陷导致调用 `/openapi/check_unit_data/troubleshooting` 接口时因参数校验失败返回500错误。
