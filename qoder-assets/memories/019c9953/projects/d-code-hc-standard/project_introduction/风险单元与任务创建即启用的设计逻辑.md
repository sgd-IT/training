项目风险单元与巡检任务采用'创建即启用'设计：
- 数据库表`status`字段默认值为'0'（启用），自2026-03-13初始提交即如此；
- 前端新增表单未提供status字段，后端insert方法未主动设置status，MyBatis SQL跳过status赋值，全程依赖数据库默认值；
- 该逻辑自2026年3月13日项目初始代码起持续生效，未被修改。
