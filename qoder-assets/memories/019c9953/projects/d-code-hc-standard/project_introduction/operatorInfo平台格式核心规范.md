平台对operatorInfo字段的格式要求为：'人员身份证号,工作证件名称,工作证件号码'（不含姓名前缀），多人时用英文分号';'隔开，最后一人末尾不加分号。该要求直接来源于平台错误响应msg，是必须严格遵守的核心接口规范。
