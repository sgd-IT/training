项目定时任务推送策略:
- 所有定时任务（分析对象、风险单元、风险事件、管控措施、任务排查、排查记录）均为增量推送，只处理未同步(sync_status为null/'0'/'2')或失败的数据
- 作业票(workSpecial)无定时任务，仅在保存/开工/完工时实时推送，或通过`/push/workSpecial`接口手动补推
- 补推接口支持`onlyUnsynced`参数控制增量或全量推送
