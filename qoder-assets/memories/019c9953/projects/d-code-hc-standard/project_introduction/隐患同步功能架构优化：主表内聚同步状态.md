项目隐患同步功能已完成架构优化：废弃独立中间表 `base_hidden_trouble_upload`，在主表 `base_hidden_trouble` 中新增 `sync_status`（同步状态，1成功/2失败）和 `sync_result`（同步结果）字段，所有同步操作（单条upload与批量补推）均直接更新主表，SQL查询自动跳过已成功同步（sync_status='1'）的记录，实现天然幂等。
