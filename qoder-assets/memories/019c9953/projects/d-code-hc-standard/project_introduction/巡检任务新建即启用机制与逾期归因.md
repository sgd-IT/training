项目巡检任务存在'新建即启用'机制：新创建的高频率巡检任务（如1小时、2小时周期）会立即生成大量待检记录，但巡检人员未同步获知执行要求，导致严重逾期（如液氯储罐气化装置7月18日新建7个任务，1小时/2小时周期逾期率高达94%/89%）。而长期运行的低频任务（如12小时、1天周期）逾期率仅0.6%，证明周期设置本身合理。
