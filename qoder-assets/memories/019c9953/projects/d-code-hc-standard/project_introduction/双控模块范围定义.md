项目中'双控'指代一组需同步推送至园区平台的核心业务模块，包括：风险四色图（base_risk_fourchart）、分析对象（base_risk_obj）、风险单元（base_risk_unit）、风险事件（base_risk_event）、管控措施（base_risk_measure）、任务排查（base_risk_task）和排查记录（base_risk_task_record）。
