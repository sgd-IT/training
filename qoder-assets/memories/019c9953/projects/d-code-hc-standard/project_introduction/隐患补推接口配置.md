项目已实现隐患补推接口，路径为`POST /push/hiddenTrouble`，支持不传参全量推送或通过`startDate`/`endDate`参数按日期范围筛选推送；接口自动跳过无`measureId`的旧记录，并在返回结果中统计跳过数量。
