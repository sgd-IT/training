项目需对接第三方园区平台的隐患排查记录接口 `/openapi/check_unit_data/troubleshooting`，该接口为外部系统定义的OpenAPI规范，要求严格遵循其字段定义、必填约束和数据类型。关键必填字段包括 `latitude`、`longitude`、`mobileMe`（15-17位）、`checkStatus`（integer）、`checkTime`（文档标为integer但示例为string）等。
