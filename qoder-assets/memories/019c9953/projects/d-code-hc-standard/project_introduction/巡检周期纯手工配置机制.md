项目巡检任务的巡检周期完全由创建者在前端界面手工配置：
- `checkCycle` 为必填数字输入框（范围1~365），无默认值
- `checkCycleUnit` 为下拉选择（小时/天/月/年），默认值为'小时'
- 后端不修改、不计算、不干预该值，直接入库
- 数据库仅对空值兜底设为1，不存在系统自动分配不同周期的逻辑
