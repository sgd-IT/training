风险单元停用/检维修状态判定以平台时间逻辑为准：当存在停机记录且当前时间在 `stopTime` 到 `activationTime` 时间范围内时，状态为停用（`status="1"`）；当当前时间超过 `activationTime` 后，状态自动恢复为正常（`status="0"`）。
