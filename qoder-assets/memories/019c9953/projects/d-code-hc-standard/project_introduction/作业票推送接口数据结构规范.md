作业票推送接口的数据结构规范如下：
- 主请求体为单个JSON对象 `{...}`
- `videos`、`sensors`、`certificates`、`signatureDtos`、`steps`、`tools`、`approves` 等子字段必须为非空数组格式 `[{}]`（含0个或多个元素），不可为 `{}` 或 `null`
- `operatorInfo` 字段为分号分隔的字符串，格式为 `姓名:身份证号,工种,证号`，支持多人
