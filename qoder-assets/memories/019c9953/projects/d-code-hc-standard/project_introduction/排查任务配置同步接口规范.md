项目提供排查任务配置同步接口 `/openapi/checkTask/saveOrUpdateBatch`（OpenAPI 3.0规范），用于新增或修改双重预防机制中的排查任务。关键约束：
- 请求体为JSON数组，每项必填 `id`、`riskMeasureId`、`troubleshootContent`、`checkCycle`、`checkCycleStart`、`checkCycleUnit`、`checkCycleEnd`、`checkStartTime`、`workType`、`createTime`、`createBy`、`updateTime`、`updateBy`、`taskNum`
- `checkCycleUnit` 取值范围1-4（1:小时, 2:天, 3:月, 4:年）
- 示例报文已验证与数据库实际任务数据一致
