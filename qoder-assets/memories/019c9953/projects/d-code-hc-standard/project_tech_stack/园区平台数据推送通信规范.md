项目中所有对接园区平台（http://111.4.80.39:8092）的数据推送，均采用同步阻塞式 HTTP POST 调用，不使用消息队列或异步线程。

推送数据格式以JSON数组为主：
- 大多数接口使用`sendPost(JSONArray array, String uri)`方法，请求体为`[{...}, {...}]`格式；
- 少数单条接口（如特殊作业的`saveTicket`）使用`sendPost(JSONObject json, String uri)`，请求体为单个`{...}`对象；
- 即使仅推送一条数据，也普遍采用将单个JSON对象包装进JSONArray的方式发送。
