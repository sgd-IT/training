## 任务描述
为维修单（wb_repair_order）表及对应Java模型补充设备关联（device_id/device_name/device_location）与来源枚举（source）字段，并完善表单验证与Excel导出支持。

## 执行过程
```mermaid
graph TD
    A[需求:补全设备与来源字段] --> B[更新建表SQL：添加字段+索引]
    B --> C[更新修复脚本：ADD COLUMN + MODIFY COLUMN + ADD KEY]
    C --> D[同步WbRepairOrder实体：新增字段+更新status/level注释]
    D --> E[完善WbRepairOrderBo：新增字段+@NotNull/@NotBlank/@Size验证]
    E --> F[扩展WbRepairOrderVo：新增字段+@ExcelProperty+workerName翻译]
```

## 任务总结
成功实现维修单弹窗表单的设备关联选择与来源枚举功能：SQL层新增4字段及2索引；Java层三类对象（Entity/Bo/Vo）全部同步；Bo层对deviceId/source/level/workerId/description施加精准验证；Vo层支持Excel导出并自动翻译workerName。
