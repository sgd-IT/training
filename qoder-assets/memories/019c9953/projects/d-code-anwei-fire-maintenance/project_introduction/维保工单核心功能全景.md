维保工单功能覆盖全生命周期管理，包含：
- 工单列表：展示工单号、设备、位置、来源、故障描述、优先级、负责人、时间、状态，支持排序与筛选；
- 状态Tab切换：全部/待处理/处理中/已完成/已验收，带数量统计；
- 新建工单：弹窗表单，含设备选择、P1-P4优先级、负责人、5类来源（计划维保/值守联动/巡查发现/合规检查/客户报修）、故障描述，含表单验证；
- 工单详情：6个Tab（基本信息/故障详情/处理时间线/配件使用/验收记录/关联告警）；
- 状态流转：pending→processing→done→verified四态单向递进；
- 来源与优先级均为枚举标签展示，优先级需颜色区分。
