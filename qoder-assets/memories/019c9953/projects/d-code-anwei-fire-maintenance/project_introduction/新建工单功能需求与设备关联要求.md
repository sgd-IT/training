新建工单功能需支持弹窗表单，包含设备选择（关联设备台账）、优先级（P1-P4）、负责人、来源（5种枚举）、故障描述，并实现完整表单验证；设备名称与位置需通过device_id关联设备台账实现‘关联选择’和‘自动带出’，device_id为必要关联字段。
