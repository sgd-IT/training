3.1.3维保工单是系统核心模块，支持全生命周期管理：
- 用户角色：技术主管（创建/分配/查看进度）、技术员（查看/处理）
- 状态流转：待处理(pending) → 处理中(processing) → 已完成(done) → 已验收(verified)
- 功能覆盖：工单列表（P0，支持排序筛选）、状态Tab切换（全部/待处理/处理中/已完成/已验收，带数量统计）、新建工单（P0，含设备选择/P1-P4优先级/负责人/来源/故障描述表单验证）、工单详情（6个Tab：基本信息/故障详情/处理时间线/配件使用/验收记录/关联告警）、工单来源（5种枚举）、优先级体系（P1-P4颜色区分）
- 数据字段：工单号（WO-YYYY-NNNN自动生成）、设备名称（关联选择，必填）、设备位置（自动带出）、来源（5种枚举，必填）、故障描述（≤500字，必填）、优先级（P1-P4枚举，必填）、负责人（关联选择，必填）、状态（4态枚举，自动流转）
