项目角色体系包含5个新增业务角色：
- 维保单位管理员（wb_admin）：系统最高业务权限，管理所有模块和数据，对应公司总经理/运营总监
- 技术主管（wb_tech_manager）：管理技术团队，审核工单和报告，对应技术部经理
- 维保技术员（wb_technician）：现场执行维保、巡检任务，对应一线维保工程师
- 客户管理员（wb_customer_admin）：客户方管理角色，查看报告和服务质量，对应物业安全主管
- 客户用户（wb_customer_user）：客户方普通用户，查看基本信息，对应物业管理层
