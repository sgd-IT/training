维保工单核心数据模型当前缺失3个关键字段：
- `device_name`（设备名称，支持关联选择）
- `device_location`（设备位置，自动带出）
- `source`（工单来源，枚举值：计划维保/值守联动/巡查发现/合规检查/客户报修）
这些字段已确认需在`wb_repair_order`表中新增，以支撑工单全生命周期管理。
