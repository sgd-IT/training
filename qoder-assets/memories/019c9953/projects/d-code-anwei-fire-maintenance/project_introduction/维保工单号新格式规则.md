维保工单号格式更新为`WB-YYYY-MM-XX`（如`WB-2026-01-A3`），其中`WB`为业务前缀，`YYYY`为年份，`MM`为月份，`XX`为当月内字母+数字组合的顺序流水号（如A1、A2…A9、B1…）
