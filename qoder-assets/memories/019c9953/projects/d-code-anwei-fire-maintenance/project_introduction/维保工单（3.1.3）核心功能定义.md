维保工单（3.1.3）是维保工单系统的核心功能模块，实现全生命周期管理：
- 用户角色：技术主管（创建/分配/查看进度）、技术员（查看/处理）
- 状态流转：待处理(pending) → 处理中(processing) → 已完成(done) → 已验收(verified)
- 工单来源：计划维保、值守联动、巡查发现、合规检查、客户报修（5种枚举）
- 优先级体系：P1(紧急)/P2(高)/P3(中)/P4(低)，颜色区分
- 关键字段：工单号(WO-YYYY-NNNN)、设备名称（关联选择）、设备位置（自动带出）、故障描述（≤500字）、负责人、状态、来源、优先级
