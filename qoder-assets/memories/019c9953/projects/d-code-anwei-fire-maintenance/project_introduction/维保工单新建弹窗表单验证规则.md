维保工单（3.1.3）新建工单弹窗的表单验证规则如下：
- `customerId`: @NotNull（客户必选）
- `deviceId`: @NotNull（设备必选，关联选择）
- `source`: @NotBlank（来源必选，5种枚举）
- `level`: @NotBlank（优先级必选，P1-P4）
- `workerId`: @NotNull（负责人必选）
- `description`: @NotBlank + @Size(max=500)（故障描述必填且≤500字）
`deviceName`和`deviceLocation`不加验证，由后端根据`deviceId`自动填充。
