维保工单系统数据库名为`anwei-fire-maintenance`，表前缀为`wb_`，共21张表，按业务划分为企业管理、客户管理、合同管理、团队管理、标准管理（树形）、维保管理、维修单、双随机一公开八大模块；核心工单流转路径为：`wb_project`（项目）→ `wb_task`（维保任务）→ `wb_patrol_test`（巡查测试）或`wb_repair_order`（维修单）。
