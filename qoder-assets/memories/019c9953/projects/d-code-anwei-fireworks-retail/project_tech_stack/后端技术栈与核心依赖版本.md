开发语言与运行环境：JDK 21（官方明确标注JDK-21与JDK-25双支持）

核心框架：
- Spring Boot 4.1.0（非主流的Spring Boot 3.x，属Spring Boot 4系列）
- Web容器：Jetty（非Tomcat）
- ORM：MyBatis-Plus 3.5.17
- 权限：Sa-Token 1.45.0
- 缓存与分布式：Redisson 4.6.1、Lock4j 2.2.7
- 任务调度：SnailJob 2.0.2
- 文件存储：MinIO、AWS S3协议客户端
- 工作流：Warm-Flow 1.8.9
- 搜索：Easy-Es 3.0.2 + Elasticsearch 7.17.28
