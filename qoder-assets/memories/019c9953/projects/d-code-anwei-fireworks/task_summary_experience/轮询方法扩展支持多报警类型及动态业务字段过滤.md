## 任务描述
修改 AlramInfoServiceImpl 中的 pollIllegalIntrusionForVoice 定时轮询方法，使其同时支持 alarmType=1（超员作业）和 alarmType=4（非法入侵）的语音播报，并对 alarmType=1 增加 sys_user.personnel_positioning 字段校验（仅当 != 0 时才轮询）。

## 执行过程
```mermaid
graph TD
    A[需求:扩展轮询覆盖alarmType=1] --> B[分析现有轮询逻辑与数据流向]
    B --> C[检索User实体及personnel_positioning字段定义]
    C --> D[确认sys_user关联方式与UserService可用性]
    D --> E[在AlramInfoServiceImpl中注入UserService]
    E --> F[扩展查询条件为alarmType IN (1,4)]
    F --> G[批量查询companyCode对应personnel_positioning值]
    G --> H[循环中显式过滤alarmType=1且positioning==0的记录]
    H --> I[修复alarmTypeStr生成逻辑为显式分支判断]
```

## 任务总结
成功改造轮询方法：新增 UserService 注入与 personnel_positioning 批量查询逻辑；alarmType=1 仅在企业启用人员定位时触发播报；alarmTypeStr 判断改为显式 if-else 分支，避免隐式兜底歧义；所有日志与注释同步更新为双类型语义。
