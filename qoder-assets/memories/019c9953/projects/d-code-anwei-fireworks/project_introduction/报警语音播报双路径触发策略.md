项目报警语音播报功能需支持两种触发路径：
- alarmType=4（非法入侵）：始终通过定时轮询触发
- alarmType=1（超员作业）：仅当对应企业开启人员定位（sys_user.personnel_positioning != 0）时才通过定时轮询触发，否则走save()方法路径
