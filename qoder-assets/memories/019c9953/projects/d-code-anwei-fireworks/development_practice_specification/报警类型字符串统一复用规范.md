报警类型字符串展示必须复用AlramInfo实体的getAlarmTypeStr()方法，该方法已完整覆盖alarmType=1至5共5种类型（超员作业、通道堵塞、超高超量、非法入侵、摄像头遮挡偏移），禁止在业务逻辑中重复定义或手动映射报警类型字符串。
