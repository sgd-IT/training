后端技术栈：
- 核心框架：Spring Boot 2.1.13.RELEASE、Spring 5.3.39、Spring Cloud Greenwich.SR6
- ORM/数据层：MyBatis-Plus 3.2.0、Sharding-JDBC 4.0.0-RC2、Dynamic Datasource 3.3.1、MySQL Connector/J 9.1.0
- 安全与认证：JWT 0.9.0、Swagger 2.7.0
- 存储与文件：Qiniu 7.2.23、Aliyun OSS 2.8.3、Tencent COS 5.6.24、iTextPDF 5.5.13、PDFBox 2.0.15、EasyExcel 2.1.6
- 工具与中间件：FastJSON 1.2.70、Jackson Databind 2.9.10.8（安全加固）、Netty 4.1.115.Final、MQTT v3 1.2.2、XXL-JOB 2.4.0、Activiti 7.1.0.M4
- 其他：ZXing 3.3.0（二维码）、Pinyin4J 2.5.0（拼音转换）、Jsoup 1.13.1（HTML解析）、Gson 2.11.0、SLF4J API 2.0.16
