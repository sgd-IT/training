# 06-Redis与缓存
> 层级：06｜建立：2026-10-30｜状态：空
## 【本类范围】
数据类型与底层编码、过期策略与淘汰策略、持久化 RDB/AOF、主从/哨兵/集群、缓存穿透/击穿/雪崩、缓存与数据库一致性、分布式锁、热 key 与大 key、序列化与反序列化兼容。
## 【高频考点】
- 缓存穿透 / 击穿 / 雪崩的区别与各自解法（空值缓存、互斥重建、随机过期、多级缓存）
- 防击穿为什么用互斥 + 双检，单机锁与分布式锁的取舍
- 缓存与 DB 双写一致性：先删缓存还是先写库，延迟双删的边界
- 分布式锁的四大要求（互斥、防死锁、防误解锁、可重入），Redisson 怎么实现
- bigkey / hotkey 的发现与治理
- 序列化格式变更导致反序列化失败（Jackson 默认类型、字段增删兼容）
## 【与项目经历的关联】
- 大屏统计缓存防击穿：轮询接口 + 缓存过期瞬间的并发重建（06-面试素材“大屏统计缓存防击穿与 Druid 配置排错”）。
- 缓存是拉长轮询间隔还是加缓存：曾做过“拉长间隔不加缓存”的取舍（important_decision）。
- Redis 反序列化问题：Boolean 写 TINYINT 与缓存反序列化的修复（02-专题）。
- 维护窗口不缓存业务数（滚动告警与值班员权限边界）。
