# 08-消息队列
> 层级：08｜建立：2026-10-30｜状态：空
## 【本类范围】
MQ 选型对比（Kafka/RocketMQ/RabbitMQ）、可靠投递（生产确认、持久化、消费确认）、幂等消费、顺序消息、消息积压、延时消息、死信队列、事务消息。
## 【高频考点】
- 如何保证消息不丢（三段各怎么做）
- 重复消费怎么防（去重表、唯一键、状态机幂等）
- 顺序消息的实现与代价
- 积压的应急处理与根本治理
- 消息 vs 定时任务轮询的选型边界
- 本地消息表 / 事务消息解决什么一致性问题
## 【与项目经历的关联】
- 本项目以轮询 + WebSocket 推送为主，MQ 使用面窄：讲清“为什么这里用轮询/WS 而不是 MQ”，比硬背 MQ 八股更容易得分。
- 推送统一门面与二级/三级告警分流的设计，可迁移到“消息路由与幂等”话题。
- 幂等复用：告警入库去重与重复弹窗治理（上游双请求入库）。
