# 07-ORM持久层
> 层级：07｜建立：2026-10-30｜状态：空
## 【本类范围】
MyBatis 执行流程与四大组件、Mapper 代理与接口绑定、动态 SQL、结果映射与驼峰、一级/二级缓存、批量与批处理、分页插件原理、注解 SQL 的边界、多租户/逻辑删除等拦截器、N+1 问题。
## 【高频考点】
- MyBatis 从 Mapper 接口到 SQL 执行的完整链路
- `#{}` 与 `${}` 的区别与注入风险
- 一级缓存的作用域与失效条件，二级缓存为什么慎用
- 动态 SQL 标签在注解里为什么不好写（`<script>` 或 XML）
- 批量插入的三种做法与性能差异（foreach 拼接、ExecutorType.BATCH、rewriteBatchedStatements）
- 分页插件是内存分页还是物理分页，深翻为什么慢
- ResultMap 与自动映射冲突、`map-underscore-to-camel-case` 的适用边界
- 拦截器链的执行顺序（租户、分页、SQL 打印）
## 【与项目经历的关联】
- 告警列表 N+1 改批量查询（IN 分批 + Map 归并），带前后耗时对比（06-面试素材）。
- `selectOne` 用在非唯一字段导致 TooManyResultsException（03-踩坑手册）。
- 注解 SQL 不支持动态拼接时的边界与改写（架构约束记忆）。
- 多租户拦截器 + 逻辑删除在 SQL 层自动加条件，注意 ignoreTable 三态判定。
