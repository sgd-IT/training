# 10-系统设计与场景题
> 层级：10｜建立：2026-10-30｜状态：空
## 【本类范围】
大屏实时数据推送、海量设备上报接入、告警去重与抑制、消息通知、限流与防刷、短链、秒杀、排行榜、文件与报表导出、长连接与断线重连。答法套路：先问清量与约束 → 定接口与数据模型 → 拆读写路径 → 讲瓶颈与兜底。
## 【高频考点】
- 设计一个设备上报接入层：协议、并发、幂等、离在线判定
- 设计一个实时大屏：轮询 vs WebSocket、推送粒度、断线重连与补偿
- 设计告警系统：去重、抑制、分级、通知渠道、防轰炸
- 设计一个统计接口：缓存、预计算、口径统一
- 限流方案：单机 vs 分布式，令牌桶 vs 滑动窗口
- 长连接方案：WS / SSE / MQTT 的取舍
## 【与项目经历的关联】
- 设备上报接入：UDP/TCP 协议组件、AEP 平台回调、24 小时心跳下的在线判定（01-项目）。
- 实时大屏：WS 双轮询并行、今日警情 WS 驱动、无 offset 上拉加载（01-项目）。
- 告警去重与弹窗治理、二级/三级轻提示分流（06-面试素材）。
- 统计口径统一（Java 与 SQL 同源）与缓存防击穿。
