# 09-微服务与分布式
> 层级：09｜建立：2026-10-30｜状态：空
## 【本类范围】
服务拆分与边界、注册中心与配置中心、网关与统一鉴权、服务调用与熔断限流降级、分布式事务（2PC/TCC/ Saga/本地消息表）、分布式 ID、分布式锁、CAP 与 BASE、幂等与重试。
## 【高频考点】
- 服务怎么拆（按业务域 vs 按团队），拆错了怎么收
- 网关层做鉴权的边界与透传用户上下文
- 熔断、限流、降级的区别与常见实现
- 分布式事务方案对比与各自代价
- 分布式 ID 的几种生成方案与时钟回拨
- 跨服务数据一致性：最终一致的落地方式
- 微服务链路排查（traceId 透传）
## 【与项目经历的关联】
- 本项目是单体多模块（module-system / module-infra / module-biz 等），可讲清“模块边界如何替代服务边界”，避免硬吹微服务。
- 统一鉴权 + 租户上下文的透传与清理，等价于网关层鉴权问题的单体解法。
- `TenantUtils.execute` 跨线程/跨租户执行与 `@TenantIgnore` 的边界（架构事实记忆）。
- AI 模块通过 Api 接口与业务模块解耦（module-ai 契约）。
