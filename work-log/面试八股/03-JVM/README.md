# 03-JVM
> 层级：03｜建立：2026-10-30｜状态：空
## 【本类范围】
内存区域划分、对象创建与逃逸分析、垃圾回收器（G1/CMS）、类加载与双亲委派、编译期常量与运行期、常用排查工具（jps/jstat/jmap/jstack/arthas）。
## 【高频考点】
- 堆与栈的分工、字符串常量池在哪个区
- G1 分区回收与停顿目标参数
- 类加载双亲委派与打破场景（SPI、热部署）
- 内存泄漏 vs 内存溢出，怎么定位
- CPU 飙高的排查路径（top → jstack → 线程栈）
- 大量反射/字节码增强带来的元空间问题
## 【与项目经历的关联】
- 线上 CPU 飙高、接口超时的排查链路可挂 06-面试素材里的故障条目。
- 增量编译毒性 class 污染 target 导致启动类加载异常（03-踩坑手册）。
- 单实例部署容量与 GC 停顿对轮询接口的影响（P99 抖动）。
