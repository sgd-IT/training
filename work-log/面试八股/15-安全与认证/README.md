# 15-安全与认证
> 层级：15｜建立：2026-10-30｜状态：空
## 【本类范围】
会话与 Token（JWT 结构、过期与刷新）、认证与授权的区别、RBAC 与数据权限、越权（水平/垂直）、SQL 注入与 XSS/CSRF、密码存储、敏感数据脱敏、接口签名与防重放、多租户数据隔离、上传与文件安全。
## 【高频考点】
- JWT 的三段结构与无状态认证的代价（无法主动失效怎么解）
- 认证（你是谁）与授权（你能干什么）分开讲，权限模型怎么落到代码
- RBAC 与数据权限（只能看本租户/本部门）的实现层次：菜单 → 按钮 → 数据
- 水平越权与垂直越权的区别与通用防法（后端强制校验资源归属）
- SQL 注入：`#{}` 预编译为什么能防，`${}` 什么时候不得不留
- 密码为什么用 BCrypt，加盐与慢哈希的意义
- 敏感字段脱敏与日志脱敏
## 【与项目经历的关联】
- 多租户隔离：拦截器自动加 `tenant_id`、`@TenantIgnore` 的边界、跨租户查询要显式走 `TenantUtils.execute`（架构事实）。
- `user_type` 位掩码控制多端登录平台与登录门禁（01-项目）。
- 角色可见性：值守大屏按租户划分数据范围、功能收口到后端校验（development_practice）。
- 客户端证书、`/app-api` 免登录边界与 Swagger 调试的认证差异（环境配置）。
- 反控码二次验证（租户级反控码 + PC 二次验证，06-面试素材）。
