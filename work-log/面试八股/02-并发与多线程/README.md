# 02-并发与多线程
> 层级：02｜建立：2026-10-30｜状态：空
## 【本类范围】
线程生命周期、线程池参数与拒绝策略、synchronized 与 Lock、AQS、CAS 与 ABA、volatile 与内存模型、ThreadLocal、CompletableFuture、并发容器。
## 【高频考点】
- 线程池七个参数、队列选择、生产环境参数怎么定
- synchronized 锁升级、锁消除/粗化
- CAS 的 ABA 与 AtomicStampedReference
- volatile 可见性与禁止重排，为什么不能保证原子性
- ThreadLocal 内存泄漏与线程池复用导致的脏数据
- 定时任务与业务线程隔离（调度线程被慢任务拖死）
## 【与项目经历的关联】
- 设备状态写库节流：内存态与持久态一致、并发写同一设备的竞态窗口（06-面试素材）。
- 定时任务（告警回捞、巡检、自动签到）线程模型与幂等：同一任务被触发两次的处理。
- 协议组件回调线程 vs 业务线程池：不要在 IO 回调里做重活。
