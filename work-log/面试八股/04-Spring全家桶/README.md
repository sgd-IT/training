# 04-Spring全家桶
> 层级：04｜建立：2026-10-30｜状态：空
## 【本类范围】
IoC 容器与 Bean 生命周期、循环依赖三级缓存、AOP 与代理、事务传播与失效场景、Spring Boot 自动装配、条件注解、事件机制、拦截器/过滤器/切面执行顺序。
## 【高频考点】
- Bean 生命周期与扩展点（BeanPostProcessor、Aware）
- 循环依赖为什么需要三级缓存，构造器注入为什么不行
- `@Transactional` 失效的六种场景（自调用、非 public、异常被吞、事务管理器不对等）
- AOP 代理边界的通用后果：**注解生效的前提是经过代理对象调用**
- 自动装配原理：`spring.factories` / `AutoConfiguration.imports` + 条件注解
- 拦截器 vs 过滤器 vs 切面：执行顺序与能否拿到 Bean
- 多租户拦截器与 Web 过滤器链的先后关系
## 【与项目经历的关联】
- AOP 代理边界：同类自调用导致注解失效的真实案例（06-面试素材“AOP 代理边界”条目）。
- 事务在批量写入 / 跨模块调用下的传播行为与部分提交风险。
- 多租户隔离靠 `TenantUtils.execute` + 过滤器/MyBatis 拦截器，可讲清一条请求里租户上下文的注入与清除。
