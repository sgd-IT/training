# 13-数据结构与算法
> 层级：13｜建立：2026-10-30｜状态：空
## 【本类范围】
数组/链表/栈/队列/哈希/树/堆/图的基础性质与复杂度、排序与二分、双指针、滑动窗口、递归与回溯、动态规划入门、并发下的无锁结构（CAS/环形缓冲）。
## 【高频考点】
- 链表反转、快慢指针判环、合并有序链表
- 二叉树遍历（递归与迭代）、层序遍历、最近公共祖先
- 二分查找的边界写法（左闭右闭 vs 左闭右开）
- 滑动窗口与双指针的适用特征
- Top K（堆 vs 快排分区）
- 哈希冲突处理与开放寻址
- 复杂度分析：均摊、最坏、空间换时间
## 【与项目经历的关联】
- 项目里的真实算法点：值班轮换的取模与锚点计算、统计口径的合并去重、时间窗口内的区间合并。
- 批量 IN 查询的分片（列表按 N 切块）与 Map 归并，属于“空间换时间”的实战。
- 一致性哈希/环形缓冲可作扩展话题，不要硬套项目。
