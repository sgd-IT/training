## 主题：泛型是给编译器看的

Day 9 的 `MiniList` 存 `Object[]`，取出来要强转、转错了运行时才炸。
泛型把强转和类型检查从**运行时**搬到**编译期**。

**擦除**：编译之后 `List<String>` / `List<Integer>` 在字节码里是同一个类。
三个后果：不能 `new T[]`、不能 `new T()`、`instanceof` 不能带类型参数。

Day 10 复述检验第 1 题（`new E[]` 为什么编译不过）在这里补上后半段：
数组在运行期必须知道自己装什么，`T` 已被擦成上界 → 编译器不知道给 `newarray` 填什么类型。

## PECS

```
List<? extends Number>   上界   →  只能读，不能 add
List<? super Integer>    下界   →  只能写，读出来只能是 Object
```

- `? extends` 不能 add：传进来可能是 `List<Double>`，塞 Integer 就毁了它
- Producer Extends, Consumer Super

## ☕ Record

```java
record Pair<K, V>(K key, V value) { }
```

自动生成：私有 final 字段、全参构造、访问器 `key()` / `value()`（**没有 get 前缀**）、
`equals` / `hashCode` / `toString`。不可继承、不能有额外实例字段、不可变。

## 复盘问答

### ① 擦除 —— 学员先交了 AI 的答案

学员贴回来的是两段「Descriptor / Signature」讲解，**不是终端输出**（有"例如""通常变为"）。
教练自己跑：

```
public static <T extends java.lang.Comparable<T>> T maxOf(java.util.List<T>);
    descriptor: (Ljava/util/List;)Ljava/lang/Comparable;
```

调用方 `javap -p -c` → **4 处 `checkcast`**（3 个 `Integer` + 1 个 `String`；
`maxOfSingleElementAndEmpty` 里调了两次 `maxOf`，所以 Integer 有 3 个）。

**链条**：源码 `T` → 字节码 `Comparable` → 调用方 `checkcast` 转回 `Integer` / `String`。

### ② PECS

学员把 jshell 片段粘进了 `GenericsLab.java:177-179`，**编译直接炸**（Day 11 同类错）：

```
int 无法转换为 capture#1, 从 ? extends java.lang.Number
```

教练用 `javac` 单独验证，拿到干净原文：

```
error: incompatible types: int cannot be converted to CAP#1
  where CAP#1 is a fresh type-variable:
    CAP#1 extends Number from capture of ? extends Number
```

| 侧 | 学员表现 |
|---|---|
| `? extends` 为什么不能写 | ✅ 最终能讲出 capture + 上界够用（读只要上界，写要精确类型） |
| `? super` 为什么能写、读出来是什么 | ❌ 首答「读出来是 capture#1」= 把 extends 的话套过来了。实际读出来是 **`Object`** |

### ③ record 自动生成了什么

学员答「**全绿**，只是改了名字，类型擦除不依赖名字」—— 两处错：

- 不是全绿
- 类型擦除跟 record **无关**（擦除是泛型的事）

正解 **4 红**：`pairEqualsIsGeneratedByRecord`（`Object.equals` 比地址）、
`pairHashCodeIsGeneratedByRecord`（`Object.hashCode` 身份哈希）、
`pairToStringIsReadable`（`类名@哈希`）、`pairIsARecord`（`isRecord()` false）。

追问「两个 `new` 出来的对象 hashCode 凭什么不一样」→ 学员答 **不清楚**，教练讲：
`Object.hashCode()` 是**身份哈希**；而且它**并不违反** Day 7 契约
（契约只要求「equals 相等 ⇒ hashCode 相等」，此时 equals 已是 false，hashCode 不同完全合规）。
