## 今日考点

1. **数组长度固定** —— 没有"变长数组"；`ArrayList` 的"可变长"是**扩容假象**
2. **`size` vs `capacity`** —— 真实元素个数 vs 底层数组长度（本日最核心的区分）
3. **懒初始化** —— 第一次 `add` 才分配数组（和 `HashMap` 的 `table` 同一套路）
4. **为什么是 `Object[]` 而不是 `E[]`** —— Java 不允许 `new E[]`（类型擦除，Day 14 正式讲）
5. **`ConcurrentModificationException` 的成因**：迭代器内部的 `modCount` 与 `list.remove()` 不同步
   —— **⚠️ 单线程也会抛**！它说的"并发"是"两方同时在改"，不是"两个线程"
6. **四种删除写法的对错**：
   | 写法 | 结果 |
   |---|---|
   | `for-each` + `list.remove()` | ❌ 抛 CME |
   | `Iterator` + `it.remove()` | ✅ |
   | `list.removeIf(...)` | ✅ 最简洁 |
   | 索引 `for` + `remove(i)` | ❌ **不抛异常，但会漏元素** ← 最危险 |
7. **索引删除为什么漏元素**：`remove(i)` 之后后面元素全部前移，`i++` 正好跳过了一个

   ```
   ["a","a","a"]  i=0 删 -> ["a","a"]，i 自增到 1
                  i=1 拿到的是原下标 2 那个元素 -> 删 -> ["a"]，i 自增到 2
                  i=2 >= size(1) -> 结束
   结果 ["a"]  ← 删不干净，而且不报错
   ```
8. **三种 List 来源的脾气**：
   | 来源 | 长度可变 | 内容可变 | 备注 |
   |---|---|---|---|
   | `new ArrayList<>()` | ✅ | ✅ | 默认选择 |
   | `Arrays.asList(...)` | ❌ | ✅（`set`） | **是视图**：改它 = 改原数组 |
   | `List.of(...)` | ❌ | ❌（连 `set` 也不行） | 完全不可变，适合当常量 |
9. **`LinkedList` 的真实定位**：`get(i)` 是 **O(n)**（没有下标，要一个个数过去）；
   中间插入也还是 O(n)（得先走到那）。**实际项目 99% 用 `ArrayList`。**
   它真正的价值是**当 `Deque` 用**：头尾进出 O(1)，`push/pop` 是栈，`offer/poll` 是队列。
