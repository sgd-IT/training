## 主题：Agent 调模型就是这个动作

### 一、JSON 就是「对象 ⇄ 字符串」

调 OpenAI / 通义 / 任何模型：请求体是 JSON，响应体也是 JSON。Java 侧标准工具是 **Jackson**（Spring Boot 内置）。

```
ObjectMapper              「翻译机」，线程安全，可复用
JsonProcessingException   受检异常 —— 解析失败必须处理（Day 15 的知识点复现）
```

### 二、★ record 天生能被 Jackson 处理（2.12+）

```java
record Point(int x, int y) {}
// 序列化 → {"x":1,"y":2}   组件名就是字段名，不需要 getter
```

能这样是因为 record 的访问器和构造器都带名字信息 —— Day 14 的东西直接用上。

### 三、★★ 未知字段默认**抛异常**（坑 1）

```java
record Point(int x, int y)
对方返回 {"x":1,"y":2,"z":3}
→ UnrecognizedPropertyException（JsonProcessingException 子类）
```

由 `DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES` 控制，**默认 true**。
线上真实事故形状：对方接口加了个字段，你的服务直接 500。

### 四、★★ 泛型擦除在这里复发（坑 2，今天最重要）

```java
mapper.readValue(json, List.class)                          → List<LinkedHashMap>   // 错
mapper.readValue(json, new TypeReference<List<Point>>(){})   → List<Point>           // 对
```

`List.class` 是擦除后的 Class 对象，里面没有 `Point`。
`TypeReference` 的原理是**匿名子类**：泛型信息写在子类签名里，运行期反射还能读到 —— 和 Day 14 的 `checkcast` 同一套机制。

### 五、★ HTTP：JDK 自带 HttpClient

```java
HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder(URI.create(url)).GET().build();
HttpResponse<String> resp = client.send(request,
        HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
```

两个要点：
1. `send` 抛 `IOException` + `InterruptedException`（都是受检的）
2. 读 body **必须显式指定 UTF-8** —— `ofString()` 不带参数用默认编码

另外 JDK 21 起 `HttpClient` 实现了 `AutoCloseable`，可以 try-with-resources。
