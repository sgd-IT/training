## 追问记录
1. `new String("abc") == "abc"` → 用户答 false ✓（new 出新对象地址不同，== 比地址；equals 比值 true）
2. static 共享原因 → 用户答「存在内存里，每个对象都可调用」——方向对但模糊；
   教练精确化：static 字段全类只有一份、属于类；实例字段才是每对象一份
3. `int... numbers` 的类型 → 用户答「数组，空数组」✓（方法内是 int[]，sum() 时是长度 0 的空数组）
4. 为什么星星数和 substring 下标都是 length()-4 → 用户主动提问；
   教练用下标图讲解：同一个数两种身份——repeat 里是「数量」（遮掉几个），
   substring 里是「下标」（保留部分从哪开始，0 起数）；9 位号码验证
5. Q3 公式化后自己跑测试确认全绿 ✓（首次主动确认测试结果的行为，值得鼓励）
