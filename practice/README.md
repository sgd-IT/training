# practice 训练工程（Day 1 摸底）

## 怎么打开（IDEA）
1. IDEA → File → Open → 选择 `D:\code\training\practice` 目录
2. 信任项目（Trust Project），等右下角 Maven 导入完成（首次会下载依赖，需要联网）
3. 打开 `src/test/java/com/training/day01/BasicsTest.java`，右键 → Run

## 规则（摸底测验专用）
- 只改文件里标注 `// TODO` 的方法体，**不要改方法签名、类名、包名**
- 限时 30 分钟，**全程不许用 AI**（包括不让 AI 查错）
- 先读测试类，明白每个方法该干什么，再动手写
- 写不完没关系，如实记录卡在哪

## 完成后
把测试运行结果（绿/红）和卡点贴回聊天，教练逐题审阅 + 追问。
